## 摘要
前沿多模态大语言模型（MLLMs）在感知方面表现出色，但在科学和数学推理上仍显不足。对于闭源权重或设备端骨干模型，参数级自适应不可用，而无状态提示则无法从已解决的问题中获得任何累积收益。我们提出	extbf{DG-Mem}，一种双粒度智能体记忆框架，通过非参数化、外部存储的记忆增强冻结的MLLM，该记忆在训练时的一次性展开中构建，并在测试时以只读方式查阅。受人类记忆的互补学习系统（CLS）理论启发，DG-Mem将其存储区分为实例级范例记忆和类别级IF-THEN规则模式记忆，并通过瞬态反思存储区调节其构建过程，使得模式仅从抽象反思中综合生成，而从不来自范例文本。DG-Mem的两个设计选择使其脱颖而出：一种在线概念分类器，在训练期间逐步扩展类别空间，而非预先设定固定分类体系；以及一种Shapley上下文归因程序，将正确性分解到整个检索到的规则集上，并为每条规则生成效用值，从而在测试时重新加权检索结果。该流程无需梯度更新，可部署于闭源权重或设备端骨干模型。在MathVista、MMMU和MMMU-Pro上，使用四种开放权重和专有骨干模型（Qwen3.5-27B、Qwen3.5-122B-A10B、GPT-5-Nano、Gemini-3-Flash），DG-Mem相较于无记忆和竞争性记忆基线均取得了一致的改进。

## Abstract
Frontier multimodal large language models (MLLMs) deliver impressive perception yet still falter on scientific and mathematical reasoning. Parameter-level adaptation is unavailable for closed-weight or on-device backbones, and stateless prompting forfeits any compounding benefit from problems already solved. We propose \textbf{DG-Mem}, a dual-grained agentic memory framework that augments a frozen MLLM with a non-parametric, externally stored memory built once from training-time rollouts and consulted read-only at test time. Motivated by the Complementary Learning Systems (CLS) account of human memory, DG-Mem factors its store into an instance-grounded exemplar memory and a category-level schema memory of IF-THEN rules, with a transient reflection store mediating their construction so that schemas are synthesized only from abstract reflections, never from exemplar text. Two design choices distinguish DG-Mem: an online concept categorizer that grows the category space incrementally during training rather than committing to a predefined taxonomy, and a Shapley context attribution procedure that decomposes correctness across the entire retrieved rule set and yields a per-rule utility that re-weights retrieval at test time. The pipeline introduces no gradient updates and is deployable on closed-weight or on-device backbones. Across MathVista, MMMU, and MMMU-Pro on four open-weight and proprietary backbones (Qwen3.5-27B, Qwen3.5-122B-A10B, GPT-5-Nano, Gemini-3-Flash), DG-Mem improves consistently over no-memory and competitive memory baselines.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构
- DG-Mem 由冻结的 MLLM 骨干网络和非参数外部记忆 M 组成，M 在训练阶段构建，测试阶段冻结并只读。
- 对每个测试问题 q，系统先生成概念摘要 K(q)，然后从记忆 M 中检索相关子集 Mq，最后将 Mq 与原始问题一起作为上下文输入骨干模型，生成答案。

### 2.2 记忆的三层结构
- **范例记忆（Exemplar Memory, ME）**：
  - 每个训练问题对应一条范例记录，包含两部分：
    - `reasoning_strategy`：适用于同类问题的具体推理步骤。
    - `verification_check`：针对最常见错误模式的核查方法。
  - 使用多模态嵌入（图像+文本）进行索引和检索，以区分纯文本无法区分的视觉近邻干扰项。
- **模式记忆（Schema Memory, MS）**：
  - 每个概念类别对应一组 IF-THEN 规则，由模式合成器（Synth）从同类问题的反思规则中归纳生成。
  - 规则经过抽象化约束：禁止包含具体数值、选项字母、实体名称等，以确保可迁移性。
- **瞬态反思存储（Reflection Store, MR）**：
  - 作为中间对象，保存每条问题级别的 IF-THEN 规则（ρ(q)）。
  - MR 仅用于合成 MS，**范例文本永远不会进入模式合成过程**，以此实现 CLS 理论中的“模式介导的整合”约束。

### 2.3 在线概念分类器（Online Concept Categorizer）
- 传统方法依赖预定义分类体系，但固定分类要么过粗（如单一"几何"桶）要么过细（如每个概念签名一个桶）。
- DG-Mem 在训练过程中动态增长类别空间：
  - 分类器 Cat 提取问题的关键概念 K(q)，与现有类别注册表比对。
  - 若匹配度高（>70% 概念重叠）则分配到已有类别；否则创建新类别，并附带代表概念。
  - 类别空间单调增长，无需预定义类别数量。

### 2.4 Shapley 上下文归因（Shapley Context Attribution）
- **目标**：解决“多个规则共同检索时，如何将正确答题的功劳合理分配给每条规则”的信用分配问题。
- **流程**：
  - 阶段 2 中，对于每个训练问题 q，随机采样 B 个子集（包括空集和全集），对每个子集运行一次推理（固定解码种子、图像内容等，只改变注入的规则子集），得到二元奖励 v(S)。
  - 将规则视为合作博弈中的玩家，Shapley 值计算每条规则的平均边际贡献：
    \[
    \Delta_q(r_i) = \frac{1}{K!} \sum_{\pi \in S_K} \left[ v(P_i^\pi \cup \{r_i\}) - v(P_i^\pi) \right]
    \]
  - 规则 rᵢ 的历史效用 U(rᵢ) 为所有问题上的平均 Shapley 贡献。
- **检索重加权**：
  - 测试时，规则得分由嵌入相似性和历史效用共同决定：
    \[
    s_i = \alpha \cdot \hat{\text{sim}}(r_i, q) + (1-\alpha) \cdot \hat{U}(r_i)
    \]
  - α 控制相似性与效用的权重，默认 α=0.8。
- **故意排除范例记忆的效用更新**，避免阶段 1 与阶段 2 问题重叠导致的信息泄漏。

### 2.5 记忆注入方式
- **Priming（前置启动）**：在问题之前注入记忆，预先引导求解思路。
- **Verification（验证）**：在问题之后注入同一记忆，用于对生成答案进行事后审计。

### 2.6 整体离线流程
- **阶段 1（记忆构建）**：
  - 对每个训练问题采样 N 条解题轨迹，通过验证级联（基准匹配器→符号解析器→LLM 裁判）标注正确/错误。
  - 并行生成反思规则 ρ(q)、范例记录 e(q) 和类别标签 κ(q)。
  - 训练完成后，按类别聚合 MR 中的规则，由 Synth 合成 MS。
- **阶段 2（Shapley 归因）**：
  - 读取 MS 和类别注册表，对每个问题采样规则子集并运行推理，计算每条规则的 Shapley 值，累加为效用列。
