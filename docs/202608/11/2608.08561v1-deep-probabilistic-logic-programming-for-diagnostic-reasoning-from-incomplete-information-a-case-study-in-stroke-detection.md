## 摘要
在医学应用中，原始数据常常涉及重大的隐私问题，因此根据文献中的汇总统计数据进行编码显得尤为重要。另一方面，深度学习已成为基于视觉或听觉传感器数据评估症状的宝贵工具。DeepProbLog提供了一种可扩展的神经符号方法，能够在透明且严谨的概率框架（即分布语义下的概率逻辑编程）中整合连接主义组件来分析患者图像。本文以多模态数据卒中检测案例研究为框架，探讨了从文献中的汇总统计数据到基于DeepProbLog的诊断系统的路径。它提出了一种工作流程，利用已建立的最大熵技术来补充可用的概率信息，并使用概率逻辑编程系统ProbLog 2从熵最大化的因果模型过渡到可在DeepProbLog中表达的可判别神经符号模型。本文还分析了基于不完整数据所得模型的相对性能，探讨了概率归纳逻辑编程系统ProbFOIL 2在压缩大型判别模型方面的潜力，并讨论了使用DeepProbLog进行诊断推理的前景和影响。

## Abstract
In medical applications, raw data is frequently associated with significant privacy concerns, lending particular importance to the encoding of summary statistics from the literature. On the other hand, deep learning has become an invaluable tool for assessing symptoms based on visual or auditory sensor data. DeepProbLog allows for an extensible neuro-symbolic approach that accommodates connectionist components to analyse patient images within a transparent and rigorous probabilistic framework, namely probabilistic logic programming under the distribution semantics. Framed as a case study in stroke detection from multimodal data, this contribution explores the pathway from summary statistics available in the literature to a DeepProbLog-based diagnostic system. It suggests a workflow using established maximum entropy techniques to complete available probabilistic information and the probabilistic logic programming system ProbLog 2 to move from the entropy-maximising causal model to a discriminative neuro-symbolic model expressible within DeepProbLog. The relative performance of models derived from less complete data is analysed alongside the potential of the probabilistic inductive logic programming system ProbFOIL 2 for compressing large discriminative models, and the perspectives and implications of using DeepProbLog for diagnostic reasoning are discussed.

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 概率知识编码与最大熵原理

- 输入信息为部分条件概率约束（如给定疾病时各症状的条件概率）。
- 由于概率信息不完整，需要选择一种准则补全概率分布。论文采用 **最大熵原理**，即在所有满足已知约束的分布中选择熵最大的分布。
- 引用 Williamson 的定理（Proposition 1）：若约束图中 Z 分离 X 与 Y，则在最大熵分布中 X 与 Y 关于 Z 条件独立。因此仅知道“症状|疾病”型约束时，最大熵分布中症状在疾病条件下相互独立。
- 论文进一步指出，医学文献中对症状的描述往往隐含因果结构（症状 = 疾病导致的部分 ∨ 其他原因导致的部分）。他们显式建模这种结构，将每个症状拆分为“由卒中/TIA引起”和“由其他原因引起”两部分，并规定“其他原因”部分在无卒中时不为零但在有卒中时独立，这比直接使用原始条件概率更符合因果语义。

### 2.2 生成式概率模型（ProbLog 2）

- 使用 **ProbLog 2** 编码概率规则，支持概率事实、概率规则及析取规则（disjunctive rules）。
- 模型分为两部分：
  1. **非卒中人群的症状基线概率**：来自文献中受访者数据，采用最大熵原理默认为各症状独立；对缺失区分的数据（如手臂/腿部无力合并；面部麻痹与言语障碍合并）做相应处理（合并；或将面部麻痹与言语障碍设相同概率）。
  2. **卒中/TIA 的症状生成模型**：针对症状与卒中/TIA 的关系建模，并使用 noisy-or 聚合机制。简化模型基于 Table 1 中各症状独立条件概率；完整模型则利用 Figure 1 中所有症状共现组合数据，为每个共现组合建立辅助谓词和频率规则。

### 2.3 判别式模型构建

- DeepProbLog 要求神经谓词作为事实输入，因此需要将因果生成模型“反转”为判别模型：以 `stroke_or_tia` 为首部，各症状组合为条件的规则。
- 通过 ProbLog 条件推理，针对每一种可能的症状组合计算 P(stroke_or_tia | 症状组合)，得到一张包含所有组合的判别式规则表。
- 判别式模型规则形式：`p :: stroke_or_tia :- weakness, \+facial_palsy, speech, \+sensory, \+visual.`，其中 p 为从生成模型推得的后验概率。

### 2.4 模型压缩：ProbFOIL 2

- 生成的判别式模型包含所有 2^n 种症状组合的规则，规模指数级增长。
- 利用 **ProbFOIL 2** 进行理论压缩：从完整模型中枚举每个症状组合的条件概率作为“人造个体”的概率事实（probabilistic entailment 设置），让 ProbFOIL 2 归纳出更简洁的规则集。
- ProbFOIL 2 在优化概率准确率的同时，采用似然比检验作为显著性准则平衡规则复杂度，最终输出少量高特异性组合规则（如 `0.972 :: stroke_or_tia :- weakness, speech, facial_palsy`）。

### 2.5 神经符号集成（DeepProbLog）

- 使用 DeepProbLog 的 `nn` 神经事实：`nn(m, [X1,...]) :: r(...)`，即神经网络输出作为概率事实。
- 面部麻痹检测使用卷积神经网络（CNN），在 PyTorch 中实现：
  - 归一化层 + 4 个卷积块（滤波器数 16, 32, 64, 128），每层后接最大池化；
  - 每卷积块后施加 25% dropout；
  - 展平后接 256 单元全连接层，ReLU 激活；
  - 3×3 卷积核、2×2 池化；Adam 优化器、He/Kaiming 初始化。
- 完整系统：用户输入症状 + 拍摄面部图像 → CNN 输出面部麻痹概率 → 结合判别式模型动态构造 DeepProbLog 程序 → 执行概率推理得到卒中/TIA概率。系统提供 Streamlit Web 界面，代码在 GitHub 公开。

## 6. 主要结论与发现

- **最大熵补全的有效性**：从文献中部分概率信息出发，最大熵原理可以合理补全分布，并自然导出症状在给定疾病下条件独立的基线模型。
- **判别式转换可行**：通过生成模型 + ProbLog 条件推理，成功构建了符合 DeepProbLog 要求的判别式模型，说明神经符号框架能够处理需要从因果模型逆转为诊断模型的任务。
- **模型复杂度的影响**：
  - 简化模型中，症状条件独立假设导致判别式模型参数数量随症状数指数增长；
  - 分型模型通过在亚型层保留部分相关性，使得在相同（甚至更少）的结构简化下，准确率和精确率优于完全独立模型；
  - ProbFOIL 2 压缩出的模型取得了最高的准确率和精确率（0.960 和 0.962），且规则数远少于完整模型，证明理论压缩在此场景有效。
- **压缩模型的取舍**：ProbFOIL 2 模型的召回率（0.931）低于简化模型（0.989），原因是它把很多低概率的卒中组合的概率设为零，可能导致高风险患者被漏诊；这对医疗诊断是一个需要谨慎对待的缺陷。
- **运行性能**：端到端推理总延迟约 153ms（150ms 量级），满足实时使用的基本要求。
- **架构反思**：DeepProbLog 将神经谓词限定为“事实”而非“软证据”，导致必须将生成模型大量重写为判别模型，增加了复杂性和参数数量。作者提出未来应支持神经谓词作为“软证据”，以更贴合观测数据的自然语义。
- **可扩展性**：添加更多症状或神经系统（如言语障碍检测）在生成层面是模块化的，但会导致判别模型翻倍和概率全部重算；风险因素（如肥胖、已有疾病）的加入也亟待更完善的因果熵最大化建模，以避免“解释消除”效应被忽视。
