## 摘要
结构因果模型是推理干预和反事实的标准语言，但它们描述的是静态变量，通常只测量一次，并且通常禁止循环依赖。我们关心的许多系统，如患者、气候和经济，反而在时间中连续演化，在不规则的时间点被观测，并且包含反馈回路。我们认为，神经算子学习为在这种情境下进行因果推理提供了自然基础，并提出了Orca，一个框架，其中因果图的每个节点是时间的函数，每个机制是函数空间之间学习到的映射。我们扩展了现有的神经算子架构以表达因果机制：一种机制通过将多个父函数作为输入来计算节点的函数值，尊重时间箭头，并将潜在的外生噪声视为可以被推断并用于反事实的函数。我们形式化了这一模型类别，并在合成连续时间示例上演示了反事实推理。代码可在 https://github.com/gerritgr/orca 获取。

## Abstract
Structural causal models are the standard language for reasoning about interventions and counterfactuals, but they describe static variables, typically measured once, and usually forbid cyclic dependencies. Many systems we care about, such as patients, climates, and economies, instead evolve continuously in time, are observed at irregular time points, and contain feedback loops. We argue that neural operator learning provides a natural foundation for causal reasoning in this setting, and propose Orca, a framework in which each node of the causal graph is a function of time and each mechanism is a learned map between function spaces. We extend existing neural operator architectures to express causal mechanisms: a mechanism computes the function value of a node from its parent nodes by taking several parent functions as input, respects the arrow of time, and treats latent exogenous noise as a function that can be inferred and reused for counterfactuals. We formalize the model class and demonstrate counterfactual reasoning on synthetic continuous-time examples. Code is available at https://github.com/gerritgr/orca

### 1. 论文的核心问题与整体含义

**研究动机与背景**：
- 结构因果模型（SCM）是因果推理的标准形式化语言，但经典 SCM 只描述静态变量，通常一次测量，并禁止循环依赖。
- 现实中的关键系统（患者健康、气候、经济、流行病等）是连续时间演化的动态系统，观测时间点不规则，且普遍存在反馈回路（如健康状况影响运动量，运动量又影响健康）。
- 现有将 SCM 扩展到时序数据的方法多基于离散时间步展开或固定采样网格，导致因果结论依赖人为选定的离散化，无法在不同分辨率间迁移。
- 神经算子学习（Neural Operator Learning）能够学习函数空间之间的**离散化不变映射**，为连续时间因果建模提供了自然基础，但现有神经算子缺乏干预/反事实语义。

**核心含义**：论文提出 Orca 框架，将神经算子作为连续时间因果模型中机制（mechanism）的自然表达形式，使每个节点是时间的函数，每个机制是函数空间间的映射，从而在尊重时间方向的前提下支持因果效应估计、反事实推理和机制学习。

### 2. 方法论：核心思想、关键技术细节与算法流程

**核心思想**：
- 以循环连续时间因果模型为生成模型，每个节点 $v$ 的值 $x_v(t)$ 是时间 $t$ 的函数，由父节点历史 $H_v(t)$（严格过去时刻的父节点观测）和当前外生噪声 $N_v(t)$ 通过机制算子 $F_v$ 决定。
- 通过自环（self-loop）处理循环依赖：每个节点的父节点集合包含自身，但在 $t' < t$ 时读取自身过去值，从而避免瞬时循环，使前向模拟拓扑为有向无环图。

**形式化模型**：
- 模型为元组 $(G, F_v, N_v)$：$G$ 为允许循环的有向因果图，$F_v$ 为前向算子（机制），$N_v$ 为外生噪声随机过程（如布朗运动）。
- 节点值更新：$x_v(t) = F_v(H_v(t), N_v(t), t)$，其中 $H_v(t) = \{(u, t', x_u(t')) | u \in pa(v), t' < t\}$。
- 特殊情形为**加性噪声**：$x_v(t) = F_v(H_v(t), t) + N_v(t)$，此时噪声可作为残差从数据中恢复。

**网络架构**：
- 采用 DeepSets 风格的 encode-sum-decode 结构：嵌入网络 $\phi_{\theta_1}$ 编码每个父节点的历史测量（节点标记、时间、值），加权求和后由解码网络 $\rho_{\theta_2}$ 结合查询时间 $t$ 输出预测值。
- 权重 $w_{t'_k} = \frac{1}{2}(t'_{k+1} - t'_{k-1})$ 使求和逼近积分 $\int_0^t \phi_{\theta_1}(u, s, x_u(s)) ds$，实现分辨率一致性（不受采样密度影响）。
- 损失函数为按受试者归一化的均方误差：$L_v(\theta) = \frac{1}{M} \sum_{i=1}^M \frac{1}{|T_{i,v}|} \sum_{t \in T_{i,v}} (\hat{x}_{i,v}(t) - x_{i,v}(t))^2$。

**因果查询计算**：
- **剂量-反应曲线**：$e \mapsto E[x_{v^*}(t^*) | do(x_v = e)]$，通过干预（替换某一节点的机制）后重新模拟获得。
- **反事实轨迹**：在加性噪声下用残差推断个体潜变量；在非加性噪声下，通过**基于秩的最优传输**将观测个体与采样噪声轨迹耦合（采样 $K \geq M$ 条噪声轨迹，用 Sinkhorn 求解熵正则化最优传输，丢弃未匹配样本），再在保持噪声固定的条件下重放干预后的模拟。

### 3. 实验设计

**数据集/场景**（均为合成数据）：

- **实验 1：血糖-胰岛素模型（分辨率收敛性）**
  - 1000 名患者，24 小时，模拟胰岛素敏感度 $X(t)$（潜在外生变量/混杂因子）、胰岛素剂量 $I(t)$（对近期血糖的响应）、血糖 $G(t)$（通过指数核累积胰岛素效应）。
  - 干预查询：剂量-反应曲线 $E[G(12) | do(I = i)]$，干预水平 $i \in [0, 2.4]$ 共 8 个水平。
  - 对比方法：① 池化基线（忽略患者身份和时间，仅用瞬时胰岛素预测血糖）；② Orca 固定核变体（已知核结构）；③ Orca 通用算子（无假设的 deep-set 算子）。
  - 变化因素：采样密度 $M \in \{5, 10, 20, 40, 80, 160\}$ 点/患者。

- **实验 2：肿瘤生长（非加性噪声下的反事实）**
  - 1000 名患者，12 个月，Gompertz 生长模型 + 化疗药物杀伤：$\frac{dV_i}{dt} = \rho V_i \log \frac{K}{V_i} - \beta e^{\sigma \varepsilon_i(t)} C_i V_i$，其中潜伏噪声 $\varepsilon_i(t)$ 为布朗路径（时变药物敏感性），非加性地乘在治疗项上。
  - 干预查询：个体反事实 $do(C \to 0.5C)$。
  - 验证方式：左面板检查噪声耦合质量（推断秩轨迹 vs 分配噪声秩轨迹）；中面板比较观测与生成的人群轨迹分布（中位数与 10–90% 区间）；右面板展示个体反事实预测与真实反事实的对比。

**Benchmark**：以真实数据生成过程的重模拟作为 ground truth，对比 Orca 两种变体与两个朴素基线（忽略因果图、忽略时间结构）。

### 6. 主要结论与发现

- Orca 能够从不规则采样的连续时间数据中学习因果机制，并恢复干预剂量-反应曲线和个体反事实轨迹，同时保持分辨率一致性（在不同采样密度下结论趋同）。
- 忽略因果图（不加年龄/敏感度作为父节点）导致混杂偏倚，估计的剂量-反应曲线斜率偏高；忽略时间结构（静态 SCM 处理时序数据）则产生系统性偏差。两个朴素基线均明显偏离 ground truth。
- 固定核变体（已知机制结构）最可解释且最准确；通用算子（无结构先验）在无需假设机制形式的情况下仍能紧跟 ground truth。
- 在非加性噪声下，基于秩的最优传输耦合可以有效地将观测受试者与潜在噪声轨迹配对，从而使个体反事实预测与真实轨迹合理吻合（中位误差 0.57 体积单位）。
- 学习得到的核函数具有可解释性——可视为过去某时刻干预对当前结果的因果效应随滞后时间的衰减。

### 7. 优点

- **方法学创新**：将神经算子学习从单个输入函数推广到多个父函数输入，并首次将时间方向原则（原因先于效应）编码进神经算子架构，同时支持循环依赖——这是静态 SCM 无法自然处理的核心场景。
- **分辨率一致性**：通过加权和逼近积分的设计，模型参数不依赖采样网格，可在训练和推理使用不同网格，具有理论收敛保证（DeepSets 表示定理 + MIONet 多输入算子逼近定理双重支撑）。
- **统一的因果语义**：在同一个框架内支持因果效应估计、机制学习和反事实推理，将干预语义（do-算子）与神经算子模拟无缝衔接。
- **可解释性**：固定核变体学习到的核函数直接可解释为滞后效应函数，为理解动态系统提供透明视角。
- **承认非加性噪声的挑战**：提出基于最优传输的耦合方案，将经典的秩-变换思想（Matzkin 2003; Chernozhukov & Hansen 2005）推广到函数空间，是处理非可分离噪声的初步尝试。
- **可复现性**：提供固定种子的三套 notebook，一键可复现全部实验。

### 8. 不足与局限

- **因果图给定**：论文假设因果图已知，未涉及因果发现（从数据学习图结构），且假设因果充分性（无未观测共同原因），这限制了在真实数据上的直接应用。
- **预测拟合≠因果正确**：即使训练损失很小，若参数化未能反映真实机制结构，因果估计可能严重偏倚——论文明确承认这一点（“参数化必须镜像真实机制，否则因果估计可能显著偏倚而训练损失几乎不动”）。这使 Orca 通用变体在真实场景中的可靠性存疑。
- **反事实假设过强**：个体反事实需要加性噪声或单调性假设；非加性通用情形仅以“草图”呈现，耦合方法的具体性质（如收敛性、最优性）未得到理论保证。
- **残留代理偏差**：节点值积分了噪声，导致残差代理反映累积偏差而非瞬时偏差，可能高估受试者潜在轨迹的持续性。
- **数据模型理想化**：假设无测量噪声、各节点同步观测，与真实纵向数据（如电子健康记录）存在差距。
- **验证全是合成数据**：无真实世界应用（如电子健康记录），外部有效性未被证明；且网格细化的收敛是渐近性质，稀疏采样下快动态弱辨识、长视界查询存在误差累积风险。
- **实验规模有限**：仅两组实验，未覆盖更复杂的机制结构、噪声模型多样性、异步观测等边缘情况。
