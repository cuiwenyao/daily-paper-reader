## 摘要
文档级关系抽取（DocRE）旨在跨扩展上下文提取多个实体之间的关系，并保持预测三元组之间的一致性。尽管大型语言模型（LLMs）在信息抽取中展现出卓越的推理能力，但其对每个候选三元组的预测通常是独立生成的，可能违反传递性、对称性和功能唯一性等基本关系约束，从而导致矛盾且不可靠的输出。我们提出了CONSISTRE，一个统一的面向DocRE的一致性感知框架，通过两条互补路径解决这一局限。第一条路径在推理阶段适用于黑盒LLMs，结合约束感知提示、基于约束的验证和迭代自省，无需任务特定微调即可优化预测。第二条路径通过知识蒸馏和强化学习流水线，将一致性知识注入较小的开源模型：来自强大教师模型的推理轨迹通过监督微调蒸馏到学生模型，随后使用联合优化抽取性能和关系一致性的复合奖励进行GRPO对齐。这两条路径在统一的一致性公式下，同时覆盖了API可访问和本地可部署的场景。在DocRED上的实验表明，两条路径均优于其基线，其中推理时路径使用现成的黑盒LLMs取得了具有竞争力的F1分数，而训练时路径则大幅缩小了7--8B开源模型与最先进专有LLMs之间的差距，且推理成本仅为后者的一小部分。消融研究证实，显式一致性建模能缓解关系矛盾，并增强基于LLM的DocRE在两种部署范式下的可靠性。

## Abstract
Document-level relation extraction (DocRE) aims to extract relations among multiple entities across extended contexts while maintaining consistency across predicted triples. Although large language models (LLMs) show remarkable reasoning capabilities in information extraction, their predictions are typically generated independently for each candidate triple and may violate fundamental relational constraints such as transitivity, symmetry, and functional uniqueness, leading to contradictory and unreliable outputs. We propose CONSISTRE, a unified consistency-aware framework for DocRE that addresses this limitation through two complementary tracks. The first operates at inference time for black-box LLMs, combining constraint-aware prompting, constraint-based verification, and iterative self-reflection to refine predictions without task-specific fine-tuning. The second injects consistency knowledge into smaller open-source models via a knowledge distillation and reinforcement learning pipeline: reasoning traces from a powerful teacher are distilled into a student via supervised fine-tuning, followed by GRPO alignment using a composite reward that jointly optimizes extraction performance and relational consistency. Together, the two tracks cover both API-accessible and locally deployable scenarios under a unified consistency formulation. Experiments on DocRED show that both tracks outperform their baselines, with the inference-time track achieving competitive F1 using off-the-shelf black-box LLMs and the training-time track substantially narrowing the gap between 7--8B open-source models and state-of-the-art proprietary LLMs at a fraction of their inference cost. Ablation studies confirm that explicit consistency modeling mitigates relational contradictions and enhances the reliability of LLM-based DocRE across both deployment paradigms.

## 一、论文的核心问题与整体含义

- **研究背景**：DocRE 要求从整篇文档中抽取分散在多个句子中的实体关系三元组，相比句子级关系抽取更具挑战性。传统监督方法（如图神经网络、逻辑规则注入）依赖大量任务特定标注，而新兴的 LLM 范式可以作为通用信息抽取器，在少样本/零样本场景下展现潜力。
- **核心问题**：现有 LLM 在 DocRE 中通常对每个候选实体对**独立生成预测**，忽略了三元组之间应有的全局一致性——如传递性（A→B 且 B→C 则应有 A→C）、对称/逆关系（A 是 B 的上级则 B 是 A 的下属）、功能唯一性（每人只有一个出生日期）。这导致输出中充斥着**自相矛盾的关系三元组**，降低了结果的可靠性。
- **整体含义**：论文提出 **CONSISTRE**——一个统一的、一致性感知的 DocRE 框架，通过两条互补轨道（推理时和训练时）将关系一致性约束引入 LLM 系统，同时覆盖 **API 可访问的专有模型** 和 **可本地部署的开源小模型** 两种应用场景，从而在保证抽取质量的同时显著提升输出的一致性与可靠性。

## 二、方法论

### 1. 一致性公式（统一核心）

- 定义三类可普遍适用的关系约束：
  - **传递性（Transitivity）**：如果 (ea, r, eb) 和 (eb, r, ec) 均成立，则 (ea, r, ec) 也应成立。
  - **对称性与逆约束（Symmetry/Inverse）**：若 (eh, r1, et) 被预测，则 (et, r2, eh) 也应存在；某些关系自对称（r1 = r2）。
  - **功能唯一性（Functional Uniqueness）**：对 (eh, r, ·) 形式的函数关系，同一 head 只能有一个有效 tail。
- 定义一致性分数：**Cons(Ŷ) = 1 − V(Ŷ) / (T(Ŷ) + ε)**，其中 T 为触发的约束实例总数，V 为违反数。该分数在两条轨道中共享，作为 Track A 的验证信号和 Track B 的奖励组件，具有**轨道无关**和**可扩展**两大特性。

### 2. Track A：推理时一致性（用于黑盒 LLM）

- **约束感知提示（Constraint-Aware Prompting）**：将文档、任务指令、结构化输出格式和声明式约束提示（传递性、逆关系、功能唯一性）拼接到输入中，引导模型首轮生成初始候选三元组。
- **基于约束的验证（Constraint-Based Verification）**：对候选集计算两类信号：基础预测分数 S_base(Ŷ) 和约束违反分数 V(Ŷ)（分解为 V_trans + V_inv + V_func），合成总分 **S(Ŷ) = S_base(Ŷ) − λV(Ŷ)**，低于阈值则触发修正。
- **迭代自省与修正（Iterative Reflection & Refinement）**：将具体违规类型（如“链式关系缺失”）作为结构化反馈提供给模型，令其针对性修正；迭代至满足一致性阈值或达到最大轮数。整个过程不修改任何模型参数。

### 3. Track B：训练时一致性（用于开源小模型）

- **教师轨迹生成**：用强教师模型（GPT-5.2）生成包含 reasoning、consistency_check、entity、relation 四个字段的结构化 JSON 轨迹；采用**金标对齐（Gold-Truth Alignment）**策略，将 entity/relation 字段替换为 DocRED 金标，而保留 reasoning 和 consistency_check 不变。
- **SFT 蒸馏**：用教师轨迹对学生模型进行 token 级负对数似然训练，采用 LoRA 参数高效微调（rank=16, α=32）。
- **GRPO 强化对齐**：使用无评论家的 GRPO 算法，采组 G=4 个完成，按复合奖励排序并计算归一化优势。奖励函数为 **R = α·F1 + β·Cons + γ·Fmt**（α=0.7, β=0.2, γ=0.1），含 KL 散度正则防止偏离 SFT 策略过远。

## 三、实验设计

- **数据集与基准**：使用 **DocRED** 基准（de facto 标准 DocRE 数据集），但评估用 **200 文档的 dev 子集**（而非完整 dev 集），原因是 Track A 多轮反思的 API 消耗巨大。作者说明 50 文档的预实验与 200 文档结果相对排序一致。
- **Track A**：骨干模型为 **GPT-5.2** 和 **Gemini-2.5 Pro**，评估 4 种提示配置（Base、+CoT、+Self-Reflection、+CoT+Self-Reflection）× 3 种 few-shot 设置（0/1/5-shot）。对比 Reflection 基线：Reflexion、Self-Refine、Chain-of-Verification（CoVe）。
- **Track B**：学生模型为 **Qwen2.5-7B-Instruct** 和 **Qwen3-8B-Instruct**，教师为 GPT-5.2。训练数据：1,200 文档 SFT + 500 文档 GRPO。
- **消融实验**：包括 Track A 的单约束消融（去传递性/逆/功能唯一性）、Track B 的金标对齐策略消融、奖励组成消融、人类评估验证 Cons 指标有效性。
- **对比方法**：监督 PLM 方法（DREEAM 0.674、KD-RoBERTa 0.671）、分类器+微调 LLM（LMRC 0.611）、纯 LoRA 微调 LLaMA2-13B（0.393）、零样本 GPT-4（0.156）等。

## 六、主要结论与发现

1. **Track A 有效且稳健**：两骨干上提示策略排序一致（Base < +CoT < +Self-Reflection < +CoT+Self-Reflection），最高 F1 为 Gemini-2.5 Pro 5-shot 下的 **0.5433**，GPT-5.2 达 **0.5305**。
2. **通用自我反思方法在 DocRE 上失效**：Reflexion、Self-Refine、CoVe 在有真实反馈信号时均 **降低** F1（相对 5-shot Base 下降 0.06–0.08），原因是“无锚点的自我批评”驱动模型过度删除正确三元组；而 CONSISTRE 用结构化违规反馈替代自由式批评，将 F1 提升 0.117。
3. **Track B 大幅缩小与专有模型差距**：Qwen3-8B 经 SFT+GRPO 达 F1=0.492，约为 GPT-5.2 最佳结果的 93%，而参数量少约两个数量级；Cons 分数达到 0.719，仅比 Gemini-2.5 Pro 低 0.040。
4. **SFT 与 GRPO 互补**：SFT 主要建立逆关系对称性（局部可学习），GRPO 主要修复传递性违规（全局多跳性质），Qwen3-8B 传递性违规减少 26.5%，且非通过抑制预测实现。
5. **一致性显式建模优于隐式浮现**：大量证据表明一致性收益来自框架本身而非 CoT/反思本身。

## 七、优点

- **统一性设计**：两轨道共享同一套形式化一致性约束，一个适用于 API 黑盒场景，一个适用于本地小模型场景，逻辑自洽、可对照比较。
- **约束定义清晰且可扩展**：三类约束（传递性、逆/对称、功能唯一性）均为关系抽取领域的常识性基础约束，易检验、可解释、可扩展新约束类型。
- **方法设计有针对性**：Track A 用结构化违规反馈替代自由式批评，解决了自我反思“噪声化”问题；Track B 采用金标对齐策略，隔离教师幻觉与蒸馏信号。
- **分析层次深入**：包括约束级消融、类型级一致性动态分析、人类评估验证指标、跨轨道对比，研究叙事完整且有说服力。
- **实用性导向强烈**：覆盖本地部署场景，明确关注推理成本与部署约束，结果贴近真实应用需求。

## 八、不足与局限

- **评估规模有限**：仅用 200 文档子集（完整 dev 3,000 文档），统计功效不足，且未报告完整 dev/test 集上的结果，无法与基准方法在完全相同的条件下比较。
- **对教师模型依赖性强**：Track B 完全依赖 GPT-5.2 的推理轨迹质量；金标对齐虽缓解输出幻觉，但 reasoning 字段的“废保真度”未被系统评估，可能影响蒸馏质量。
- **预定义约束覆盖有限**：三类约束远不能覆盖 DocRE 中所有可能的全局一致性（如互斥关系、多实体联合约束等），框架效果受约束覆盖率制约。
- **Track B 结果多为单种子**：主表仅报告单种子（seed=42），3 种子方差仅出现于补充；种子间 F1 波动约 ±0.009，尚可但应更全面报告。
- **DocRED 注释不完备**：论文指出 DocRED 金标本身传递性 Cons 仅 0.265，说明部分性能差距可能源自注释缺失而非模型失败；但未在测评中使用 Re-DocRED 等修正版基准来验证。
- **人类评估样本极小（30 文档）且依赖 LLM 判官**：两位 LLM 判官（Claude、Gemini）也是模型，且 transitivity 维度相关系数中等（r=0.705），不构成严格的心理学测量标准。
