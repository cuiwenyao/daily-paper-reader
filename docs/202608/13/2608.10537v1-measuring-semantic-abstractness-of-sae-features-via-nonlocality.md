## 摘要
稀疏自编码器（SAEs）通过理解相应任务相关且因果有效的特征，帮助揭示了大型语言模型（LLM）行为（如推理、越狱等）的机制性解释。为了评估此类机制性解释，下游研究必须区分表层词汇特征与真正高级的特征。然而，基于自动解释的语义描述和因果引导效用都无法完全确定特征的抽象层次。为此，我们引入了特征非局域性（FNL），定义为对SAE特征激活的归一化逐位置影响的熵。我们报告称，FNL与现有的基于LLM的特征语义抽象性代理指标相关，并成功区分了上下文依赖的推理特征与词元驱动特征，在随机抽取的一对上下文特征和词元级特征中，有73%–84%的比例将更高的FNL正确分配给上下文特征。我们展示了两项下游应用。我们审计了用于越狱缓解的基于SAE的特征，并惊奇地发现，大多数有效特征是低FNL的位置特征，而非真正识别有害意图。我们报告称，在DeepSeek-R1-Distill-Llama-8B中引导高FNL特征，相比未引导模型，MATH-500准确率提高了4.6个百分点，并且优于引导低FNL特征，尽管这种提升因模型而异。我们的结论是，FNL提供了一种不依赖LLM、无标签、相关性的证据，可用于衡量SAE特征的抽象层次，并应用于评估机制性解释以及选择用于下游干预的特征。

## Abstract
Sparse autoencoders (SAEs) have helped uncover mechanistic explanations for LLM behaviours such as reasoning, jailbreaking etc., via understanding the corresponding task-relevant and causally effective features. To evaluate such mechanistic explanations, downstream studies must distinguish surface lexical features from genuinely high-level ones. However, neither an autointerp-based semantic description nor causal steering utility fully resolves the abstraction level of a feature. To this end, we introduce \emph{Feature Nonlocality} (FNL), defined as the entropy of the normalized per-position influence on an SAE feature's activation. We report that FNL correlates with existing LLM-based proxy metrics of feature semantic abstractness, and successfully distinguishes context-dependent reasoning features from token-driven ones, correctly assigning the higher FNL to the contextual feature in $73$--$84\%$ of randomly drawn pairs that consist of one contextual and one token-level feature.   We demonstrate two downstream applications. We audit SAE-based features used for jailbreak mitigation and find surprisingly that most effective features are positional features with low FNL rather than genuinely recognizing harmful intents.   We report that steering high-FNL features in DeepSeek-R1-Distill-Llama-8B improves MATH-500 accuracy by $4.6$ points over the unsteered model and outperforms steering low-FNL features, though the gains are model-specific. We conclude that FNL provides an LLM-independent, label-free, correlational witness of the abstraction level of an SAE feature, with applications in evaluating mechanistic explanations as well as selecting features for downstream interventions.

## 论文中文总结：通过非局域性度量 SAE 特征的语义抽象性

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：稀疏自编码器（Sparse Autoencoders, SAEs）是当前可解释性研究（Mechanistic Interpretability）中用于提取大语言模型（LLM）内部可解释特征的主流工具。基于 SAE 特征的因果干预（steering）已被证明能可靠地修改模型行为，如真实性、拒绝回答、推理能力和人格特征。
- **核心问题**：一个特征“可被用于干预”并不等于“机制上被理解”。例如，某个特征能触发模型回溯（backtracking），其既可能是“检测到不确定性”的抽象特征，也可能只是提高了“Wait”这个词的生成概率。现有特征筛选方法（如关键词过滤、对比数据集筛选、自动解释 auto-interp）均无法可靠地区分**表层词元级特征**（token-level）与**真正高层的语义特征**（high-level contextual），从而阻碍了对模型机制的准确评估。
- **核心贡献**：本文提出一种名为**特征非局域性（Feature Nonlocality, FNL）** 的新度量，通过计算 SAE 特征激活对输入序列各位置的影响熵，以无标签、不依赖 LLM 评判的方式量化特征的“上下文触达范围”（contextual reach），从而作为特征语义抽象水平的经验性关联指标（correlational witness）。

### 2. 方法论：核心思想、技术细节与公式

- **核心定义**：给定一个作用于 LLM 第 ℓ 层残差流的 SAE 特征 a，对其在一次前向传播中于最后一个 token 位置 T 处的激活值 za(T,P)，FNL 通过反向传播计算输入序列每个前缀位置 xt 对该激活的影响。
- **逐位置影响（per-position influence）**：定义为激活值对某一前缀位置嵌入的梯度平方范数：
  \[
  J_a(t, T, P) = \left\| \frac{\partial z_a(T,P)}{\partial x_t} \right\|_2^2
  \]
- **归一化概率分布**：对所有前缀位置归一化，得到一个合法的概率分布：
  \[
  p_a^{(P)}(t) = \frac{J_a(t,T,P)}{\sum_{t' \le T} J_a(t',T,P)}
  \]
- **FNL 定义**：该概率分布的香农熵即为每个 prompt 的特征非局域性：
  \[
  H(a,P) = -\sum_{t=1}^{T} p_a^{(P)}(t) \log_2 p_a^{(P)}(t)
  \]
  数据集级别的 FNL 为所有触发事件上 H(a,P) 的平均值。
- **直觉解释**：词元级特征（如双字母组统计）只依赖局部前缀线索，因此 FNL 较低；而抽象的主题性特征需要广泛收集整个上下文窗口中的证据，因此 FNL 较高。
- **计算流程**：① 用数据集 D 进行前向传播，收集特征 a 的 top-k 触发事件；② 对每个触发事件，考虑其前 T 个 token 作为上下文，做反向传播计算梯度；③ 后处理得到每个事件熵，然后平均。默认参数为 k=32，T=128。FNL 可并行计算同层所有特征。
- **扩展性**：FNL 天然可以扩展到任意残差流线性子空间，如直接计算残差流向量 hT 本身的非局域性 H(hT) 作为基线。

  - DeepSeek-R1-Distill-Llama-8B（LlamaScope 及 Galichin 65k 字典）

  - FNL 计算与特征选择：OpenThoughts-114k、FineWeb-Edu、LMSYS-Chat-1M、The Pile
  - 推理基准：MATH-500、MMLU-Pro
  - 越狱安全评估：404 条 StrongReject 请求 + Few-Shot-JSON wrapper 攻击
- **实验场景与对比方法**：
  1. **跨数据集稳定性**：衡量同一特征在不同语料上的 FNL 排名一致性（Spearman 相关）。
  2. **深度依赖**：观察 FNL 随网络层数加深的变化趋势。
  3. **特征几何**：检验解码器余弦相似度相近的特征是否 FNL 范围也相近。

  6. **FNL 引导 steering**：按 FNL 排名选取 top/bottom 20% 特征做包络引导（envelope steering），对比低 FNL、随机特征、单特征（ReasonScore 选取的 f3466）以及无引导基线。

### 6. 主要结论与发现

1. **FNL 是稳定的特征属性**：跨 WikiText/GSM8K/Code-Python 三个语料，特征 FNL 的排名高度一致（Spearman ρ ≈ 0.71–0.92）；随着网络加深 FNL 呈上升趋势并在中层饱和，暗示深层更偏向提取上下文语义信息。
2. **FNL 与语义抽象性显著相关**：
   - 与 token 注入恢复度 d 呈显著负相关（ρ = −0.39 至 −0.46），说明高 FNL 特征不轻易被词元线索触发。
   - 与释义保留度 Sa 呈正相关（ρ = +0.27，p = 0.011）。
   - 在随机配对中，能以 73%–84% 的概率（AUC 0.73–0.84）正确地将高 FNL 判定给上下文特征而非 token 级特征。
3. **FNL 具有独立的筛选价值**：与 ReasonScore 相关性极低（ρ = −0.214），说明它不是 token 频率统计的“伪装”，两者携带不同的信息。
4. **越狱缓解机制的重要发现**：CC-Delta 筛选出的 25 个有效防御特征中，21 个（84%）为非局域性为 0 的纯位置特征（BOS/attention sink），只有 4 个是内容感知特征。Steering 实验表明，位置特征子集贡献了绝大部分的 OOD 防御效果，内容子集几乎无效。这说明该类防御并非“识别有害意图”，而是利用了位置线索。
5. **FNL 引导的 steering 效果**：在 DeepSeek-R1-Distill-Llama-8B 上，高 FNL 包络引导使 MATH-500 准确率提升 4.6 分（0.865→0.911），超过低 FNL（+3.8）、随机特征（+3.6）和单一 ReasonScore 特征（+3.9）。但该提升是模型特异的，在其他模型上不成立。

### 7. 优点

- **方法简洁且优雅**：FNL 只需要前向/反向传播和熵计算，不依赖任何标注数据、对比数据集或 LLM 判定器，理论定义干净。
- **概念创新性强**：将“特征的上下文物理解范围”量化为一个标量，打通了局部词元特征与全局语义特征之间的可量化桥梁；受全息对偶（holographic duality）启发的概念类比也颇具深度。
- **验证体系多维且严谨**：从跨语料稳定性、深度剖面、特征几何、与已有代理指标的统计关联、到下游应用（越狱审计、steering），形成了一条完整的证据链；使用 bootstrap 置信区间和去衰减相关来校正测量误差。
- **对可解释性实践有直接指导意义**：越狱审计揭示了此前的机制解释可能建立在位置伪影上，具有重要的安全警示价值；FNL 还可作为特征筛选的新维度。
- **可复现性出色**：代码已开源，遵循 Agentic Publication Protocol，所有图表可在 CPU 分钟内复现，并详细记录了种子、超参和硬件配置。

### 8. 不足与局限

- **相关性而非因果性**：FNL 与语义抽象性的关系是统计关联（correlational witness），并未证明 FNL 是抽象性的充分或必要条件；存在未观测的混淆变量（如激活幅度、特征频率）的可能性。
- **计算成本仍然较高**：字典级 FNL 扫描需 7–8 小时（4×H200），对更大模型（如 70B+）或更大字典的可扩展性存疑。
- **FNL 引导 steering 的外部效度有限**：高 FNL 特征提升推理准确率仅在 DeepSeek-R1-Distill-Llama-8B 上成立，在 Gemma-2-9B（基础模型）和 Qwen3-8B 上均低于基线；论文虽明确声明“proof of concept”，但从高 FNL 到“值得引导的特征”的推断仍有较大鸿沟。
- **统计显著性有限**：释义不变性的相关性仅为 ρ = 0.27（p = 0.011），属于弱相关；跨数据集排名一致性随层深下降；高层 FNL 的区分度也低于中层（AUC 0.73 vs 0.84）。
- **定义中的运算选择未系统比较**：如式（5）换成 softmax、式（6）换成 Rényi 熵的替代效果没有进行比较，可能影响鲁棒性结论。
- **评价基准偏窄**：抽象性验证集中于推理类特征（token 注入、释义），对情感、事实性、人格等其它抽象维度的推广尚未验证；越狱审计仅针对单一模型（DeepSeek-R1-Distill-Llama-8B）和单一 wrapper 攻击。
