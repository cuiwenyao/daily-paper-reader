## 摘要
一阶概念综合要求系统推断出一个公式，该公式能在多个有限关系结构上一致地对标记对象进行分类。每个候选都可以被精确评估，但量化的一阶公式构成了巨大的搜索空间，而LLM的输出通常在语义上有前景却不完全正确。我们引入了假设前沿，一个验证器引导的神经符号框架，它在每个训练对象上评估每个LLM公式，跨轮次保留最强验证假设，并利用其剩余错误指导后续生成。符号处理在保持锚定于LLM生成的假设的同时修复无效公式，并在不改变任何训练预测的情况下简化训练验证公式。在匹配的模型、问题集和LLM轮次预算下，假设前沿解决的问题远多于重复原始提示生成。在最终公式选择后，精确简化缩短了许多训练验证公式，同时保留每个训练预测。因此，精确符号推理既有助于解决更多归纳问题，也有助于压缩许多所得公式。

## Abstract
First-order concept synthesis asks a system to infer one formula that classifies labeled objects consistently across several finite relational structures. Every candidate can be evaluated exactly, but quantified first-order formulas form a vast search space, and LLM outputs are often semantically promising without being fully correct. We introduce Hypothesis Frontier, a verifier-guided neurosymbolic framework that evaluates each LLM formula on every training object, retains the strongest verified hypothesis across rounds, and uses its remaining errors to guide subsequent generation. Symbolic processing repairs invalid formulas while remaining anchored to the LLM-generated hypothesis, and simplifies train-valid formulas without changing any training prediction. Under matched models, problem sets, and LLM-round budgets, Hypothesis Frontier solves substantially more problems than repeated original-prompt generation. After the final formulas are selected, exact simplification shortens many train-valid formulas while preserving every training prediction. Exact symbolic reasoning therefore helps both to solve more induction problems and to compress many of the resulting formulas.

## 2. 方法论：Hypothesis Frontier 框架

### 2.1 核心思想

> **"LLM 公式不必一开始就正确才有用"**——通过精确反馈，一个不完美的公式可以成为符号方法测试、修复、保留和简化的假设。

### 2.2 循环流程

```
LLM 提议 → 精确验证 → 修复/简化 → 前沿选择 → 下一轮提议（携带前沿与剩余错误）
```

- 每个 LLM 公式在**每个训练对象**上被精确执行
- 无效公式进入**残差引导修复**；训练有效公式进入**验证简化**
- 确定性训练集排名选出**累积前沿（frontier）**，保证进度不丢失
- 下一轮 prompt 包含：当前前沿公式、有效性状态、误分类对象明细

### 2.3 残差引导修复（Residual-Guided Repair）

- **残差定义**：
  - `FP(ϕ) = {(W,a) : W |= ϕ[a], a ∉ TW}`（假阳性）
  - `FN(ϕ) = {(W,a) : W ⊭ ϕ[a], a ∈ TW}`（假阴性）
  - 残差大小 `m(ϕ) = |FP| + |FN|`
- **三种候选生成器**：
  1. **结构束（structural beam）**：布尔规范化与因式分解、子树删除、量词体剪枝、约束松弛、公式/存在量词见证的守卫
  2. **选择器生成器**：在训练对象上评分紧凑条件及其否定，生成限制器 `r(x)`（拒绝假阳性）和扩展器 `e(x)`（覆盖假阴性）
  3. **多术语生成器**：当单一条件无法覆盖残差时，将多个选择器组合为合取/析取补丁
- **修复形式**（始终以父公式为组件，不独立合成）：
  - `ϕ ∧ r`、`ϕ ∨ e`、`(ϕ ∧ r) ∨ e`、`(ϕ ∨ e) ∧ r`
- **接受条件**：每个后代必须被精确执行——达到训练有效、降低残差、或同等残差下更简单

### 2.4 验证简化（Verified Simplification）

- **适用范围**：仅限训练有效公式，无效公式留在修复流程
- **接受规则**：候选 `ψ` 仅当 `p_W(ψ) = p_W(ϕ₀)`（所有训练对的真值向量完全一致）且 `c(ψ) <lex c(ϕ)`（AST 大小、量词深度、等式数量字典序更小）时才能替换
- **编辑操作**：布尔删除与因式分解、量词剪枝与合并、等式简化、复用已有子公式
- **最终精确简化**：在搜索结束后运行，有界束搜索，只改变报告公式，不影响 prompt、停止或 LLM 调用

### 2.5 前沿选择与后续提议

- **字典序排名**：可执行 > 可解析 > 训练有效 > 更小残差 > 更小 AST > 更浅量词深度 > 更少等式
- 来源（LLM 或符号）和轮次不影响排名
- 后续 prompt 保留原始问题，锚定 Round 1 公式，提供 `F_{r-1}` 的有效性、残差计数、AST 大小、量词深度和误分类对象
- 最多 6 轮 LLM 调用，可提前停止

## 7. 主要优点

1. **验证器深度集成**：验证不只是打分，而是**转变公式本身和下一轮搜索状态**，这是方法论核心创新
2. **确定性前沿保证**：进度只增不减，后续更差的输出不会覆盖已验证的最强公式
3. **符号编辑锚定于 LLM 假设**：修复/简化都是父代派生编辑，不替换为独立合成的答案

6. **符号优先级联实用**：先跑 Z3 再跑 LLM 的实际工作流减少调用、提高有效性
7. **公式质量分析深入**：将 AST 大小与植入参考比较（Acc@gold），揭示"概念恢复"所需的条件

## 9. 总体评价与启示

### 9.1 论文定位

本论文提出了一种**可复用的神经-符号集成架构**，其核心贡献不在于某个单一算法，而在于将“验证器”从评估者提升为搜索过程的**协同驾驶者（co-pilot）**。相比纯 LLM 生成或纯符号合成，Hypothesis Frontier 在有限预算内显著提升了训练精确推论的完成率，并证明了符号推理的三种互补角色（独立综合、修复、简化）可以系统性地协同。

### 9.2 对 LLM 推理与程序合成社区的启示

- **“不完全正确”的生成物具有修复价值**：LLM 的草稿即使整体错误，也往往逼近真解；符号编辑可以将错误转化为可执行的假设，这是单纯重新采样无法企及的。
- **可验证领域的搜索状态应当显式化**：将公式谱系、残差明细和已验证简化结果注入后续 prompt，实质上是在构建一个更丰富的“推理状态”，比仅提供正确答案或错误信号更有利。
- **符号搜索的剪枝策略受 LLM 输出分布启发的潜力**：本文的修复编辑实际上是一种**语法约束的引导搜索**，如果能够将 LLM 的候选分布纳入符号搜索的启发式打分中，可能进一步缩小搜索空间。

### 9.3 局限总结

总体而言，论文的贡献是扎实的，但实验规模、任务复杂度和分析深度仍有限。机制层面的结论多为观测性，符号优先工作流未做到公平的算力对齐，公式质量的评估也依赖人工生成的参考概念。这些不足暗示了后续研究的方向：更复杂的逻辑语言、部分观测与噪声环境、在线学习设定，以及将验证器反馈用于 LLM 微调而非仅 prompt 编排的可能性。

## 10. 总结

Hypothesis Frontier 通过将 LLM 的一阶公式设想与 Z3 精确验证、定向修复和语义保持简化相结合，显著提高了在有限结构上完成概念合成的成功率。在 9 个受控配置对比中，它全部超过重复生成基线，平均训练有效比例提升 24–30 个百分点，同时减少了 LLM 调用。该工作最重要的方法论启示是：**即使 LLM 不能一次性给出正确答案，其错误候选也能通过与精确验证器的密切协作，被转化为可验证、可累积、可泛化的符号解**。尽管实验范围有限，但它为神经符号搜索的工程实践提供了清晰且可复现的蓝本。
