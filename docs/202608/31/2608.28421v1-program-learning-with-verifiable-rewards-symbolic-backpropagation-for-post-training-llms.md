## 摘要
对语言模型进行后训练以使其具备推理能力意味着更新其权重。监督微调和强化学习都将所获得的能力置于模型内部，在那里无法检查、无法逐步验证，也无法迁移到另一个模型。我们认为，对于中间步骤可验证的任务，推理更适合置于基础模型权重之外，作为由确定性和神经原语组成的显式程序。我们提出PLVR（可验证奖励的程序学习）：一种后训练方法，直接从输入-输出示例中学习此类程序。其机制是符号反向传播：每个程序层携带一个类型化本体，在输出端根据真实值计算损失，并通过基于原语签名的类型推断向后传播所需的输入本体：这是链式法则的类比，其中信用分配是一种推导而非估计。RLVR验证终端结果，而PLVR的奖励是每一步的合约判定，密集覆盖程序结构。在LiveCodeBench v6和Tau2Bench上，使用PLVR的30B基础模型在相同预算下平均优于RL 27.8个百分点，优于大一个数量级的先进模型13.6个百分点。一个单一的原语库即可服务于两个基准测试，因此新任务的边际成本是100个程序搜索示例，且无需新的微调数据。在相同预算下，用均匀采样替代损失引导的搜索，在相同的类型允许空间内，将中位程序从65.6坍缩到17.5，这表明优势来源是反向传播而非类型系统。我们发布符号反向传播库和一致性检查器，以便该方法可应用于我们之外的原语库。

## Abstract
Post training a language model to reason means updating its weights. Supervised finetuning and reinforcement learning both place the acquired capability inside the model where it cannot be inspected cannot be checked step by step and cannot be moved to another model. We argue that for tasks whose intermediate steps admit verification, reasoning is better placed outside the base models weights as an explicit program composed from deterministic and neural primitives. We introduce PLVR (Program Learning with Verifiable Rewards): a post training method that learns such programs directly from input-output examples. Its mechanism is symbolic backpropagation: each program layer carries a typed ontology a loss is computed at the output against ground truth and required input ontologies are propagated backward by type inference over primitive signatures: an analogue of the chain rule in which credit assignment is a derivation rather than an estimate. Where RLVR verifies a terminal outcome, PLVRs reward is a per step contract verdict dense over program structure. On LiveCodeBench v6 and Tau2Bench, 30B base models with PLVR outperform RL at matched budget by 27.8 points on average and frontier models an order of magnitude larger by 13.6 points. A single primitive library serves two benchmarks, so the marginal cost of a new task is 100 examples of program search and no new finetuning data. Replacing the loss guided search with uniform sampling over the same type admissible space at equal budget collapses the median program from 65.6 to 17.5, identifying the backward pass rather than the type system as the source of the advantage. We release the symbolic backpropagation library and a conformance checker so the method can be applied to primitive libraries other than our own.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现有的 LLM 后训练方法（SFT 与 RL）都将推理能力隐式地编码进模型权重中，由此带来三个固有缺陷：
  - **不透明**：权重中没有可检查的逐步骤推理信息，无法得知模型在哪个步骤得到了改进；
  - **过程不可验证**：只能对完整轨迹进行端到端评分，无法在中间步骤验证正确性；
  - **不可迁移**：针对某个模型（如 12B checkpoint）学到的能力无法直接转移到另一模型（如 30B）上。
- **整体命题**：对于中间步骤可以被检查的任务（如工具调用、程序生成、策略约束对话），推理过程应**显式地置于模型权重之外**，表示为由确定性和神经原语组成的**可验证程序**，而非隐式地存在于权重之中。这类似于用程序化检查替代学习式奖励（RLVR 的精神），并将其向内部扩展为密集的逐步骤合约验证。
- **核心隐喻**：论文提出一个可检验的猜想——**在类型化、合约验证的原语上运行程序构造过程，优于在原始模型调用上运行同一过程**。

## 2. 方法论：PLVR 与符号反向传播

- **总体框架**：PLVR 将程序组织为 N 层，每层携带一个**类型化本体（ontology）**——一个结构化的、类型化的状态表示，既是程序的中间状态（类似调试器断点），也是类型推导与损失计算的载体。
- **本体与损失**：
  - 对象为类型化记录，可嵌套（`Ω = K ⇀ Obj`），本体是键控对象集合。
  - 损失 `L(Ω_pred, Ω_tgt)` 按目标键域计算：类型错误（整数计数）排在值错误（L2 范数）之前，采用**字典序比较**。内容对齐（content alignment）而非键对齐（key alignment）。
  - 代码对象的对齐策略为测试通过率（TESTS），工具调用为部分匹配（PARTIAL）；聚合后以 `(type count, val L2)` 作为得分。
- **原语与运算符**：
  - 10 个原语（如 DENOTE, ELABORATE, DECOMPOSE, MATCH, GET-ORDER, CHECK-PREREQUISITES 等），分为提升、状态、结构、绑定、结构性五类；既有完全确定性实现，也有“神经+符号”混合实现。
  - 运算符（SEQUENCE, PARALLEL, BRANCH, FOREACH, LOOP, FALLBACK）是更高阶的组合子，携带类型规则而无输出合约。
- **符号反向传播（核心机制）**：
  - 正向传播执行程序并得到输出损失；反向传播则传播**所需本体（required ontologies）**而非梯度。
  - 给定第 i 层所需本体与各原语签名，通过**类型推断（一阶统一）**得出第 i−1 层必须提供的输入本体；该推导是确定性的，类似于链式法则中上游梯度的作用。
  - **类型解析**与**值解析**分离：类型解析确定且可穷举；值解析在声明范围内的有限搜索中寻找最小化值损失的参数，**合约判定（contract verdicts）**在值解析中剪枝并定位失败步骤，因此信用分配是一种**推导**而非**估计**。
- **训练循环**：交替进行——在固定原语下的程序搜索（beam search）与在固定程序下的原语重训练。基础模型权重**永不更新**；学到的是显式程序以及被调用的小型神经原语的权重。

## 6. 主要结论与发现

- **性能显著超越**：在匹配预算下，PLVR（以 Muse Glimmer 30B 为例）相对三个 RL 基线在共同列上平均高 **27.8 分**，相对五个前沿模型 vanilla prompting 平均高 **13.6 分**；最强的 PLVR 配置（Inkling 975B 上）平均 83.1 分。
- **消融证明核心机制有效**：用均匀采样替换损失引导搜索（保持相同类型合法空间和预算）后，程序池中位数从 **65.6% 坍缩至 17.5%**；45% 的引导搜索程序超过 70%，而随机样本只有 2%。差距源于**反向传播（得分引导）**而非**类型系统**（两者共享）。
- **收敛可靠且快**：在 109 个排列上平均，**70 个示例以内即可可靠识别最优程序**；但单次训练运行（unshuffled）直到 n = 100 才收敛——报告的单个精度曲线（n = 10 即平台化）可能掩盖识别未完成的情况。
- **迁移良好**：在 60 个示例上选择的程序在 73 个未见示例上仅下降 4.7 分，且工具调用（BFCL）几乎无衰减（74.7 → 74.6，池内平均降 8.3）。这暗示类型优先的字典序损失倾向于选择结构性而非偶然正确的程序。
- **关键洞察**：类型系统使候选良构，但**束搜索使搜索有限**（1e27 个类型正确程序 vs 实际评分 14,400 个）；程序发现持续到训练结束，即使最优精度已经平台化。

## 7. 优点与亮点

- **外显推理的可检查性**：程序是显式、可检查、可迁移、可逐步验证的构件；基础模型权重不被更新，能力注入到可审计的工件中。
- **符号反向传播的独创性**：将信用分配从"估计"转变为"推导"——类型解析确定性完成，值搜索受声明范围约束，合约判定逐步骤定位失败。避免了文本梯度随深度累积误差的问题。
- **密集可验证奖励**：将 RLVR 的终端稀疏奖励扩展为逐步骤的合约判定，是"可验证奖励"维度的自然延伸，且不引入学习式过程奖励模型。
- **严格的消融与统计方法**：对随机采样无效假设进行预先注册；报告排列分布而非单个训练顺序；对问题集使用 bootstrap；明确区分"搜索时得分"与"报告时评估"配置。
- **原语库的可复用性**：一个原语库（19,627 个合成示例）即可服务两个基准，新任务的边际成本约为 100 个搜索示例，无需新的微调数据。
- **开源与可扩展**：发布符号反向传播库和一致性检查器，可应用于任何满足接口的原语库。

## 8. 不足与局限

- **适用性有限**：方法仅适用于中间步骤可验证的任务（前提是必要条件，而非可选的改进）；对于摘要、开放式生成等判断性任务不适用，论文明确不对此作任何声明。
- **未与 SFT 比较**：只与 RL 后训练比较（作者声明 RL 是更强的目标），不与 SFT 比较。
- **消融不完整**：损失函数设计和反向传播机制在所有臂中固定不变，未单独隔离分析；论文承认"在固定搜索条件下改变损失"的消融实验并未进行。鲁棒性选择（类型优先）的证据是单一选定程序的观察而非受控实验。
- **实验覆盖有限**：主对比仅两个基准（以及迁移用的一小部分 BFCL）；τ² Retail 上领先幅度很小（2.6 分），三组运行无法确认；部分检查点（DeepCoder 不用于 τ²；Nemotron 缺 LCB 数值）造成平均值的列不完整。
- **RL 基线比较的偏差风险**：是在**不同训练数据规模、不同参数规模、不可控的检查点质量**上进行的间接比较；作者选择了发布的数据量足够大的检查点，但仍然无法排除基线未充分训练的可能性。
- **统计功效受限**：每臂仅 3 次运行，且部分（如 Airline）50 个问题导致的置信区间过宽，无法分辨约 13 分以内的差距。
- **泛化性无保证**：程序在训练分布上良构并不保证对未覆盖的分支路径有静态安全性——尽管部署时若产生非类型化输出，合约会触发并定位故障原语（失败可检测、可定位，而非静默传播）。
