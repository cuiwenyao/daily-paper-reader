## 摘要
设计、实现和比较可解释架构需要一种形式化语言来表示它们。最常见的表示方法在两个方面存在不足。符号方程无法提供架构的全局视图。概率图模型和流程图不描述实际的张量操作，因此隐藏了关键见解并限制了可复现性。为了弥补这一差距，我们引入了一种用于设计可解释AI架构的图形化符号，改编自Penrose张量符号。这种图形化符号提供了架构的全局视图，并一一映射到PyTorch einsum代码。我们首先使用这种符号来描述通过构造可解释的架构，包括概念瓶颈、稀疏探针、原型网络、神经加性模型和线性模型混合。然后，我们绘制了前沿可解释语言模型Steerling-8B的关键架构组件的图示。该图提供了对架构的全局洞察（例如，显示Steerling是一个残差模型）、每个单独操作的几何解释，以及直接转换为33行PyTorch代码。

## Abstract
Designing, implementing, and comparing interpretable architectures requires a formal language to represent them. The most common representations fall short in one of two ways. Symbolic equations give no global view of an architecture at a glance. Probabilistic graphical models and flowcharts do not describe actual tensor manipulations, thus hiding key insights and limiting reproducibility. To close this gap, we introduce a graphical notation for designing interpretable AI architectures, adapted from Penrose tensor notation. This graphical notation gives a global view of an architecture and maps one to one onto PyTorch einsum code. We first use this notation to describe architectures that are interpretable by construction, including concept bottlenecks, sparse probes, prototype networks, neural additive models, and mixtures of linear models. We then diagram the key architectural components of Steerling-8B, a frontier interpretable language model. The diagram yields global insights into the architecture (e.g., showing that Steerling is a residual model), a geometric interpretation of each individual operation, and a direct translation into 33 lines of PyTorch code.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 图形化符号的基础定义

- **张量的图形化表示**：每个张量用一个圆（或节点）表示，圆周上的“腿”（legs）代表张量的一个维度（即索引）。例如：
  - 标量：无腿；
  - 向量：1 条腿；
  - 矩阵：2 条腿；
  - 3 阶张量：3 条腿，以此类推。
- **张量操作的图形化规则**：
  - 连接两个张量的腿表示对共享索引进行**收缩（contraction）**：先逐元素相乘，再对该索引求和；
  - 未连接的“自由腿”即为输出张量的维度；
  - 操作方向约定为从左到右（或从上到下），输入节点用灰色绘制以便区分。
- **与 PyTorch einsum 的映射**：每个图形化操作可直接写成 `einsum` 代码，例如：
  - `einsum('i,i->', a, b)` 对应向量点积；
  - `einsum('ij,i->j', A, b)` 对应矩阵-向量积；
  - `einsum('ij,ik->jk', A, B)` 对应矩阵-矩阵积。
- 论文建立了一个“**罗塞塔石碑（Rosetta stone）**”表格，将**图形、PyTorch 代码、几何含义、代数表达式**并列展示，涵盖以下基础操作：
  - 标量乘法、逐元素积、点积、平方范数、归一化、凸组合、余弦相似度、矩阵切片求和、矩阵-向量积、缩放矩阵切片、矩阵-矩阵积。

### 2.2 简单神经网络示例

- **线性模型**：矩阵-向量积 + 激活函数，图形符号直观展示输入与权重矩阵切片的仿射关系。
- **多层感知机（MLP）**：多个线形层堆叠，图形符号清晰展示嵌入表示在层间流动。
- **自注意力（Self-attention）**：
  - 将输入序列 Z 复制三份，分别乘以权重矩阵 W_q、W_k、W_v 得到 query、key、value；
  - 计算 query 与 key 的相似度得到 logits；
  - 使用 softmax 归一化得到注意力概率；
  - 以概率为权重对 value 做凸组合，得到更新后的 token 嵌入；
  - 图形分解为若干原子操作，每一步对应一段 einsum 代码，最终可合并为完整框图。
- 为适应更复杂模型，论文采用 **ellipsis 符号**表示任意 batch 维度，使图形符号可以扩展到多头、多批次等场景。

### 2.3 可解释架构中的典型模块

论文将可解释架构划分为三部分：**骨干网络（backbone）**、**概念编码映射（concept encoding map）**、**概念组合映射（concept composition map）**，并针对每个部分中的常见操作绘制图形符号：

- **概念编码映射**：
  - **稀疏编码器/稀疏探针**：`c = sigma(einsum('d,dk->k', z, W))`，将隐藏表示 z 映射为稀疏概念激活 c（k >> d）。
  - **概念瓶颈（Concept Bottleneck）**：操作形式与稀疏编码器相同，但训练时使用监督概念标签，即概念语义内置于损失中。
  - **概念嵌入瓶颈（Concept Embedding Bottleneck）**：先生成高阶概念嵌入 u ∈ R^(d×k×s×e)，再经评分矩阵 S 得到概念预测 logits。
  - **原型网络（Prototype-based Concept Map）**：将输入嵌入与原型矩阵 P 做余弦相似度，经过 softmax 得到原型概率，再与真实原型标签 π 做凸组合得到概念预测。
- **概念组合映射**：
  - **神经加性模型（Neural Additive Models）**：每个概念独立经过一个 MLP，然后对概念维度求和得到任务预测。
  - **概念嵌入预测器（Concept Embedding Predictor）**：用概念激活 c 缩放概念嵌入 u，再经线性映射得到输出 logits。
  - **线性模型混合（Mixture of Linear Models）**：通过路由概率选择多个线性模型的预测结果，再进行加权求和。
- 每种操作都同时给出**图形表示、einsum 代码和代数解释**，确保图形符号能够精确指导实现。
