## 摘要
尽管大型语言模型（LLMs）在标准化图任务中具有潜力，但它们对于节点标识符和任务表述的真实世界变化仍然脆弱。虽然确定性图工具对此类变化具有不变性，但从嘈杂文本中提取拓扑结构对LLMs而言高度不稳定，它们往往过度拟合表面模式。此外，通过多智能体系统缓解这些解析失败会带来高昂的延迟。为解决这一问题，我们提出了GRAIN，一个通过强化学习优化的单智能体框架。GRAIN将推理建模为语义解析和工具执行流水线，并由结构不变性奖励引导。通过将提取的中间图与真实拓扑进行验证，该奖励迫使LLM学习稳健的文本到结构映射，而非记忆语言伪影。我们还引入了GRIT，一个评估对此类语言变化敏感性的基准。GRAIN在准确性上以约24%的更低延迟超越多智能体基线16.45\%。此外，它展示了优越的结构泛化能力，将SFT模型的分布外（OOD）差距减半（从15.77\%降至7.80\%），并在训练分布之外的大规模图上保持鲁棒性。

## Abstract
Despite their potential in standardized graph tasks, Large Language Models (LLMs) remain brittle to real-world shifts in node identifiers and task formulation. While deterministic graph tools are invariant to such shifts, extracting topological structures from noisy text is highly fragile for LLMs, which often overfit to surface patterns. Moreover, mitigating these parsing failures via multi-agent systems incurs prohibitive latency. To address this, we propose GRAIN, a single-agent framework optimized via reinforcement learning. GRAIN models reasoning as a semantic parsing and tool-execution pipeline, guided by a Structure Invariance Reward. By validating extracted intermediate graphs against ground-truth topologies, this reward forces the LLM to learn robust text-to-structure mappings rather than memorizing linguistic artifacts. We also introduce GRIT, a benchmark evaluating sensitivity to such linguistic shifts. GRAIN outperforms multi-agent baselines by 16.45\% in accuracy with approximately 24\% lower latency. Furthermore, it demonstrates superior structural generalization, halving the out-of-distribution (OOD) gap of SFT models (from 15.77\% to 7.80\%) and maintaining robustness on large-scale graphs beyond the training distribution.

- **核心问题**：大型语言模型（LLM）在标准化图任务上表现尚可，但对真实世界中的**两类表面变化**高度脆弱：
  - **节点标签敏感性**（Node-label sensitivity）：改变节点命名方案（如随机 ID 替换语义名称）会导致性能剧烈波动，即使底层图结构完全相同。
  - **任务表述敏感性**（Task-form sensitivity）：从合成模板表述切换到真实世界叙事（如物流路由、社交网络描述）时，性能显著下降。
- **深层原因**：LLM 在"从噪声文本中提取拓扑结构"这一环节上高度不稳定，倾向于**过拟合表面语言模式**（如特定的命名规律、模板句式），而非学习真正的结构语义。确定性图工具算法本身对这些变化具有不变性，瓶颈在于 LLM 的语义解析环节。
- **现有方案的不足**：
  - 多智能体系统（如 MA-GTS）虽能缓解解析失败，但多轮交互带来**高昂延迟和令牌成本**，难以实时部署。
  - SFT 方法容易过拟合表面模式，在结构同构变化、图规模扩大等分布外场景下泛化能力差。
- **研究意义**：该工作试图弥合"干净基准"与"真实应用"之间的鲁棒性鸿沟，使 LLM 在图推理中学习**不变的拓扑规则**而非记忆表面形式，同时保持单智能体的效率。

## 2. 方法论：GRAIN 框架

### 2.1 核心思想

GRAIN（**G**raph **R**easoning **A**gent with **IN**variance）将图推理显式分解为**"语义解析 + 算法执行"**两阶段流水线：

- LLM 只负责其擅长的**自然语言理解与结构抽取**（从噪声叙事中解析出图结构）。
- 将计算任务（最短路、TSP、着色等）**外包给确定性图工具库**，保证算术/算法正确性。
- 通过**结构不变性奖励**（Structure Invariance Reward）驱动强化学习，强制模型学习"文本 → 拓扑结构"的稳定映射。

### 2.2 推理流水线（四个结构化阶段）

模型输出分为四个带标签的段：

1. **`<think>`**：任务理解与规划，识别任务类型、抽取实体、规划算法调用。
2. **`<graph>`**：输出结构化 JSON 表示（节点集、边、权重、任务参数），由运行时解析为工具输入。
3. **`<result>`**：工具执行结果注入回上下文，模型可继续推理或直接作答。
4. **`<answer>`**：最终答案。

### 2.3 门控奖励设计（核心公式）

总奖励采用**硬门控**结构（式 3）:

\[
R(\tau) = 
\begin{cases} 
\rho_{\text{err}}, & \text{if invalid (格式违规)} \\
r_{\text{ans}}(\tau) + \lambda_{\text{inv}} s_{\text{inv}}(\tau), & \text{if valid}
\end{cases}
\]

- **`r_ans`（答案奖励）**：检查最终答案是否正确（路径长度、TSP 代价等）。
- **`s_inv`（结构相似度）**：将预测图与真实图的规范化同构边集计算 **Jaccard 指数**（连续值 ∈ [0,1]），对拓扑恢复提供稠密的部分奖励信号。相比矩阵余弦相似度，不会因幻觉节点产生维度错误；相比图编辑距离（GED），计算高效（非 NP-hard）。
- **格式违规直接给予惩罚 `ρ_err`**，而非软性正则化，强制模型遵守工具调用协议。

### 2.4 强化学习：ARPO（Agentic Reinforced Policy Optimization）

- **阶段一（SFT 热身）**：在小子图（|V|≤14）上自动生成专家轨迹，教授标签语法和基本建图能力，作为 RL 初始化策略 `π_ref`。
- **阶段二（RL 优化）**：优化目标为带 KL 约束的期望奖励（式 4），采用 ARPO 算法，其关键机制：
  - **熵驱动的自适应部分展开**：当模型在实体消解/建图决策时出现 token 熵尖峰（高不确定性），自动触发分支式采样，探索多种图构建假设。
  - **分支感知优势估计**：对共享前缀的轨迹标准化回报，前缀 token 共享优势（任务理解），分支后缀 token 获得各自优势（图构建），使结构奖励精确作用于高熵决策点。

## 6. 主要结论与发现

1. **性能 SOTA**：GRAIN 在 Qwen-3-Base 上达到 **95.76%** 宏平均准确率，超过强 SFT 基线（89.10%）6.66 个百分点；将 Llama-3.2-Instruct（<5%）提升至 47.41%。
2. **超越多智能体**：比 MA-GTS（GPT-4o-mini）准确率高 **16.45%**，同时延迟降低约 **24%**，令牌消耗仅 3.3k（约为 GPT-5-nano 的 1/5）。
3. **鲁棒性显著提升**：在 8 种命名/表述视图下性能近乎均匀（图 4），而 SFT-Tool 在 Random/Mixed 命名下明显坍塌。
4. **OOD 泛化减半**：OOD 精度差距从 SFT-Tool 的 15.77% 降至 **7.80%**；在 GraphInstruct 和 GraphArena 上分别达到 97.05% 和 91.0% 零样本准确率。
5. **长度泛化**：|V|>40 时基线急剧退化，GRAIN 保持稳健，证明"解析-执行"解耦能有效隔离计算复杂度。
6. **结构恢复质量高**：精确图恢复率达 97.28%（Edge-F1 98.67%）；移除结构奖励后精确恢复率暴跌至 63.10%。
7. **ARPO 有效**：相比 GRPO，准确率提升（96.51%→96.76%）且方差降低（7.05→4.64）。

## 7. 优点

- **问题定义清晰**：将"命名敏感性"和"表述敏感性"作为可量化的诊断维度，设计受控的同构多视角评测，定位准确。
- **奖励设计巧妙**：门控结构将格式约束设为硬条件；Jaccard 边集相似度兼顾计算效率与稠密反馈，避免了矩阵相似度的维度问题和 GED 的计算爆炸。
- **单智能体效率优势**：将多智能体协作的能力蒸馏进单一策略权重，同时获得高准确率和低延迟，兼顾精度与部署可行性。
- **数据构造严谨**：GRIT 采用确定性模板注入而非 LLM 生成，从根源上消除文本-图不同构的污染；OOD 划分显式隔离未见场景。
- **诊断深度**：对 MA-GTS 的失败做端到端管道健康分析（原生调用覆盖率、终止失败率、条件准确率），揭示了"推理外解多智能体化不能自动修复接地失败"的深刻洞见。
- **验证全面**：中间结构误差分解、图复杂度分层分析、跨基准迁移测试，形成闭环证据链。

## 8. 不足与局限

- **工具上下文管理**（作者自述）：将大量图算法定义静态嵌入系统提示，导致上下文长度膨胀、可能分散模型注意力；未来需引入 MCP 等动态工具定义标准。
- **评测覆盖有限**：
  - 图类型局限于**连通无向图**（作者在附录 H 中承认），未验证有向图、带参图、动态图等更复杂拓扑。
  - LLM 的角色被限制为"解析-参数选择"，而非真正意义上的算法推理，对需要算法设计的开放任务可能不适用。
- **比较公平性问题**：MA-GTS 官方基于 GPT-4o-mini，而小模型迁移诊断中 Qwen3-4B 为**零样本**使用未训练，与经过完整训练和 warm-start 的 GRAIN 不在同一起跑线上；作者已作说明但仍存在残余争议。
- **OOD 规模偏小**：OOD Test 场景数（180）远小于 ID 测试（2,760），可能低估未见表述下的性能方差。
- **训练资源未报告**：缺少训练耗时、总 GPU 时数等关键成本信息，不利于复现

## 9. 对后续研究的启示与开放问题

GRAIN 的价值不仅体现在其自身实验结果，更在于为图推理乃至更广泛的结构化推理研究提供了可迁移的思路。

- **“解析-执行”解耦范式具有普适性**：GRAIN 证明了将 LLM 从“算法计算”中解放出来、只承担“语义到结构”的映射，是提升鲁棒性的有效手段。这一范式可自然迁移至表格推理、知识图谱问答、代码生成中的 API 调用规划等场景，凡是“自然语言 → 结构化中间表示 → 确定性求解器”的任务链，均可借鉴门控奖励与熵驱动分支采样的设计。
- **工具与上下文的动态化管理是下一步工程重点**：作者指出将算法定义静态塞入系统提示会带来上下文膨胀问题。未来可引入 **MCP（Model Context Protocol）** 或检索增强式工具库，让模型按需拉取图算法定义，既减小输入长度，又能扩展到更大规模任务。
- **图类型的拓展方向**：当前方法仅覆盖连通无向图。有向图（如依赖关系、引用网络）、带权多重边、动态图（时序演化）以及超图是自然延伸。尤其是动态图，需要模型在多次时间戳之间保持状态一致性，对“解析-执行”流水线中的状态管理提出更高要求。
- **奖励信号的进一步可解释化**：Jaccard 结构奖励虽好，但仍是图级整体度量，无法定位到具体哪一条边解析错误。未来可设计**边级过程奖励**或**基于子图分解的层次奖励**，为 RL 提供更细粒度的学习信号。
- **从“工具调用者”走向“算法理解者”**：GRAIN 中 LLM 始终是“解析器”而非“求解器”，其算法能力边界未被真正触及。后续工作可逐步退火工具依赖（如先执行后解释、再过渡到纯推理），让模型在训练中内化算法逻辑，从而应对无现成工具可调用的开放任务。
- **公平比较的设定问题**：多智能体系统（如 MA-GTS）的对比不公平性提示未来研究应建立**统一训练预算与统一工具访问权限**的基准协议，避免“训练过的单智能体 vs. 零样本多智能体”的错位评估。
- **评测集的生态化建设**：GRIT 的场景模板虽由人工设计，但覆盖仍有限。未来可利用图生成器 + LLM 辅助改写构造大规模异构场景库，并增加对“自然文本偏离图事实”的对抗性样本，进一步考验模型的接地能力。

## 10. 总体评价

GRAIN 是一项定位精准、方法论完整、验证扎实的工作。它不试图让 LLM 直接“学会”图算法，而是重新界定了 LLM 在图推理中不可替代的角色——**从噪声文本中稳定地恢复拓扑结构**，其余交给确定性工具。这一角色重定位直击了当前 LLM 图推理脆弱性的症结：模型擅长语义词法理解，却不擅长数值计算与组合优化。

其核心贡献可概括为四点：

1. **可靠的数据基建**：GRIT 通过确定性模板注入，构建了文本-图严格同构的多视角评测集，为“命名敏感性”与“表述敏感性”提供了量化基准。
2. **有效的奖励设计**：门控奖励 + Jaccard 边集相似度 + 熵驱动分支采样的组合，在稀疏答案奖励与稠密结构监督之间取得平衡，且计算代价可控。
3. **单智能体的效率优势**：以大幅低于多智能体系统的延迟和令牌成本，达到显著更高的准确率，展示了“蒸馏协作能力进单一策略”的可行性。
4. **深刻的失败分析**：对 MA-GTS 的系统诊断揭示了多智能体架构无法自动修复“接地失败”这一反直觉现象，为领域提供了宝贵的实证洞察。

当然，GRAIN 并非终结答案。它的成功建立在“工具可用且完备”的假设之上；面对无工具、有向动态图、需要算法设计的开放问题，其边界仍待拓展。但作为“LLM + 确定性工具”协同范式的代表性工作，它为图推理的鲁棒性研究树立了一个高标准的参照系，也为后续研究者留下了一系列清晰的开放问题。
