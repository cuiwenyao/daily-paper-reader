## 摘要
连续时间动态图模型通过将过去的交互压缩为神经状态来预测未来的链接。尽管在预测上有效，但这种计算掩盖了哪些实体在事件间共享，以及时间模式如何促成预测。我们将这一差距视为预测架构的一个属性，而不是预测后需要解决的问题。链接事实时间规则归纳器（LiFTER）是一种神经符号预测器，它将观察到的交互保留为基于事实的时间事实，并对预查询事实应用可执行的时间规则。每个分数是规则执行的带符号总和，其历史事实、实体绑定和时间顺序都被显式满足。因此，负责预测的证据和规则可以被检查、独立重新计算和干预。在四个CTDG基准测试中，LiFTER实现了具有竞争力的历史负样本预测，以及最高的宏解释准确性和删除保真度。相同的架构还充当显微镜，将循环、历史位置和转换的贡献跨数据集分离，并将其追溯到单个事实。独立执行重构了19,664个测试预测的所有logits，最大误差为0.0000131。LiFTER将未来链接预测转变为可验证的基于事实的计算。

## Abstract
Continuous-time dynamic graph models predict future links by compressing past interactions into neural states. Although effective for forecasting, this computation obscures which entities are shared across events and how temporal patterns contribute to a prediction. We treat this gap as a property of the predictive architecture rather than a problem to be addressed after prediction. Link-Fact Temporal Rule Inducer (LiFTER) is a neuro-symbolic predictor that preserves observed interactions as grounded temporal facts and applies executable tempo- ral rules to pre-query facts. Each score is a signed sum of rule exe- cutions whose historical facts, entity bindings, and temporal order are explicitly satisfied. The evidence and rules responsible for a prediction can therefore be inspected, independently recomputed, and intervened upon. Across four CTDG benchmarks, LiFTER achieves competitive historical-negative forecasting and the highest macro explanation ac- curacy and deletion fidelity. The same architecture also serves as a microscope that separates the contributions of recurrence, history po- sition, and transition across datasets and traces them to individual facts. Independent execution reconstructs all logits for 19,664 test predictions with a maximum error of 0.0000131. LiFTER turns future-link forecasting into a verifiable grounded computation.

## 1. 核心问题与研究动机

- 连续时间动态图（CTDG）中的链接预测通常由 TGN、TGAT、GraphMixer、DyGFormer 等神经模型完成，这些模型将历史交互压缩为记忆、时间邻域或事件序列表示。
- 这类模型虽然预测效果好，但预测 score 的生成过程不透明：**哪些历史事件被复用、哪些实体在事件间共享、时间模式如何影响预测**均被隐式编码，无法直接检查。
- 现有可解释性方法（T-GNNExplainer、TempME、TGIB、SIG）多为**事后解释**：先训练预测器，再通过子集搜索、掩码或子图生成“重要证据”。但这些证据并不能真正参与 score 计算，解释与预测是脱节的。
- 时间知识图谱（TKG）上的神经符号规则学习（如 Neural-LP、TLogic、TILP）依赖语义谓词（relation type），而 CTDG 基准通常只有一种交互类型，无法直接套用。
- 因此，论文将“不可解释”视为**预测架构本身的问题**，提出 LiFTER：把预测直接构造成“可执行、可验证、可干预”的接地时序规则计算，使预测与解释从同一前向过程中产生。

## 2. 方法论：LiFTER 的核心思想与技术细节

### 2.1 总体思想

- 将每条历史交互直接表示为接地事实：`Link(u, v, t)`，保留 source、destination、timestamp 三要素。
- 预测阶段将所有查询前事实作为“可执行事实库”，用有限规则集合对候选 query `Link(X, Y, Tq)` 打分。
- 最终 logit 是**规则执行的带符号总和**，每个非先验项都必须对应具体的历史事实、实体绑定和时间条件。
- 预测与解释是同一过程，而非两阶段；外部验证器可从原始历史重建全部 logit。

### 2.2 接地时序规则语言

- **端点绑定一元规则（Endpoint-bound unary rules）**：检查历史事实与 query 端点共享关系，共 6 种方向，如 `Pk(X,Y,T)`、`Pk(X,Z,T)`、`Pk(Z,Y,T)` 等，要求 `T < Tq`。
- **成对更新规则（Pair renewal）**：`P(X,Y,T1) ∧ P(X,Y,T2) => Link(X,Y,Tq)`，要求 `T1 < T2 < Tq`，用于捕捉同一 pair 重复出现的时间间隔。
- **位置化重复规则（Positioned recurrence）**：`Pk(X,Y,T) ∧ PosX(T)=j`，`j=1` 表示最近一次，枚举 `1≤j≤H`，让训练学习每个历史位置的重要性。
- **有序转移规则（Ordered grounded transitions）**：基于 source 最近访问的 destinations 判断下一个候选 `Y`：
  - 单事件转移：`P(X,Z1,T1)`，学习 `(Z → Y)` 的兼容性；
  - 双事件转移：`P(X,Z1,T1) ∧ P(X,Z2,T2)`，学习 ordered pair `(Z1, Z2) → Y` 的兼容性；
  - 兼容性通过低维向量内积计算，例如 `ctr,1 = (a_Z ⊙ p_k)^T b_Y / sqrt(d)`。

### 2.3 Score 计算

最终 logit：
`s(X,Y,Tq) = b + Σ_r w_r E_r + Σ_j Σ_k u_{j,k} R_{j,k} + Σ_m c_{tr,m}`

- `b`：全局先验；
- `w_r E_r`：一元与更新规则证据；
- `u_{j,k} R_{j,k}`：位置化重复；
- `c_{tr,m}`：有序转移贡献。
- 所有非先验项都关联具体事实、绑定、时间条件，**不包含隐式残差打分器**。

时间证据 `e_r(g,q)` 用 log-time gap 核函数衡量历史事件与规则偏好时间间隔的匹配程度，再通过 max（直接 pair）或 capped sum 聚合。

### 2.4 学习与高效执行

- 训练目标：提升正样本 logit，压低负样本 logit，即 `L_pred = -log σ(s+) - log σ(-s-)`。
- 同一结构模式的规则共享一部分参数，另加 clause-specific residual，避免参数爆炸。
- 可选 `K>1` 谓词词汇：通过事实编码器与 prototype 相似度选择离散谓词，使用 straight-through estimator 保持前向离散、反向可梯度。
- 高效执行：全局事件流只建一次索引，每 batch 只 gather 最近事实张量，不逐 query 扫描全量历史。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- 使用 JODIE 四个标准 CTDG 数据集：**Wikipedia、Reddit、MOOC、LastFM**。
- 取每个数据集前 32,768 个事件，按时间顺序 85% 训练、15% 测试；三个种子（7/17/27）。
- 预测任务：给定 query `Link(X, Y, Tq)`，判断 source `X` 是否会与候选 `Y` 交互。
- 负样本协议：
  - **historical negative**：从 `X` 历史交互过的 destination 中采样（排除当前正样本），考察“在历史中见过的候选”之间的排序能力；
  - **random negative**：从全局候选池随机采样。
  - 没有历史候选时用 random negative fallback，历史候选覆盖率分别为：Wikipedia 51.1%、Reddit 48.9%、MOOC 97.7%、LastFM 99.7%。

### 3.2 对比方法

- 预测基线：EdgeBank，TGN，TGAT，DyGFormer，GraphMixer，CRAFT，CRAFT-R。
- 解释基线：TGN+T-GNNExplainer，TGN+TempME，TGIB，SIG。
- 所有方法共用相同 query、相同证据库（query source 与 candidate 的最近 10 条事件）、相同选择预算，以尽量保证公平。

## 6. 主要结论与发现

- **预测性能不输神经模型**：LiFTER 在 historical-negative 协议下，Reddit 与 LastFM 的 AUC/AP 排名第一；Wikipedia 排名第二；MOOC 上 AP 第一、AUC 第二。
- 在 random-negative 协议下，除 LastFM 外与最优神经模型差距在一个百分点以内；这说明 LiFTER 的强项在于区分“都出现过的候选”之间的时间/复发差异，而不是单纯依靠流行度或身份。
- **解释质量最优**：宏 ACC-AUC 0.8671、Deletion AUFSC 0.0552，均高于 T-GNNExplainer、TempME、TGIB、SIG。
- **机制可分离**：精确 Shapley 分解显示：
  - Wikipedia 与 Reddit 主要依赖 pair renewal；
  - MOOC 主要依赖双事件转移；
  - LastFM 主要依赖单事件转移。
- **单个事实可干预**：删除“最大贡献事实”比删除随机事实对 logit/AP 影响大得多，说明解释不是“象征性展示”，而是真正参与计算的证据。
- **语义谓词不是必须**：JODIE 四个数据流上 K=1 最简洁且性能足够；只有当事件类型既可从上下文中识别（β 高）、又确实影响未来分布（α 高）时，K>1 才有显著增益。
- LiFTER 将未来链接预测变为“可验证、可重放、可编辑”的接地计算。

## 7. 优点

- **可解释性内生于预测架构**：预测 logit 与解释 trace 是同一个前向过程的产物，不需要事后搜索或代理模型。
- **接地且可验证**：每条规则执行都绑定具体事实与时间条件；独立验证器可以在数值容差内重建全部 logit。
- **可干预**：删除或修改某个事实后，可以重新执行规则并观察完整后果，这是许多黑箱解释方法不具备的。
- **表达能力适配 CTDG**：不需要语义关系链，也能表达实体绑定、pair 更新、历史位置、时间顺序和候选条件转移。
- **机制分析清晰**：精确 Shapley 分解、查询 regime 分桶、事实验证三者结合，能从“数据集层面”下钻到“单条事实层面”。
- **公平性控制较好**：统一证据库、统一预算、统一 seed，并检查了解释方法的搜索预算敏感性。
- **效率可观**：trace 生成只有约 0.024 ms/query，远快于基于搜索的解释器，适合在线可解释预测。

## 8. 不足与局限

- **数据集覆盖有限**：只使用 JODIE 的 4 个数据流，且都截取前 32,768 个事件；未在 TGB-Seq 等更强调顺序动态的更大规模 benchmark 上验证。
- **缺少真实多语义交互数据**：论文用合成实验证明 K>1 有用的条件，但没有用真实多动作流（如不同行为类型的电商/社交数据）做端到端评估。
- **历史负样本覆盖率不均衡**：Wikipedia/Reddit 仅约一半 query 有历史候选，其余使用随机负样本 fallback，可能影响“历史排序”指标的纯度。
- **LastFM 随机负样本性能下降明显**：说明模型对“从未见过”的候选泛化能力弱于某些神经模型，可能限制真实推荐场景中的覆盖率。
- **未报告训练算力与资源**：缺少 GPU 型号、数量、训练时间，难以判断训练成本。
- **符号语言依赖人工设计**：六种绑定方向、更新/位置/转移规则是作者设计好的“语言偏置”，虽然可穷举，但仍可能遗漏某些数据集特有的模式。
- **与 TKG 方法缺少直接数值比较**：论文给出“表示层不同”的理由，未与 TLogic/TILP 在统一协议下进行数据实验，使得“符号规则”方法之间的对比不够直接。
- **解释评估指标本身的局限**：ACC-AUC 衡量“选中证据能否复现原决策”，AUFSC 衡量“删除后 AP 下降”，两者都依赖原预测器；不同解释方法往往基于不同预测器（如 LiFTER vs TGN），跨方法比较时仍隐含模型差异。
