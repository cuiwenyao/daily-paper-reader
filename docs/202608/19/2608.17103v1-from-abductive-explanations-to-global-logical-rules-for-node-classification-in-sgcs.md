## 摘要
图神经网络（GNN）在节点分类任务中取得了显著性能，激发了人们对解释其预测的方法日益增长的兴趣。近期基于逻辑的方法，如LogicXGNN，从解释性子图的集合中为图神经网络（GNN）推导全局逻辑规则。尽管这些子图信息丰富，但可能包含针对单个节点特有冗余结构信息，从而可能限制所提取规则的泛化性。在本工作中，我们提出了一种基于逻辑的框架，用于简单图卷积（SGC）网络中的节点分类，该框架使用最小反事实解释作为规则提取的中间表示。对于每个节点，我们计算一组最小的节点-特征对，足以保留预测类别。然后，这些解释用于训练决策树，从决策树中提取全局逻辑规则。在基准数据集上的实验表明，所提出的框架能产生紧凑的全局规则，同时保持对原始SGC模型的高保真度。

## Abstract
Graph Neural Networks (GNNs) have achieved remarkable performance in node classification tasks, motivating growing interest in methods capable of explaining their predictions. Recent logic-based approaches, such as LogicXGNN, derive global logical rules for Graph Neural Networks (GNNs) from collections of explanatory subgraphs. While informative, these subgraphs may contain redundant structural information that is specific to individual nodes, potentially limiting the generality of the extracted rules. In this work, we propose a logic-based framework for node classification in Simple Graph Convolution (SGC) networks that uses minimal abductive explanations as an intermediate representation for rule extraction. For each node, we compute a minimal set of node-feature pairs sufficient to preserve the predicted class. These explanations are then used to train decision trees from which global logical rules are extracted. Experiments on benchmark datasets show that the proposed framework produces compact global rules while maintaining high fidelity to the original SGC model.

- **保真度显著提升**：AXSGC 在四个基准上的保真度均超过 LogicXGNN，最高提升达 30.2 个百分点（PubMed：99.9% vs 69.7%），在 Cora 与 Citeseer 上的提升分别为 12.1 和 6.9 个百分点，BAShapes 上两者均达 100%。

- **规则覆盖更集中**：AXSGC 的 top-10 规则覆盖高达 79.8%（Cora）、85.5%（Citeseer）、98.8%（PubMed），分别为 LogicXGNN 的 2.3×、4.2×、1.85×，说明其全局规则更具代表性。
- **NF-AXp 规模分布呈长尾形态**：大多数节点的 NF-AXp 尺寸远小于均值（中位数显著低于均值），表明典型节点可由较短的充分条件解释，仅少量高密度枢纽节点承担了较高的计算成本。这种重叠的短 NF-AXp 结构正是聚合为紧凑全局规则的基础。
- **NF-AXp 中间表示的价值**：相比直接基于原始传播特征枚举决策树路径，以 NF-AXp 为中间表示能先筛选出真正支撑决策的节点-特征对，再进行聚合，从而生成既紧凑又高保真的全局规则。

### 7. 优点

- **形式化保证**：NF-AXp 具有严格的充分性与极简性证明，这是大多数 GNN 解释方法（包括 LogicXGNN）所不具备的。充分性通过显式的逐类最坏情况间隔计算得到精确保证，而非依赖采样或启发式近似。
- **多项式时间计算**：利用 SGC 的线性性质，将一般情况下的组合 AXp 搜索简化为多项式时间（O((C-1)|C_v|²)），且系数可预先计算和复用，计算效率高。
- **局部与全局的统一框架**：同一 NF-AXp 同时充当局部解释和全局规则提取的桥接，将个体解释的严格保证与全局规则的概括能力有机结合。
- **可扩展性设计良好**：距离索引谓词使 AXSGC 天然适配不同规模的图与布尔特征数据，解释矩阵的宽度仅取决于模型超参数（K 与 d），与图规模无关。
- **控制变量严谨的实验设计**：保真度以 SGC 预测而非真实标签作为基准，将规则提取器的贡献与 SGC 分类器的预测质量分离；与 LogicXGNN 在相同深度、相同 SGC 上公平对比。
- **提供定性可读性验证**：通过在 BAShapes 上展示单条规则的结构化语义（如高间度 bin 与房型结构的对应），说明规则不仅数学上有效，语义上也与实际图结构一致。

### 8. 不足与局限

- **适用范围受限**：AXSGC 目前仅适用于 SGC 这一线性化 GNN 架构，对于包含非线性激活的标准 GCN、GAT 等模型，需依赖额外的蒸馏步骤（如将 GNN 蒸馏为 SGC）才能间接应用，会引入近似误差。论文虽声明计划直接扩展至其他 GNN，但实际并未实现。
- **实验覆盖有限**：仅对比了 LogicXGNN 一个基线，未覆盖 GLGExplainer、GraphTrail 等方法；未提供消融实验证明各阶段（特别是 NF-AXp 中间表示本身）的独立贡献；未对超参数（如决策树深度、贪心删除顺序）做敏感性分析。
- **真实数据规则语义缺乏深度分析**：定性可解释性示例仅在 BAShapes 合成数据上展示，未在 Cora/Citeseer/PubMed 上展示规则对应的具体语义内容，对真实场景中规则的可理解性论证不够充分。
- **依赖二元特征假设**：方法的前提是节点特征为布尔值。PubMed 的 TF-IDF 特征需通过零点二值化处理才能使用，这可能导致信息损失。特征值连续的非布尔场景未被正式处理或讨论。
- **保真度下限风险**：在 Citeseer 上 AXSGC 的保真度仅为 83.5%，意味着约 16.5% 的节点无法被规则集复现预测，此类规则集是否足以支撑关键决策应用值得探讨。
- **最坏情况语义的局限**：NF-AXp 的最坏情况间隔假设补集可以任意翻转二进制值，这在现实图特征中不一定对应实际的扰动分布；虽然具有鲁棒性保证，但可能产生过度保守的解释。
- **仅限无向图**：方法基于无向图设定（对称归一化），未讨论有向图或异质图场景的适用性。
