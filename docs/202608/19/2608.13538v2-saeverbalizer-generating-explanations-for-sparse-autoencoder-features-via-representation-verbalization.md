## 摘要
稀疏自编码器（SAEs）被提出来从大型语言模型（LLM）的表示中提取大量特征，但解释这些特征仍然主要依赖外部观察。这种依赖导致从观察到的模型行为中推断出表面的解释，并且在大规模收集此类行为证据时产生计算效率低下的问题。我们引入了SAEVerbalizer，这是一个将SAE解码器方向注入LLM的表示中，并微调LLM的下游层以生成所注入特征的自然语言解释的框架。一旦训练完成，生成的词语化器直接从解码器方向解释SAE特征，解决了上述两个局限性。我们的实验表明，所学的词语化能力能够泛化到未见过的特征，跨单独训练的SAE字典进行迁移，并且通过轻量级适配器，扩展到来自不同LLM的SAE特征。干预实验表明，注入多个方向会产生结合其含义的解释，而反转单个方向则会产生相应的含义变化。

## Abstract
Sparse autoencoders (SAEs) are proposed to extract numerous features from large language model (LLM) representations, yet explaining these features still relies primarily on external observation. This reliance leads to superficial explanations inferred from observed model behavior and computational inefficiency from collecting such behavioral evidence at scale. We introduce SAEVerbalizer, a framework that injects SAE decoder directions into an LLM's representations and fine-tunes the LLM's downstream layers to generate natural-language explanations of the injected features. Once trained, the resulting verbalizer explains SAE features directly from decoder directions, addressing both limitations. Our experiments show that the learned verbalization capability generalizes to unseen features, transfers across separately trained SAE dictionaries, and, with a lightweight adapter, extends to SAE features from different LLMs. Intervention experiments show that injecting multiple directions yields an explanation combining their meanings, while reversing individual directions produces corresponding meaning shifts.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：稀疏自编码器（Sparse Autoencoders, SAEs）能够从大语言模型（LLM）的表示中提取大量可解释特征，但如何为这些特征生成自然语言解释仍然是一个开放难题。
- **现有方法的缺陷**：
  - 现有主流方法（bottom-up 方法）依赖**外部行为观察**，即让 LLM 在大型语料上运行，找出每个特征的最高激活示例，再交由 LLM 总结其共性模式。
  - 这种方式存在两大局限：
    1. **解释表面化**：没有直接考察特征在模型内部如何表示，解释仅反映激活示例的表面共性，而非特征本身的语义本质。
    2. **计算效率低**：每个新 SAE 都需要重复进行语料级推理、激活计算、示例检索和逐特征 LLM 摘要，成本高昂且难以大规模扩展。
- **研究背景**：近期研究（如 Patchscopes、SelfIE 等）表明 LLM 具备处理内部表示并将其语义内容以自然语言表达的能力，这为直接从表示空间解释特征提供了可能。

## 2. 论文提出的方法论

### 2.1 总体思路

SAEVerbalizer 的核心思想是：**将 SAE 解码器方向（decoder direction）直接注入 LLM 的表示中，并微调 LLM 的下游层，使其生成对应的自然语言解释**，从而绕过对外部行为证据的依赖。

### 2.2 核心设计

- **Verbalizer（词语化器）**：经过微调的 LLM，接收一个固定且与特征无关的提示词。
- **输入**：在提示词预填充期间，目标解码器方向被注入到指定注入区间（injection span）的每个 token 表示中，这是唯一的特征特定输入，不提供任何激活示例或上下文。
- **输出**：其余 Transformer 层处理注入后的表示，通过自回归生成得到自然语言解释。

### 2.3 注入公式

在层 \( L_{inj} \) 的输出处，对每个 batch 元素独立执行以下范数匹配的加性注入：

\[
h'_{b,s} = h_{b,s} + \alpha \bar{n}_b \hat{v}_{f_b}, \quad s = 1, \ldots, S
\]

其中：
- \( \hat{v}_{f_b} = v_{f_b} / (\|v_{f_b}\|_2 + \epsilon) \) 是归一化解码器方向；
- \( \bar{n}_b \) 是注入区间内表示的平均范数，用于将注入方向缩放到局部表示量级；
- \( \alpha \) 控制注入强度（默认 \( \alpha = 0.2 \)）。

### 2.4 适配器设计（跨 LLM 迁移）

- 对于来自另一个 LLM 的 SAE 特征，引入一个**轻量级适配器**（单层仿射层）将源 LLM 表示空间映射到 verbalizer 注入层的表示空间：

\[
A(x) = W x + b, \quad W \in \mathbb{R}^{d_t \times d_s}, b \in \mathbb{R}^{d_t}
\]

- 由于偏置在差分运算中抵消，解码器方向映射为：\( \tilde{v}_f^{(t)} = W v_f^{(s)} \)。

### 2.5 训练方法

- **Verbalizer 微调**：
  - 使用来自 Neuronpedia 的高质量特征-解释配对作为监督；
  - 采用标准因果语言建模目标（仅对解释 token 计算交叉熵损失）；
  - 部分微调策略：注入层及之前的层冻结，注入层之后的层可训练，同时冻结嵌入层、SAE 参数。
- **适配器训练**：
  - 使用无标注文本训练，让源 LLM 与 verbalizer 骨干处理同一 token 序列，对齐相同位置的隐藏表示；
  - 最小化均方误差（MSE），仅更新适配器参数，两个 LLM 均保持冻结。

## 3. 实验设计

### 3.1 数据集与场景

- **LLM 骨干**：gemma-3-1b-it、gemma-3-4b-it、gemma-3-27b-it（三个规模）。
- **SAE 配置**：Gemma Scope 2 的 width-262k、medium-sparsity SAE，涵盖每个骨干的多个层（1B 的 L7/L13/L17/L22，4B 的 L9/L17/L22/L29，27B 的 L16/L31/L40/L53）。
- **跨字典迁移**：同一 LLM/层上未参与训练的 width-65k SAE。
- **跨 LLM 迁移**：从 1B-L7 和 4B-L9 的 SAE 特征通过适配器映射到 27B 默认 verbalizer。

### 3.2 Benchmark 与评估指标

- **测试集**：
  - **GTS（Global Train-Standard）**：1000 个全局采样、满足训练合格标准的特征；
  - **LIG（Low-Index Gold）**：200 个低索引、满足更严格金标准的特征；
  - **GG（Global Gold）**：1000 个全局采样、满足金标准的特征。
- **评估指标**：**Reference Agreement（RA）**，即生成解释与 Neuronpedia 参考解释被 LLM 评测判官判定为一致的测试特征比例。
- **对比/参考方法**：以 verbalizer 骨干（未微调）作为零监督基线，以及各配置的原生 verbalizer 作为跨模型对比。

## 4. 资源与算力

## 6. 论文的主要结论与发现

- **直接词语化可行**：微调后的 verbalizer 能从解码器方向直接生成高质量解释，最佳配置（27B-L16，48k 训练对）在 GTS/LIG/GG 上分别达到 52.3%/80.5%/56.1% 的 RA。
- **泛化能力强**：词语化能力可泛化到训练中未见的特征。
- **可跨字典迁移**：在相同表示空间内，默认 verbalizer 直接用于未见过的 width-65k SAE 时获得更高 RA（见表 2），说明该能力不绑定特定 SAE 字典。
- **可跨 LLM 迁移**：轻量级适配器能将 verbalizer 扩展到其他 LLM 的 SAE 特征，无需源模型的特征-解释监督；在 1B→27B 场景中，适配器方案甚至优于 1B 原生 verbalizer。
- **注入参数鲁棒**：提示词、注入区间、注入模式和强度的合理变化对性能影响有限，但注入强度过弱会显著降低性能。
- **干预行为合理**：联合注入多个方向会生成融合语义的解释；方向反转会产生语义偏移但语义相关。

## 7. 优点

- **方法创新性**：将 SAE 特征解释从"观察外部行为"转向"直接处理内部表示"，是一种范式转变。
- **高效可扩展**：训练完成后，对未见特征的解释无需语料级推理和示例检索，推理路径简短高效。
- **轻量级适配器设计**：利用跨 LLM 表示空间的对应性，实现低成本跨模型迁移，且适配器训练无需特征-解释监督。
- **部分微调策略合理**：冻结注入层及之前层，保证 SAE 解码器方向所在的表示空间不变，同时减少训练开销。
- **详细的消融与干预分析**：对提示词、注入区间、注入强度、联合注入和方向反转的系统分析，增强了方法的可信度。

## 8. 不足与局限

- **LLM/SAE 覆盖范围有限**：仅验证了 Gemma 系列 LLM 和 Gemma Scope 2 SAE，其他架构（如 Qwen、Llama）和 SAE 变体的泛化性尚待验证。
- **解释验证存在偏差风险**：RA 指标衡量生成解释与参考解释的一致性，而参考解释本身来自激活示例观察，非绝对真值；训练监督同样来自过滤后的 Neuronpedia 解释，可能继承其系统性偏差。
- **单次运行无方差估计**：未报告多随机种子的均值与方差，统计稳健性不足。
- **监督构建成本高**：当前依赖高质量的 Neuronpedia 过滤解释，该过程计算代价较高（作者指出可替代方案，但未实证验证）。
- **跨模型对比不完整**：与同期的 SAEExplainer 等方法缺少直接比较，难以全面定位方法的相对优劣。
- **潜在伦理风险**：对内部特征意义的操控可能带来双用途风险（安全审计与恶意操控并存）。
