## 摘要
在这项工作中，我们介绍了DMDIntel，它利用动态模式分解（DMD）使大型语言模型在分类任务中的预测变得可解释。它开发了一个输入归因流程，首先将大型语言模型的隐藏状态分解为显著模式（也称为模态），然后根据这些模态上的投影值对输入令牌进行排名。跨三个数据集和三个模型家族的严格实验一致表明，使用DMDIntel获得的输入令牌的排名归因远远优于主成分分析、积分梯度和SHAP等最先进技术。

## Abstract
In this work, we introduce DMDIntel which uses dynamic mode decomposition (DMD) to make the predictions made by LLMs in a classification task interpretable. It develops an input attribution pipeline, that first decomposes the hidden states of an LLM into prominent patterns, also known as modes, and then associates ranks to the input tokens based on the projection values on those modes. Rigorous experiments across three datasets and three model families consistently show that the ranked attribution of input tokens obtained using DMDIntel by far outperforms state-of-the-art techniques such as principal component analysis, integrated gradients and SHAP.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：Transformer 架构的 LLM 在各类 NLP 任务上表现优异，但其内部决策机制难以理解。现有可解释性方法（如 Integrated Gradients、SHAP 等）虽可进行输入归因，但存在两个核心缺陷：
  - 将 token 视为彼此独立的离散实体，忽略了隐藏状态随序列演化的**顺序动态**；
  - 只提供“碎片化快照”，无法刻画模型推理的**连续叙事**。
- **核心问题**：如何利用 LLM 处理序列时隐藏状态的**时序演化信息**，更准确、更高效地识别驱动分类预测的关键输入 token？
- **核心思路**：将监督微调后的 LLM 视为一个离散时间**动力系统**，其隐藏状态构成一条轨迹；用 **动态模式分解（DMD）** 学习该系统的近似线性算子，并分解为可解释的时空模式，再通过 token 在这些模式上的投影值进行重要性排序。
- **整体含义**：首次将 DMD 引入 decoder-only LLM 的输入归因，为 LLM 解释提供了一种全新的“动力学视角”，并在多种模型和数据集上显著超越现有方法。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想
- 将 LLM 的每一层看作一个状态转移函数：\( h_{t+1} \approx F(h_t) \)，用 DMD 找到一个最佳线性近似算子 \( A \)，使得 \( h_{t+1} = A h_t \)。
- 对算子 \( A \) 进行特征分解得到若干 DMD 模式（模态），这些模式代表隐藏状态演化中的低维显著结构，可作为模型信息流的主要载体。

#### 关键技术细节

1. **数据矩阵构建**：
   - 选取某一 decoder 层的 MLP 中 `down_proj` 输出作为每个 token 的隐藏状态 \( h_i \)。
   - 将输入序列的所有 token 隐藏状态排列为矩阵 \( X = [h_1, h_2, \dots, h_n] \)。

2. **指令偏置去噪**：
   - 微调后的模型在隐藏状态中编码了大量 prompt 模板信息，构成噪声。
   - 将“空 prompt”（不含输入句子）通过模型得到指令偏置向量 \( b \)。
   - 对每个 token 的隐藏状态去偏：\( \hat{h}_i = h_i - b \)，形成去偏后的数据矩阵 \( \hat{X} \)。

3. **启发式层选择（Algorithm 1）**：
   - 遍历从中间层 \( L_{mid} \) 到最后一层 \( L_{last} \) 的每一层。
   - 计算每层 token 隐藏状态与偏置向量 \( b \) 的平均余弦相似度，形成曲线 \( C \)。
   - 选择候选层中相似度低于阈值 \( \tau = 0.25 \) 且梯度（相邻层相似度差）最大的层 \( \ell^* \)，作为“输入内容表示”和“指令跟随”的平衡点。
   - 论文通过实验验证该启发式在多个模型和数据集上一致有效。

4. **DMD / HODMD 分解**：
   - 使用 PyDMD 库对去偏后的隐藏状态矩阵进行 DMD 分解。
   - 标准 DMD：假设一阶马尔可夫关系，通过 SVD 得到低秩近似算子 \( \tilde{A} \)，再特征分解获得 DMD 模式和特征值。
   - HODMD（高阶 DMD）：引入时间嵌入（Hankel 矩阵），将每个隐藏状态表示为前 \( d \) 个状态的线性组合，从而捕获更长程的时间依赖。

5. **模式排序**：
   - 采用两种排序准则：
     - 初始模态振幅大小（amplitude-based ranking）；
     - 时间平均振幅大小（time-averaged amplitude ranking）。
   - 实验中通常取 top-5 模式。

6. **Token 归因得分**：
   - 定义 token 的状态变化 \( \Delta h_t^{\ell^*} = h_t^{\ell^*} - h_{t-1}^{\ell^*} \)。
   - 计算该变化在 top-k 模式 \( \phi_i \) 上的标量投影：\( \alpha_{t,i} = \langle \Delta h_t^{\ell^*}, \phi_i \rangle / \|\phi_i\| \)。
   - 将 k 个模式上的投影绝对值求和得到该 token 的得分 \( s_t = \sum_{i=1}^k \alpha_{t,i} \)。
   - 按得分降序排列 token，即得输入归因排名。

### 3. 实验设计

- **数据集**（3 个文本分类任务）：
  - **Sentiment**（情感分类，Amazon Polarity 评论）：正 / 负二分类。
  - **HateXplain**（仇恨言论检测）：仅针对仇恨类（hateful）进行归因。
  - **FakeEdit**（假新闻检测，Reddit 帖子）：仅针对“fake”类进行归因。
- **模型**（3 个不同规模和家族的 decoder-only LLM）：
  - Llama-3.2-3B-inst
  - Qwen3-4B-inst
  - Mistral-7B-v0.3-inst
  - 均使用全精度进行监督指令微调。
- **评估基准 / Ground Truth (GT)**：
  - 使用 GPT-4.1 标注每个输入句子中最多 20 个影响分类输出的关键 token，并按重要性排序。
  - 同时由两位有经验的标注者对 100 个句子进行人工排名，与 GPT-4.1 的标注进行一致性验证（RBO 在 0.54~0.70 之间，一致性较好）。
- **对比方法（Baselines）**：
  - **IG**（Integrated Gradients）
  - **SHAP**（Gradient SHAP 实现）
  - **PCA**（将 PCA 主成分直接替代 DMD 模式，token 归因流程与 DMD 相同）
- **评估指标**：
  - **平均匹配数（Matched Count, MC）**：检索到的 top-k token 中与 GT 重合的数量。
  - **RBO（Rank-Biased Overlap）**：考虑排名顺序的列表相似度，取 p=0.95。
  - **Recall@k**：GT token 被检索到的比例。
- **输入长度分桶**：

- **DMD 变体组合**（在每组实验中报告最佳组合）：

  - DMD + 时间平均振幅排名；

### 6. 主要结论与发现

1. **DMDIntel 在绝大多数场景下优于基线**：
   - Sentiment：HODMD + 时间平均振幅排名效果最佳，MC、Recall 均高于 PCA/IG/SHAP。

2. **任务性质影响最优变体**：
   - 情感分类依赖多词短语（需要上下文），HODMD 的时间嵌入能更好捕捉；
   - 仇恨言论 / 假新闻的“触发词”更局部化，标准 DMD 已足够，且模式初始振幅更能体现关键 token。
3. **去噪步骤至关重要**：
   - 去除指令偏置后，Sentiment 指标显著下降，说明 prompt 模板信息会干扰动态模式提取。
4. **DMDIntel 具有较好的鲁棒性**：
   - 对层选择不敏感（±1 层变化很小）；
   - 跨模型表现稳定（而 PCA 在不同模型间波动较大）。
5. **保真度验证**：
   - 在 token 掩蔽实验中，DMDIntel 通常达到最高或次高的准确率 / 置信度下降，说明识别出的 token 确实对预测至关重要。
6. **高效性**：
   - 单次前向传播即可完成归因，计算开销远小于 IG/SHAP。

### 7. 优点（方法或实验亮点）

- **视角新颖**：首次将 LLM 隐藏状态演化视为动力系统，并引入 DMD 进行输入归因，为可解释性领域提供了新工具。
- **技术设计巧妙**：
  - 使用指令偏置去噪，缓解 prompt 模板对内在动态的污染；
  - 启发式层选择无需额外训练，且实验验证有效；
  - 结合 DMD/HODMD 两种算法适应不同任务的时间依赖需求。
- **实验严谨**：
  - 多维度评估（匹配数、排序质量、召回、保真度、重构误差、效率）较全面；
  - 进行了丰富消融实验，验证了各组件的作用；
  - 使用人工标注对 GPT-4.1 GT 进行交叉验证，降低了单一模型标注偏差。
- **计算高效**：相比梯度类方法，DMDIntel 仅需一次前向传播，显著降低归因成本，具有实际应用价值。
- **通用性**：在三个不同规模模型（3B/4B/7B）、三个不同任务上均表现稳定，说明方法具有一定泛化能力。

### 8. 不足与局限

- **任务范围受限**：
  - 仅适用于生成少量输出 token 的分类任务；对于生成长文本（如机器翻译、摘要）或多 token 生成场景，如何在自回归过程中构建 DMD 矩阵并归因输入 token 尚未解决（论文在 Limitations 中明确说明）。
- **只研究监督微调模型**：
  - 未探索通用对齐模型（如开源 chat 模型）的归因表现；这些模型的指令跟随模式更复杂，可能影响去噪和层选择的适用性。
- **GT 依赖 LLM 标注**：
  - 尽管有人工验证，但 GPT-4.1 的排名仍可能带有主观偏差，且人工标注仅覆盖 100 句，验证规模偏小。
- **统计显著性不足**：
  - 报告多为均值差异，缺少方差和显著性检验（如 t-test 或 bootstrap），部分 RBO 差异较小（如 0.01~0.02），稳健性存疑。
- **噪声去除的建模假设**：
  - 将空 prompt 的隐藏状态作为“指令偏置”直接相减，可能过度简化了 prompt 与输入的非线性交互；在复杂指令模板下该近似可能失效。
- **模式数量与变体选择依赖经验**：
  - top-5 模式、阈值 τ=0.25、延迟参数 d 的自适应规则均需要根据任务调参；论文未提供自动选择这些超参数的通用方法。
- **未探索更长序列与更大模型**：
  - 实验输入长度最多 100 token，模型最大 7B；更长的上下文和更大规模模型的适用性未知。
- **计算资源细节缺失**：
  - 微调的时间、能耗、GPU 数量未报告，影响复现和成本评估。
