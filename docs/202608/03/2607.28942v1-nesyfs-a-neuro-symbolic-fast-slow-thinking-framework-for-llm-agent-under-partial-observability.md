## 摘要
近期，大语言模型（LLMs）越来越多地被部署为自主智能体，应用于自我反思、检索增强生成和科学发现等场景中。在这些设置中，智能体必须基于有限的观测而非完整的环境状态进行决策，从而导致部分可观测性。这引入了几个关键挑战：信念状态推断、任务目标错位以及不确定性下的规划。先前的方法通常基于完整或摘要的动作-观测历史来条件化动作，而这些历史中的冗余和无关信息可能误导LLM智能体的决策。受人类认知的启发，我们提出了一种新颖的神经符号快慢思考（NeSyFS）框架，用于LLM智能体，以统一的方式应对部分可观测性带来的挑战。我们使用知识图谱（KG）来表示信念状态，并为NeSyFS的每个模块提供三元组作为上下文。快思考模块执行反应性动作，而慢思考通过遵循扭转顺序蒙特卡洛（TSMC）算法的高级结构进行新的不确定性感知规划。为了缓解任务目标错位问题，使用反思模块对快思考动作进行反思，并在反应性动作反复失败时切换到慢思考模块。在三个代表性基准测试（即ALFWorld、Webshop和ScienceWorld）上的实验表明，该方法相对于先前方法具有显著优势。

## Abstract
Recently Large Language Models (LLMs) have been increasingly deployed as autonomous agents in applications such as self-reflection, retrieval-augmented generation, and scientific discovery. In these settings, agents must act based on limited observations rather than full environmental states, leading to partial observability. This introduces several key challenges: belief state inference, task objective misalignment, and planning under uncertainty. Prior approaches typically condition actions on full or summarized action-observation histories whose redundant and irrelevant information can mislead the decision making of LLM agent. Inspired by human cognition, we propose a novel neuro-symbolic fast-slow thinking (NeSyFS) framework for LLM agent, addressing the challenges introduced by partial observability in a unified approach. We use a knowledge graph (KG) to represent the belief state, providing triplets as context for every module of NeSyFS. The fast-thinking module performs reactive action, while slow-thinking conducts a new uncertainty-aware planning by following the high-level structure of twisted sequential Monte Carlo (TSMC) algorithm. To mitigate the misalignment of task objective, a reflection module is used to reflect fast-thinking actions, and also switches to the slow-thinking module whenever reactive actions repeatedly fail. Experiments on three representative benchmarks, i.e. ALFWorld, Webshop, and ScienceWorld, demonstrate significant advantages over previous methods.

- **现有方法局限**：先前方法通常以完整或摘要化的动作-观测历史作为上下文，其中冗余和无关信息会误导 LLM 的决策；基于摘要的信念状态（如 ABBEL）也容易丢失关键信息。
- **本文意义**：受人类认知中"快思考与慢思考"双系统启发，提出 NeSyFS 框架，以知识图谱（KG）作为结构化符号记忆，统一解决上述三类挑战。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体框架
- NeSyFS 由三大模块组成：**快思考模块**、**反思模块**、**慢思考模块**，所有模块共享由 KG 检索得到的三元组作为上下文。
- KG 作为环境潜在状态的代理（belief state），每个时刻由 `G_{t+1} = Update(G_t, o_t, a_t)` 动态更新——新观测转化为三元组加入，过时三元组被剪除。

### 2.2 知识图谱（KG）表示
- 三元组形式包括三种：
  - `(entity1, relationship, entity2)`——实体关系；
  - `(entity1, attribute, boolean/value)`——属性；
  - `(entity1, verb in past tense, entity2)`——历史事件。
- 通过检索函数 `τ_t = R(G_t, η)` 获取与任务 η 相关的三元组，作为每个模块的上下文，近似 POMDP 中潜在状态。

### 2.3 快思考模块（Fast Thinking）
- 输入为检索到的三元组、当前观测和任务描述，用 CoT 推理生成反应式动作：
  - `a_t = LLM(P_fast; R(G_t), o_t, η)`
- 动作执行后收到新观测，更新 KG。

### 2.4 反思模块（Reflection）
- 以第三人称视角验证动作是否与任务目标一致，输出 `Y_ref ∈ {Yes, No}`：
  - `Y_ref = LLM(P_ref; a_t, o_t, R(G_t), η)`
- 采用 **self-consistency**：采样 n=5 次，80% 以上为 "Yes" 才判定通过。
- 若反思结果为 "No"，反思信息返回快思考模块重新生成动作；连续失败 K=3 次则触发慢思考模块。
- 创新点：基于 KG 三元组实现**逐步（stepwise）反思**，而非传统的轨迹级反思，更高效、更稳健。

### 2.5 慢思考模块（Slow Thinking）：TSMC 风格规划
- 提出一种遵循**扭曲序列蒙特卡洛（TSMC）**高层结构的规划算法，据作者所述是首个将 TSMC 风格方法用于 LLM 智能体规划的工作。
- **粒子定义**：粒子 `p_i^τ = (ô^i_{1:τ}, Ĝ^i_{1:τ}, â^i_{1:τ}, ω^i_τ)`，包含预测的观测、KG 状态、动作序列和权重。
- **初始化**：慢思考激活时刻 t₀，所有粒子从相同的真实观测、KG 和动作出发，权重均为 1。
- **传播（Propagation）**：对每个粒子依次预测下一动作、下一观测、下一 KG：
  - `â^i_{τ+1} = LLM(P_fast; R(Ĝ^i_τ), ô^i_τ, η)`；
  - `ô^i_{τ+1} = LLM(P_obs; R(Ĝ^i_τ, η), â^i_{τ+1})`；
  - `Ĝ^i_{τ+1} = Update(Ĝ^i_τ, ô^i_{τ+1}, â^i_{τ+1})`。
- **权重更新（Weight Update）**：
  - `ω^i_{τ+1} ← ω^i_τ · exp(λ·δ^i_{τ+1})`；
  - `δ^i_{τ+1} = LLM(P_prog; â^i_τ, R(Ĝ^i_τ), τ_new, η) ∈ {0,1}`，为二值任务进展判别器；
  - 使用二值反馈与精炼三元组上下文可减少 LLM 幻觉与误判。
- **重采样（Resampling）**：按权重比例概率保留粒子，丢弃低质量粒子；对 LLM 判断错误具有鲁棒性，且比树搜索（MCTS）计算效率更高。
- **输出**：规划视界 H 之后，均匀采样一个剩余粒子，将其第一个动作应用到真实环境。

## 6. 主要结论与发现

- **NeSyFS 全面优于基线**：在三个基准上均持续显著超越 ReAct、Reflexion、ABBEL、RAFA、SwiftSage，例如 GPT-5 下 ALFWorld SR 达 93.6%（SwiftSage 为 81.9%），WebShop 平均奖励 69.4%（SwiftSage 为 56.3%），ScienceWorld SR 69.4%（SwiftSage 为 40.2%）。
- **KG 上下文优于历史与摘要**：三元组提供简洁、结构化的状态表示，显著提升决策与反思效果，优于完整历史和 LLM 摘要信念；相较 ABBEL 的提升说明符号化表示比摘要式信念更能保留关键状态信息。
- **反思模块有效**：引入逐步反思能有效纠正目标错位，KG 上下文的 ER 显著高于 History/Belief，能更可靠地拦截错误动作。
- **TSMC 风格规划可行**：粒子滤波方式配合二进制 LLM 进展判别，能够在部分可观测下兼顾探索与利用，并对判别错误具有鲁棒性。
- **统一框架的协同效应**：KG 记忆增强了快慢思考与反思之间的协同，优于单纯叠加规划（RAFA）或单纯快慢分工（SwiftSage）。

## 7. 优点
