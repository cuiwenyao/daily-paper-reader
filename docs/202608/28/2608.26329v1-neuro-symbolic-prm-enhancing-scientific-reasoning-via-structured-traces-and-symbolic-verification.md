## 摘要
尽管工具增强的大型语言模型在定量STEM任务中的多步推理能力已显著提升，但一个关键的残余失败模式依然存在：中间推理步骤在语法上结构良好、数学上可执行且单位一致，却在语境上缺乏根据。当前方法要么依赖无法评估语义意图的正式验证器，要么使过程奖励模型（PRM）承担同时检查算术与逻辑的双重任务。在本文中，我们提出一个神经符号框架，将推理清晰解耦为两个形式维度：符号有效性（V）与语义根据性（G）。我们通过使用确定性符号验证器作为硬过滤器，从构造上保证V。为评估G，我们在验证器接受的流形上条件训练一个PRM。为高效训练该PRM，我们引入了反事实符号扰动（CSP），一种新颖的数据合成策略，可算法生成保持约束的难负样本（完美通过验证器但逻辑有缺陷的步骤）。在推理时，我们部署验证器优先的约束搜索，在验证器覆盖的操作上保证执行一致性，同时仅依靠PRM对语义根据性进行排序。通过精确针对强工具型LLM的残余错误类别，我们的方法在无需先前框架的庞杂启发式规则的情况下，显著提升了推理可靠性。

## Abstract
While tool-augmented Large Language Models have significantly improved multi-step reasoning in quantitative STEM tasks, a critical residual failure mode remains: intermediate reasoning steps that are syntactically well-formed, mathematically executable, and unit-consistent, yet contextually ungrounded. Current approaches either rely on formal verifiers that cannot assess semantic intent, or burden Process Reward Models (PRMs) with the dual task of checking both arithmetic and logic. In this paper, we propose a neuro-symbolic framework that cleanly decouples reasoning into two formal dimensions: Symbolic Validity ($V$) and Semantic Groundedness ($G$). We guarantee $V$ by construction using a deterministic symbolic verifier acting as a hard filter. To assess $G$, we train a PRM conditionally on the verifier-accepted manifold. To train this PRM efficiently, we introduce Counterfactual Symbolic Perturbation (CSP), a novel data synthesis strategy that algorithmically generates constraint-preserving hard negatives (steps that perfectly pass the verifier but are logically flawed). At inference, we deploy a verifier-first constrained search that guarantees execution consistency for verifier-covered operations while relying on the PRM solely to rank semantic grounding. By targeting the exact residual error class of strong tool-using LLMs, our method significantly improves reasoning reliability without the sprawling heuristics of prior frameworks.

### 一、核心问题与研究动机

- **问题背景**：工具增强的大语言模型在定量 STEM 推理中虽然已通过代码解释器、Program-of-Thought 等方式大幅消除了算术和语法错误，但仍存在一类关键残余失败模式：**"可执行但缺乏上下文语义根据"（executable-but-ungrounded）的中间推理步骤**。这类步骤语法正确、数学上可执行、物理单位一致，却使用了错误公式、错误变量或错误物理原理。
- **现有方法的不足**：
  - 确定性符号验证器能检查语法、数学和单位，但**无法评估语义意图**；
  - 过程奖励模型（PRM）被迫同时承担计算器、语法检查器和语义判断器的多重角色，导致训练样本效率低，模型能力被浪费在执行规则而非深层语义接地上。
- **核心目标**：将推理正确性解耦为两个正交维度——**符号有效性（Symbolic Validity, V）** 与 **语义接地性（Semantic Groundedness, G）**，并由不同组件分别负责，以精准消除上述残余错误。

### 二、方法论

#### 2.1 核心思想
- 用**确定性符号验证器 V** 作为硬过滤器，从构造上保证符号有效性（V=1）；
- 在验证器接受的流形上**条件训练 PRM**，仅负责评估语义接地性 P(G=1 | V=1, ...)；
- 提出**反事实符号扰动（Counterfactual Symbolic Perturbation, CSP）** 生成"完美通过验证但逻辑错误"的难负样本，使 PRM 专注于语义判断。

#### 2.2 结构化推理表示
- 设计领域特定语言（JSON Schema），包含 **128 个数学/物理计算原语**和 **15 个逻辑演绎操作**；
- 结构化轨迹 J = (G_ext, S, a)，其中：
  - G_ext 为初始已知变量集合（含符号、数值、单位）；
  - S 为有序推理步骤序列；
  - a 为最终答案集合；
- 每一步 s_t = (op_t, args_t, O_hat_t)，输出为多个新变量元组，支持多值输出（如向量分量、二次方程双根）。

#### 2.3 符号验证器 V
- 执行三类硬检查：
  1. **语法/类型验证**（TypeCheck）；
  2. **数学等价性验证**（相对容差 ε = 10⁻⁵）；
  3. **量纲分析验证**（基于 Pint 库，单位自动转换与等价判定）。
- 验证公式：V(s_t)=1 当且仅当类型检查通过且所有输出的数值与单位均匹配。
- 验证器只保证执行有效，不保证科学正确，语义判断委托给神经网络。

#### 2.4 CSP 难负样本生成
- **正样本**：用强推理模型（GPT-5.2）作为 oracle 评估结构化轨迹的步骤级正确性。
- **两类扰动策略**：
  1. **上下文逻辑扰动**（"正确原理、错误上下文"）：交换当前步骤的逻辑操作为一个同类但语境不正确的公式，由确定性求解器重新计算输出以通过验证器；
  2. **语义操作数扰动**（"有效数学、错误变量"）：将参数替换为上下文中**物理单位和数据类型完全同构**的变量（如初速度换为末速度），重新执行使数学有效但语义错误。
- **混合生成管线**：GPT-5.2 只提语义扰动建议，不动手计算；确定性代数求解器自动重算数值和单位，确保所有负样本严格满足 V=1。
- **扩展性**：提出两种无教师扩展方式（算法化 CSP 和 MCTS 自博弈/拒绝采样），摆脱对商用 LLM 的依赖。

#### 2.5 训练目标
- 使用**边际排序损失**（margin ranking loss）训练 PRM：
  L = E[ max(0, γ − (Rϕ(s⁺) − Rϕ(s⁻))) ]，γ=0.5；
- PRM 基于 Qwen2.5-Math-7B 初始化，在线性分类头输出归一化概率分数。

#### 2.6 推理：验证器优先的约束束搜索
- 流程：扩展 k 个候选 → 符号验证器硬剪枝（V=0 直接丢弃）→ PRM 语义软评分 → 保留 Top-B 束；
- 优势：神经 PRM 只在验证器接受的流形上做语义排序，大幅缩小搜索空间。
- **理论效率**：若基础模型符号错误率为 ρ，PRM 调用量从 k·C_PRM 降至 (1−ρ)·k·C_PRM；验证器 FLOPs（≈0.05 GFLOPs）远小于 PRM 前向（≈14.5 GFLOPs），可实现更宽的搜索树。

#### 2.7 鲁棒性机制
- **Post-Hoc Schema Translation**：当结构化生成重试耗尽仍失败时，退回自由文本 CoT，再翻译回结构化模式；若仍不通过，则当作未验证候选（但符号优先级最低）；
- **动态 PRM 回退（Dynamic Fallback）**：对于验证器无法覆盖的开放操作（如几何洞察），验证器返回 Unverified，由 PRM 承担完整评估；训练时为此类操作混合标准执行错误样本，使 PRM 可优雅降级为整体评估器。

### 六、主要结论与发现

1. **解耦有效性**：将符号验证与语义评估解耦后，PRM 能专注于逻辑意图判断，避免把模型容量浪费在执行规则上；
2. **验证器是关键稳定器**：加入确定性验证器 V 后，在 OlympiadBench 上 F1 从 62.6 提升至 68.9，OmniMATH 从 60.2 提升至 67.3，说明纯神经 PRM 即使有 CSP 数据仍无法抵御结构错误；
3. **CSP 显著提升语义判别**：相比标准 PRM 训练，CSP 训练额外带来约 +3.8% F1；逻辑扰动与操作数扰动联合使用（75.4%）远优于各自单独使用（71.2%/70.9%），说明 SOTA LLM 的残余错误是双模态的；
4. **推理效率收益巨大**：验证器优先搜索可将相同计算预算下的有效束宽近乎翻倍（B=16→28），在约 900 GFLOPs 相同预算下，MATH 准确率从 82.3% 提升至 85.6%（+4.5%），且不增加推理成本；
5. **优于 Python 执行方案**：在长程任务中，标准 Python 执行 Silent Fail 率高达 21.0%，NS-PRM 降至 5.0%，验证器可即时剪除复合错误；
6. **科学推理泛化**：在 GPQA/SciBench 等科学问题上，NS-PRM Full 平均比纯神经版本高 +3.6%，表明物理推理失败主要源于结构性/量纲性崩溃，而 CSP 能有效训练模型判别有效逻辑步骤与扰动错误步骤；
7. **低符号覆盖率下仍保持鲁棒**：即使验证器在 Geometry 上 38.5% 的操作选择弃权（Abstain），动态回退机制仍使表现优于标准 PRM 基线。

### 七、方法优点

1. **问题定位精准**：聚焦"可执行但不接地"这一具体残余错误类别，而非泛泛提升推理能力，针对性强；
2. **职责清晰分解**：V 与 G 的二分法干净利落，避免了现有 PRM "既当裁判又当运动员"的混乱；验证器保证数学下限，PRM 决定逻辑上限；
3. **CSP 数据生成巧妙且可扩展**：混合 GPT-5.2 语义提议 + 确定性求解器数值平衡的管线，既保证负样本"难"（通过验证），又保证"高质量"（语义合理错误）；且设计了无教师扩展路径；
4. **推理效率理论扎实**：形式化分析了计算级联收益，并在多种束宽、同计算预算条件下验证了效率-性能权衡；
5. **鲁棒性机制完备**：Post-Hoc Schema Translation、Python 回退原语、动态 PRM 回退等机制使得框架在验证器覆盖不完全时优雅降级，而非崩溃；
6. **实验设计严谨**：统计显著性检验、多次随机种子报告标准差、同计算预算对照、消融阶梯完整；
