## 摘要
基于强化学习的知识蒸馏有望将复杂推理从教师模型迁移到学生模型，但目前面临一个关键困境：研究者必须在稀疏的基于结果的奖励（提供不充分的逻辑指导）与昂贵的神经过程奖励模型（PRM）以获取密集信号之间做出选择。我们通过引入SPEAR（符号过程评估与对齐奖励）解决了这一问题，这是一种无需训练、即插即用的过程奖励方法，用于序列级在策略蒸馏。SPEAR将自然语言推理轨迹映射为领域自适应的符号里程碑，为过程级推理对齐提供了高效代理。通过利用最长公共子序列（LCS）将学生探索与教师里程碑对齐，SPEAR提供了密集、有序的奖励信号，在不需外部神经验证器的情况下强制逻辑一致性。我们在数学、科学和常识推理任务上的实验表明，SPEAR通过序列级蒸馏和高效密集过程奖励，有效弥合了学生与教师模型之间的推理差距。我们的代码和数据可在以下网址获取：https://github.com/zhuochunli/SPEAR。

## Abstract
Reinforcement learning-based knowledge distillation has the potential to transfer complex reasoning from teacher to student models, yet it currently faces a critical dilemma: researchers must choose between sparse outcome-based rewards, which provide insufficient logical guidance, or expensive neural Process Reward Models (PRMs) for dense signals. We resolve this by introducing SPEAR (Symbolic Process Evaluation and Alignment Reward), a training-free and plug-and-play process reward method for sequence-level on-policy distillation. SPEAR projects natural-language reasoning traces into domain-adaptive symbolic milestones, providing an efficient proxy for process-level reasoning alignment. By utilizing the longest common subsequence (LCS) to align student explorations with teacher milestones, SPEAR provides a dense, order-aware reward signal that enforces logical consistency without the need for an external neural verifier. Our experiments across math, science, and commonsense reasoning tasks demonstrate that SPEAR effectively bridges the reasoning gap between student and teacher models via sequence-level distillation with efficient dense process rewards. Our code and data are available at: https://github.com/zhuochunli/SPEAR.

## 1. 核心问题与整体含义（研究动机与背景）

**研究动机**：基于强化学习的知识蒸馏（RL-KD）旨在将大语言模型（LLM）的复杂推理能力迁移到小语言模型（SLM），但现有方法面临一个关键困境：

- **稀疏结果奖励**（如最终答案验证）：只提供二元信号，缺乏对多步逻辑过程的指导，容易导致"过度思考"（overthinking）和奖励黑客（reward hacking）。
- **稠密神经过程奖励模型（PRM）**：能提供逐步监督，但需要额外的数十亿参数模型，计算开销巨大，且容易在领域特定任务中产生幻觉，可迁移性差。

**本文提出的解决方案**：SPEAR（Symbolic Process Evaluation and Alignment Reward，符号过程评估与对齐奖励）——一种**无需训练、即插即用**的过程奖励方法，通过将自然语言推理轨迹投影为**领域自适应的符号里程碑**，利用最长公共子序列（LCS）进行顺序感知对齐，同时解决了逻辑指导不足和计算开销过高的两难问题。

## 2. 方法论

### 2.1 核心思想

SPEAR 的核心洞察是：**推理过程可被视为一系列符号里程碑的序列**。与其在 token 级别强制学生模仿教师的语言表达，不如在符号级别对齐师生双方的**逻辑骨架**，让学生在保留自身语言自由度的情况下，内化推理的逻辑结构。

### 2.2 训练目标

采用在策略蒸馏（on-policy distillation），使用 GRPO 等 RL 算法优化学生策略：

- 目标函数：最大化带裁剪的期望奖励（公式 1），优势函数 Â 由复合 SPEAR 奖励计算。

### 2.3 领域自适应符号锚点（Φ 映射函数）

SPEAR 将高维自然语言轨迹 y 投影为低维符号轨迹 A = [a₁, a₂, …, aₙ]，针对不同任务类型设计不同的提取规则：

| 任务领域 | 锚点类型 | 提取方法 |
|---------|---------|---------|
| 数学（GSM8K/MATH） | LaTeX 表达式 + 变量赋值 | 基于正则的投影，排除裸数值，关注结构推导 |
| 科学（GPQA） | 动词为中心的关联元组（动词词元, 宾语span）或（主语span, 动词词元） | 依赖解析（dependency parsing），并强制去重防止重复奖励 |
| 常识（CommonsenseQA） | 状态-动作对（名词短语根词, 支配动词词元） | 名词块 + 句法中心词提取，对修饰语和时态变化保持不变性 |

### 2.4 LCS-F1 顺序对齐

采用**最长公共子序列（LCS）**计算过程推理奖励：

- **公式**：R_reason = 2|LCS(A_s, A_t)| / (|A_s| + |A_t|)
- **LCS-F1 的优越性**：同时惩罚"学生锚点缺失"（低召回）和"学生锚点冗余/重复"（低精度），比单独使用精确率或召回率更均衡，完全对齐才得满分。
- LCS 是顺序感知的，严格惩罚逻辑顺序颠倒；对非逻辑贡献的冗余语言填充具有不变性。
- 计算采用动态规划（公式 6），可在 RL 实时 rollout 中高效执行。

### 2.5 门控复合奖励

总奖励为：**R_spear = I_fmt · (R_acc + λ · R_reason)**，其中 λ = 0.5

- I_fmt ∈ {0, 1}：格式合规门（检查 <think> 和 <answer> 标签）
- R_acc：最终答案正确性二元奖励
- R_reason：LCS-F1 过程推理奖励（稠密信号，取值 [0, 1]）
- 即使最终答案错误，推理里程碑也能提供部分奖励，防止训练早期梯度崩溃。

## 6. 主要结论与发现

1. **SPEAR 在几乎所有设置下都优于纯结果奖励基线**：在两个学生模型、三个 RL 框架、四个任务上，Avg. Δ 为 +1.56% ~ +2.01%，显著高于 Logic-RL（+0.12%~+0.45%）。
2. **RL 蒸馏与 SFT 各有优势**：数学任务上 RL 优于 SFT（因为数学答案与逐步推理强耦合）；但 GPQA 这类多选题上 SFT 仍具竞争力（模型可能猜对选项，结果奖励信号有效信息少），直接模仿教师解释有时能迁移更多领域知识。
3. **蒸馏并非对所有任务都有效**：CommonsenseQA 上 SFT 蒸馏反而导致性能下降（Qwen3-4B 从 83.95% 降至 80.90%），说明强制学习教师的自然语言模式可能引入不可迁移的隐式模式。
4. **与神经 PRM 相比，SPEAR 具有极佳的性能-效率权衡**：在 MATH 上与领域专用 PRM 差距在 1-2% 以内，在 GPQA 上显著优于数学专用 PRM（平均高出 3.87%），且不需要额外的神经网络。
5. **消融实验的关键发现**：
   - 准确率奖励仍是主导学习信号（去除后降幅最大）；
   - 格式门有助训练稳定性；
   - λ=0.5 对 MATH 最优，GPQA 在 λ=0.75 更优，λ=1.0 会因过度强调推理对齐而损害性能；
   - 符号抽象和顺序结构两者缺一不可（原始 token LCS 或无序 Jaccard 都会带来约 2% 下降）；
   - 领域自适应的锚点提取至关重要（通用表面锚点导致 2.22% 平均下降）。
6. **中等比例的 SFT 冷启动最佳**：30% SFT + 70% RL 组合效果最好，过度 SFT 会降低后续 RL 的探索多样性。

## 7. 优点

1. **无需训练、即插即用**：SPEAR 不依赖任何神经奖励模型，可无缝集成到现有的 GRPO/Dr. GRPO/DAPO 等 RL 流水线中，显著降低使用门槛。
2. **高效的稠密奖励**：仅用约 12MB 的 spaCy 解析器和动态规划 LCS 就实现了比肩数十亿参数 PRM 的过程奖励效果，每步训练开销仅增加 1.87%（对比 PRM 的 30.04%）。
3. **顺序感知的逻辑一致性约束**：LCS-F1 在惩罚逻辑顺序颠倒的同时容忍语言表达的多样性，实现了"逻辑获取与语言表达解耦"，避免 RL 蒸馏中的"风格模仿"问题。
4. **领域自适应的符号投影**：不同的任务类型（数学、科学、常识）使用不同的锚点提取策略，使过程监督从形式化领域（数学/编程）扩展到更广泛的知识推理任务。
5. **方法设计具有较好的可解释性**：符号锚点为推理过程提供了直观的可视化和案例验证（如 GPQA 案例研究展示的师生锚点对比）。
6. **实验设计较为扎实**：覆盖任务、模型、RL 框架三个维度的交叉验证，并有配套的消融、效率分析、冷启动分析、跨基准迁移和 OOD 测试。

## 8. 不足与局限

1. **精确匹配的语义盲区**：依赖符号锚点的精确匹配（LCS），无法捕捉"语义等价但结构不同"的推理路径。学生若采用与教师符号顺序不同但同样有效的推理方式，会获得较低奖励，可能在开放任务中抑制有效替代推理路径的探索。
2. **教师轨迹质量假设**：假设教师生成的 rationale 是可靠的推理轨迹，但 LLM 的思考过程可能包含冗余或次优的中间步骤，这些噪声会通过锚点提取传递给学生的奖励信号。
3. **规则提取

3. **规则提取器的泛化依赖**：领域自适应锚点（Φ 映射函数）依赖人工设计的正则表达式、依赖解析和句法规则。每进入一个新领域，都需要专业知识和额外调试来设计合适的符号投影规则；对非英语文本、代码生成、多轮对话等非规范或弱句法结构任务的迁移能力有限，不像神经奖励模型那样可自动学习表征。

4. **对推理链条长度与粒度的敏感性**：LCS-F1 的归一化方式在师生轨迹锚点序列长度差异较大时可能产生不公平评分——学生给出逻辑完整但更简洁的推理时，会因为分母偏大或匹配偏少而获得较低奖励；这可能导致学生在 RL 过程中不必要地模仿教师的步骤数量，而非真正内化逻辑结构。

5. **超参数 λ 的任务依赖性**：尽管 λ=0.5 在整体上表现良好，但消融实验显示 GPQA 上 λ=0.75 更优，说明过程奖励和结果奖励的相对权重仍需按任务调整。这在一定程度上削弱了"即插即用"的简洁性，用户需要针对目标领域进行少量调参。

6. **统计显著性不足**：GPQA 测试集仅 198 个样本，主实验和消融实验也未报告多次独立运行的均值和标准差/置信区间。考虑到 RL 训练本身具有随机性，观察到的 1~2% 平均提升是否具有严格的统计显著性仍存疑。

7. **开放域和长尾推理场景验证不足**：对 AlpacaEval 2.0 的跨基准迁移是初步尝试，但并未覆盖真正开放域的长文本推理、代码/结构化输出、多模态推理等场景。符号锚点的句法特征在这些环境中可能失效，其普适性仍需进一步验证。

8. **奖励游戏化的残余风险**：格式门和符号对齐奖励为学生提供了一种新的"快捷方式"——可能生成形式上包含预期符号锚点、但语义空洞或逻辑跳跃的推理链。虽然 LCS-F1 和答案正确性奖励在一定程度上抑制了该行为，但论文未设计专门的对抗性防御或作弊检测机制。

## 9. 适用场景与部署建议

SPEAR 最适合以下场景：

- **推理轨迹具有明显符号化中间步骤的任务**：如数学、程序化推理、科学问答等，逻辑骨架可以较容易地映射为结构化锚点。
- **对训练/推理成本敏感、无法部署大参数 PRM 的团队**：SPEAR 只需 CPU 上的小型 NLP 解析器和动态规划，即可获得近似神经 PRM 的过程监督效果。
- **已有 GRPO 等 RL 蒸馏流水线的用户**：SPEAR 是即插即用的外部奖励模块，改动成本低，适合快速替换或增强现有结果奖励。

部署时建议：

- 优先采用 30% SFT + 70% RL 的冷启动策略，避免冷启动作业效率过低或过度 SFT 导致探索退化。
- 在新领域应用时，先用小规模验证集对锚点提取规则和 λ 进行快速校准，再扩展到全量训练。
- 对高价值任务可保留一个轻量级规则校验器，用于过滤"符号对齐但逻辑空洞"的学生轨迹。

## 10. 未来研究方向

1. **从手工规则到可学习的符号投影**：探索利用小模型或解析器自动归纳领域锚点，降低迁移成本。
2. **处理语义等价的多样化推理路径**：结合蕴含判定或语义相似度与 LCS 结构匹配，允许不同的逻辑编排方式获得同等奖励。
3. **跨语言与多模态扩展**：将符号里程碑思想推广到中文等非英语场景，以及代码、图表推理等结构化输出。
4. **更细粒度的过程反馈**：在 LCS 对齐的基础上提供每个符号里程碑的局部正/负反馈，替代单一的全局过程奖励。
5. **不确定性量化与可信度评估**：为 SPEAR 的奖励分数提供置信区间，帮助过滤教师轨迹中的噪声锚点。

---

## 11. 总结评价

SPEAR 是对 RL 蒸馏中"奖励设计"这一关键环节的一次务实且高效的创新。它没有选择继续堆叠更大参数的过程奖励模型，而是回归到"推理逻辑可被符号化表达"这一核心观察，用最小的计算代价换取了接近神经 PRM 的过程监督质量。论文的实验设计较为严谨，覆盖任务、模型、RL 框架三个维度，并通过系统的消融验证了符号抽象、顺序对齐、领域自适应提取等各组件的必要性。

当然，SPEAR 还不是通用推理奖励的最终答案——它对语义等价路径的盲区、对人工规则的依赖、以及统计验证的薄弱之处，决定了它更适合作为一种高效、可解释、低成本的推理奖励组件，与结果奖励和少量人工规则结合使用，而不是完全替代更强大的神经过程奖励模型。未来若能在符号投影的自动化与语义泛化方面取得突破，这类方法有望成为 RL 蒸馏奖励设计的通用范式。
