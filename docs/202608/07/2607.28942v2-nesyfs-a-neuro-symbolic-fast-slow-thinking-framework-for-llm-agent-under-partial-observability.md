## 摘要
近年来，大型语言模型（LLMs）越来越多地被部署为自主智能体，应用于自我反思、检索增强生成和科学发现等场景。在这些场景中，智能体必须基于有限的观测而非完整的环境状态进行行动，从而导致部分可观测性。这引入了几个关键挑战：信念状态推断、任务目标错位和不确定性下的规划。先前的方法通常将行动建立在完整或摘要性的动作-观测历史上，其中冗余和不相关的信息可能会误导LLM智能体的决策。受人类认知启发，我们提出了一种新的神经符号快慢思考（NeSyFS）框架，用于LLM智能体，以统一的方式应对部分可观测性带来的挑战。我们使用知识图谱（KG）来表示信念状态，为NeSyFS的每个模块提供三元组作为上下文。快思考模块执行反应性行动，而慢思考通过遵循扭曲序列蒙特卡洛（TSMC）算法的高级结构，进行新的不确定性感知规划。为了缓解任务目标错位，我们使用反思模块对快思考行动进行反思，并在反应性行动反复失败时切换至慢思考模块。在三个代表性基准（即ALFWorld、Webshop和ScienceWorld）上的实验表明，该方法相较于先前方法具有显著优势。

## Abstract
Recently Large Language Models (LLMs) have been increasingly deployed as autonomous agents in applications such as self-reflection, retrieval-augmented generation, and scientific discovery. In these settings, agents must act based on limited observations rather than full environmental states, leading to partial observability. This introduces several key challenges: belief state inference, task objective misalignment, and planning under uncertainty. Prior approaches typically condition actions on full or summarized action-observation histories whose redundant and irrelevant information can mislead the decision making of LLM agent. Inspired by human cognition, we propose a novel neuro-symbolic fast-slow thinking (NeSyFS) framework for LLM agent, addressing the challenges introduced by partial observability in a unified approach. We use a knowledge graph (KG) to represent the belief state, providing triplets as context for every module of NeSyFS. The fast-thinking module performs reactive action, while slow-thinking conducts a new uncertainty-aware planning by following the high-level structure of twisted sequential Monte Carlo (TSMC) algorithm. To mitigate the misalignment of task objective, a reflection module is used to reflect fast-thinking actions, and also switches to the slow-thinking module whenever reactive actions repeatedly fail. Experiments on three representative benchmarks, i.e. ALFWorld, Webshop, and ScienceWorld, demonstrate significant advantages over previous methods.

- **核心挑战**：
  - **信念状态推断困难**：完整交互历史冗长、含噪声，难以有效压缩进上下文。
  - **任务目标错位**：信息不完整会使智能体产生与任务目标不一致的动作。
  - **不确定性下的规划困难**：缺乏真实状态，难以预测未来情况并规划行动。
- **现有局限**：已有方法通常依赖完整历史或摘要历史作为上下文，冗余信息会误导决策；基于LLM的摘要可能丢失关键信息；树搜索等方法计算开销大且难以适应不确定性。
- **整体含义**：论文提出**NeSyFS**（Neuro-symbolic Fast-Slow Thinking Framework），利用**知识图谱（KG）** 结构化表示信念状态，结合**快慢双系统认知**（Kahneman）统一处理上述挑战，为LLM智能体在部分可观测环境下提供新范式。

## 2. 论文提出的方法论

### 核心思想
- 用**知识图谱（KG）** 作为工作记忆，动态维护环境潜在状态的符号化近似，取代完整历史或LLM摘要。
- 将决策分为**快思考**（反应式动作）和**慢思考**（基于规划的深度推理），并用**反思模块**连接二者，保证动作与任务目标对齐。

### 关键技术细节
- **知识图谱（KG）表示与维护**：
  - 三元组形式：`(实体1, 关系, 实体2)`、`(实体1, 属性, 布尔/值)`、`(实体1, 过去时动词, 实体2)`。
  - 动态更新：将新观测解析为三元组，与旧三元组对比，删除过期信息，生成更新后的KG。
  - 检索函数 `R(G, η)`：根据任务描述抽取相关实体和关系，检索邻接三元组作为上下文。

- **快思考模块（Fast Thinking）**：
  - 输入：检索到的KG三元组、当前观测、任务描述。
  - 使用CoT（思维链）生成下一个反应式动作：`at = LLM(P_fast; R(Gt), ot, η)`。
  - 动作执行后的新观测通过`Update(Gt, ot, at)`更新KG。

- **反思模块（Reflection）**：
  - 采用**第三人称视角**，判断快思考动作是否与任务目标对齐：`Y_ref = LLM(P_ref; at, ot, R(Gt), η)`。
  - 使用**自一致性**（self-consistency）机制，采样5次，满足80%“Yes”才通过。
  - 若动作被否决，将反思思维反馈给快思考模块重新生成动作；若连续失败K次（默认K=3），则激活慢思考模块。

- **慢思考模块（Slow Thinking）——TSMC风格规划**：
  - 遵循**扭曲序列蒙特卡洛（TSMC）** 的高级框架，维护一组粒子，每个粒子表示可能的未来观测序列、状态（KG）和动作序列。
  - **初始化**：所有粒子从当前真实观测、KG和动作开始，权重为1。
  - **传播（Propagation）**：对每个粒子，用LLM预测下一动作、下一观测，并用`Update`更新对应KG。
  - **权重更新**：基于LLM二分类判断“该转移是否推进任务完成”，`ω ← ω * exp(λδ)`，其中δ ∈ {0,1}为任务进度检测器。
  - **重采样（Resampling）**：按权重概率保留粒子，丢弃低权重粒子，使粒子集中于高可能性成功轨迹。
  - 规划结束后随机采样一个粒子，将其第一个动作应用到真实环境。
  - 该机制对LLM评估错误具有一定鲁棒性，并比树搜索计算效率更高。

## 6. 论文的主要结论与发现

- NeSyFS在**所有三个基准**上显著优于ReAct、Reflexion、ABBEL、RAFA、SwiftSage，成功率提升约20-40个百分点。

- 与树搜索规划相比，TSMC式规划在略低成功率下大幅减少token消耗，计算效率更高。
