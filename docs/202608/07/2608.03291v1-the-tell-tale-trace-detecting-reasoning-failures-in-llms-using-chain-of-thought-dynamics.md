## 摘要
思维链（CoT）推理提升了大语言模型（LLM）的性能，同时也为模型的推理过程提供了可观察的接口。然而，现有利用口头化CoT来监控推理正确性的方法大多评估各个中间步骤的语义正确性或一致性，而非推理过程在整个轨迹中的演变方式。因此，分布在推理轨迹中的失败，而非局限于单个错误步骤的失败，仍相对未被充分探索。此外，口头化CoT不一定要忠实反映模型的内部推理过程，这促使我们采用不将单个陈述视为内部计算字面描述的分析方法。因此，我们探讨是否可以利用可见CoT的动态特性，在不假设语义忠实性的前提下，系统地区分成功推理与失败推理。我们在一系列复杂度可变的可验证布尔可满足性任务上研究了多种LLM，从而能在每个模型的能力边界附近进行受控比较。通过推理功能对CoT句子进行标记，我们揭示了SAT问题上的过早验证崩溃：错误的轨迹更早进入子句检查阶段，重复相似操作并更快结束。在UNSAT问题上，模型会贸然走向错误的SAT结论，检查候选赋值而非在构造案例中推导矛盾。随后，一种有针对性的证明搜索提示干预将Llama3-70B的准确率从13.3%提升至85%，纠正了84.6%的错误。这些结果表明，能力失败可以表现为可见推理结构中的分布式、与任务相关的变化，而无论口头化轨迹是否反映模型内部计算，CoT动态特性都能帮助诊断和纠正失败。

## Abstract
Chain-of-thought (CoT) reasoning improves large language model (LLM) performance while also providing an observable interface to the model's reasoning process. Existing approaches that leverage verbalized CoTs to monitor reasoning correctness, however, largely evaluate the semantic correctness or consistency of individual intermediate steps, rather than how the reasoning process evolves across the trace. As a result, failures distributed across the reasoning trajectory, rather than those localized to a single incorrect step, remain comparatively underexplored. Furthermore, verbalized CoTs need not faithfully reflect the model's internal reasoning, motivating analyses that do not treat individual statements as literal accounts of internal computation. In this work, we therefore ask whether the dynamics of visible CoT can be leveraged to systematically distinguish successful from failed reasoning without assuming such semantic faithfulness. We study a range of LLMs on verifiable Boolean satisfiability tasks with variable complexity, enabling controlled comparisons near each model's capability frontier. Tagging CoT sentences by reasoning function reveals premature verification collapse on SAT problems: incorrect traces enter clause checking earlier, repeat similar operations, and finalize sooner. On UNSAT problems, models presumptuously move towards incorrect SAT conclusions, checking candidate assignments rather than deriving contradictions across constructed cases. Subsequently, a targeted proof-search prompt intervention raises Llama3-70B accuracy from 13.3% to 85%, correcting 84.6% of these errors. These results show that capability failures can manifest as distributed, task-dependent changes in the structure of visible reasoning, and that CoT dynamics agnostic to whether the verbalized trace reflects the model's internal computations can help diagnose and correct failures.

## 二、方法论

### 任务设置与基准选择
- 论文选择**布尔可满足性问题（SAT/UNSAT）**作为实验场景，原因有三：
  1. **可验证性**：每个实例的答案由外部求解器独立验证，正确性无需依赖模型自身文本。
  2. **复杂度可控**：系统性地改变实例复杂度，可以将每个模型置于其“能力前沿”（capability frontier）附近，实现公平的成败对比。
  3. **过程不对称性**：SAT与UNSAT虽然共享统一形式化框架，却要求不同的推理过程——SAT只需构造一个可验证的赋值，而UNSAT则需要系统性排除整个赋值空间、构造矛盾论证。

### 能力前沿匹配（Capability Frontier Matching）
- 为避免“单一难度对某模型太容易、对另一模型太难”的不公平比较，论文为每个模型单独选择难度级别：
  - 定义为经验准确率满足 **0.30 ≤ 准确率 ≤ 0.90** 的模型–难度级别对。
  - 这样可保证每个模型在同类问题上既产生成功轨迹也产生失败轨迹，从而获得受控的比较环境。
- 最终从127个匹配问题–条件对中识别出91个**分歧对**（divergent pairs），即相同问题与提示下，至少一个模型正确、另一个错误。

### 推理动态分析框架
论文的核心分析手段是对CoT进行**句子级功能角色标注**与**动态特征提取**：

- **功能角色标注**：使用基于规则的regex分类器，将CoT句子的功能划分为粗粒度角色。SAT任务包括：规划（planning）、赋值（assignment）、验证（verification）、回溯（backtracking）、收尾（finalization）、其他（other）；UNSAT任务额外引入：矛盾搜索（contradiction_search）、UNSAT证明构造（unsat_proof）、SAT执念（sat_commitment）、子句检查（clause_check）。
- **动态特征提取**：对角色序列 \( r_1, ..., r_T \)，统计相邻转移 \( r_t \to r_{t+1} \) 并构建行归一化转移矩阵 \( P_{ij} = \Pr(r_{t+1} = j \mid r_t = i) \)，由此计算：
  - 角色密度（role density）
  - 循环率（cycle rate）：返回近期角色模式的程度
  - 加权自转移（weighted self-transition）：同一角色持续程度
  - 转移熵（transition entropy）：下一步角色选择的多样性
  - 收尾时机（finalization timing）：最终答案开始出现的归一化位置
  - 子句覆盖率（clause coverage）等。

### 早期预警机制
- 在CoT逐步展开的过程中，按轨迹长度的递增比例（25%、50%、75%、100%）重新计算上述动态特征，一旦特征得分越过阈值即触发预警。
- 校准统计量和阈值来自各模型自身在基线提示下的正确轨迹，按问题ID拆分50%校准/50%测试，确保无公式跨分区泄漏。

### 针对性干预设计
- 针对UNSAT上模型“选错过程”的失败模式（检查候选赋值而非构建矛盾），设计了一个**proof-search提示**，要求模型：
  1. 选取受约束变量
  2. 按变量真值拆分案例
  3. 传播强制后果
  4. 检查是否存在无法满足的子句
  5. 仅当给出完整赋值并逐子句验证后才可声称SAT
  6. 若所有分支都矛盾则回答UNSAT
- 同时设置**通用重试提示**作为对照组，仅要求“再仔细试一次”而不指明策略，以区分“模型不稳定”与“模型缺少正确过程”两种可能。

### 1. SAT失败表现为“过早验证崩溃”（Premature Verification Collapse）
- 在105个受控配对的SAT问题中，错误轨迹约为正确轨迹的一半长度，验证密度更高、循环率更高、转移熵显著更低，且更早开始收尾（77.1% vs 89.8%位置）。
- 关键发现是：**子句覆盖率并不存在显著差异**（p = 0.206）——失败轨迹并未忽略更多公式内容，而是将推理组织为更狭窄的重复检查和过早收尾。
- 循环增加和熵降低在跨族与族内对比中均成立，属于较稳健的信号；而长度和验证密度效应仅在跨族对比中显著，体现模型家族风格影响。

### 2. 可见CoT动态可提供模型相关的早期预警
- 在能力前沿区域，基于动态特征的检测器对于Llama3-8B（80.2%提前标记，中位提前23句）和OLMo2-13B（78.2%，中位提前17.5句）有效；
- 但对Llama3-70B效果较弱（35.7%提前标记，中位提前0句）。说明该信号并非通用失效检测器，而是与模型、难度区间相关。

### 3. UNSAT失败源于过程选择错误而非句意错误
- Llama和OLMo模型在UNSAT实例上几乎总是给出“错误SAT”的完整结论（Llama3-70B的0.800完成率为错误SAT）。
- 角色轨迹分析发现：错误SAT轨迹包含更少的矛盾搜索和显式UNSAT证明构造，更多赋值验证与循环——模型仿佛用“寻找候选赋值”的过程来处理“需要证明不可能性”的任务。
- 即使移除最终答案相关特征，AUROC仍达0.800–0.905，证明区分度确实来自推理过程组织方式而非标签声明。

### 4. 定向提示干预可高效纠正过程错误
- 通用重试提示仅有11.5%修正率（6/52），证明失败并非简单的不稳定重采样。
- 专门的proof-search提示将Llama3-70B准确率从13.3%提升至85.0%，纠正84.6%（44/52）原始错误SAT结论（p < 0.001，McNemar检验）。
- 轨迹角色变化也验证了过程层面的改变：SAT承诺密度从0.0263降至0.0105，矛盾搜索密度从0.0658升至0.1097。

### 5. 核心总体结论
能力失败可以显现为分布式、任务相关的推理结构变化；即使不能将CoT视为内部计算的忠实转录，其动态特征仍可作为行为层监控、诊断和修正推理失败的有效补充信号。

## 七、优点

1. **突破语义忠实性假设**：不要求CoT“说真话”，而是通过推理过程的组织方式（排序、重复、时机）获取行为信号，更具现实适用性。
2. **可验证任务与外部真值**：SAT/UNSAT任务由外部求解器认证标签，避免了模型自我引用循环。
3. **能力前沿匹配设计**：为每个模型选出既有成功又有失败的难度区间，使对比不受“模型太强”或“模型太弱”的混淆，方法论上严谨。
4. **SAT/UNSAT不对称任务设计**：巧妙的利用统一框架下两个方向相反的过程要求，制造了极具区分力的诊断场景。
5. **多层对比控制策略**：跨族、族内、模型内三层对比，以及最终标签泄漏控制，体现实验设计的严谨。
6. **从诊断到干预的闭环**：不仅识别了失败模式（过程不匹配），而且设计了针对该过程的干预并显著验证了可纠正性。
7. **清醒的自省性**：作者在讨论中明确说明“过早验证崩溃”是稳定模式而非普遍规律，早期预警呈明显模型差异，且覆盖率需结合误报率解读，态度客观。

## 八、不足与局限

### 实验覆盖方面的局限
- 仅涵盖Qwen、Llama、OLMo三个开源模型系列，未包含闭源前沿模型（如GPT-4/o系列、Claude等）；规模仅至70B。
- 仅使用SAT/UNSAT形式化任务，不具备自然语言开放式推理任务的生态效度。作者也承认，通用性尚待验证。
- 干预实验仅针对Llama3-70B模型上的52个错误SAT案例，样本量较小，且未验证同一干预对其他模型的效果。
- 未报告早期预警的误报率、精确率、阈值敏感度等部署关键指标。

### 方法层面的偏差风险
- **角色标注误差**：依赖正则表达式分类器，是对可见文本的启发式抽象，标签错误不可避免地传入所有下游动态特征。
- **跨族风格混淆**：最强对比（Llama3-8B vs Qwen3-14B）可能混杂了模型家族的冗长程度与表达风格差异；族内对比虽缓解但未能完全消除该问题。
- **干预的oracle属性**：仅基于求解器已知的错误案例进行rerun，属于事后辅助测试，不能构成端到端的自动监控-修复系统。作者也承认该局限。
- **提示失配**：通用重试与定向proof-search提示在长度和详细程度上并不匹配，无法完全排除“更长更明确的指令”这一替代解释。

### 理论层面的局限
- 论文论证的是行为层面的相关性，不建立“可见CoT动态与内部计算”之间的因果关系。
- 早期预警信号在不同模型间差异极大，尚未形成统一的、可迁移的预警特征。
- 是否能在更开放、更真实场景中产生同样显著的动态区分度，仍是一个开放问题。

### 其他注意事项
- 论文时间戳为2026年8月，部分引文为arXiv预印本，尚未经历完整同行评审。
- 未提供算力和资源消耗的透明披露。

## 总结性评述

这篇论文提出了一个新颖且具有现实意义的研究视角：将CoT监控从“验证每一步说了什么”转向“观察每一步是怎么走的”。通过精心设计的可验证SAT/UNSAT任务、严格的匹配对比框架和诊断-干预闭环验证，作者令人信服地表明——即使模型口头化的推理不忠实于其内部状态，推理过程的**动态结构**依然能暴露能力失败的痕迹，并可以作为定向修正的可行依据。虽然通用性、部署鲁棒性和理论解释力仍有待深化，该工作为推理模型的监控、归因与纠错开辟了有希望的新方向。
