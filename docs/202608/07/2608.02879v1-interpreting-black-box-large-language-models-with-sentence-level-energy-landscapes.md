## 摘要
广泛采用通过封闭API严格访问的专有大型语言模型（LLM），为负责任的部署带来了关键挑战：从根本上缺乏可解释性。为解决这一问题，我们提出了一种模型无关、事后归因的解释器，在句子级别进行操作。我们的方法训练一个基于能量的模型（EBM）作为代理，以捕捉LLM在提示与响应之间的内部概念一致性。这种能量景观指导了一个轻量级解释器网络的训练。独特的是，我们的解释器作为独立工具运行；一旦训练完成，它就能量化提示句子对用户指定目标输出的影响，而无需进一步向LLM发起API查询。通过在多样化输入上全局训练一个局部解释器，我们的框架捕捉了更广泛的生成模式，并减轻了实例特定偏差。实验表明，我们的EBM能准确模拟目标LLM，使解释器能够有效识别生成特定目标输出时最具影响力的提示句子。

## Abstract
The widespread adoption of proprietary Large Language Models (LLMs) accessed strictly through closed APIs has created a critical challenge for responsible deployment: a fundamental lack of interpretability. To address this, we propose a model-agnostic, post-hoc attribution interpreter operating at the sentence level. Our approach trains an Energy-Based Model (EBM) as a surrogate to capture the LLM's internal conceptual consistency between prompts and responses. This energy landscape guides the training of a lightweight interpreter network. Uniquely, our interpreter operates as a standalone tool; once trained, it quantifies the influence of prompt sentences on a user-specified target output without requiring further API queries to the LLM. By globally training a local interpreter across diverse inputs, our framework captures broader generation patterns and mitigates instance-specific biases. Experiments demonstrate that our EBM accurately simulates the target LLM, allowing the interpreter to effectively identify the prompt sentences most influential in generating specific target outputs.

## 6. 主要结论与发现

1. **双目标设计有效**：$M_{Hybrid}$（λ=0.9）在四个维度上整体最优，定位能力比 $M_{Fidelity}$ 提升 5 倍 SNR 且保持鲁棒性；$M_{Fidelity}$ 过度依赖表面伪影，$M_{Dep}$ 虽能量边界清晰但潜在空间过于抽象，不利于下游解释器训练。
2. **解释器合理性高**：ESCI 尽管参数量远小于 oracle（约 71M 可训练），但在场景 B 中与 GPT-J-6B 和 Gemini-2.5-Flash 高度对齐，说明能量景观内化了自回归生成的因果机制。ESCI 的注意力分配比指令调优 oracle 更稀疏、更果断。
3. **因果忠实度接近 LIME 但效率极高**：ESCI 的忠实度差距（Gap=0.195）接近 LIME（0.245）和大容量 LLM 判断器（GPT-4o-Mini 为 0.192），但推理时零 API 调用；训练成本在解释 400 个提示后达到盈亏平衡。
4. **定性案例**：ESCI 能正确将风格化输出归因于风格指令（如“Explain like I’m five”），而 oracles 往往聚焦语义内容；但有时会过度关注主题关键词而忽略具体查询。
5. 随机基线产生负的忠实度差距，说明任意选择会损害生成，验证了指标的有效性。

## 7. 优点

- **句子级概念的提出**：将分析单元从 token 提升到句子，既符合人类可理解性，又避免 token 级别噪声；理论基础扎实（引用 Frege 的语境原则、Kintsch 的命题结构理论）。
- **EBM 作为代理的合理性**：EBM 天然适合建模高维文本的全局一致性，避开概率归一化困难；双目标损失兼顾全局保真与局部因果精度，设计有洞察力。
- **模型无关且训练后免查询**：完全兼容黑盒 API 场景；推理时 O(1) 复杂度、零 API 成本，适合大规模部署。
- **全局训练局部解释**：跨多样输入全局训练缓解实例特定偏差，且避免了局部解释器的可解释性错觉。
- **评估体系较完整**：从合理性对齐（或acles）到因果干预（sufficiency/comprehensiveness），再到计算成本分析，多维度验证方法有效性。
- **实验设计细致**：包括动态阈值基线构建、NLI 刚性检查、RLHF 平凡目标过滤等，体现严谨性。

## 8. 不足与局限

- **预训练成本高、任务特定**：需要在训练阶段投入大量计算和 API 资源；框架是任务导向的，迁移到新任务需要重新训练并重复超参数调优，阻碍开箱即用的泛化性。
- **实验覆盖有限**：仅覆盖标准 Q&A 场景、一个目标模型（GPT-4o-Mini）、约 181M 参数的紧凑代理模型；未涵盖复杂推理、长上下文（128K+ tokens）、不同架构家族（如 Llama、Pythia）等场景。
- **缺乏机制级地面真值验证**：黑盒环境下只能依赖概率性 oracle 验证行为模拟，无法保证与目标模型内部真实计算路径的机制级对齐。论文自身承认此限制并建议未来用开放权重模型与白盒信号交叉验证。
- **定性分析中的偏差**：某些案例（如 ID 33）中 ESCI 过度关注主题关键词而忽略用户具体问题；ID 94 的“完全混沌”案例说明在需要综合分析时解释可能不稳定。不过论文承认这是“人类可解释性”与“机械归因”之间天然存在的张力。
- **人类中心效用验证不足**：sufficiency/comprehensiveness 是自动代理指标，不能等同人类可理解性；缺乏受试者研究来验证解释在高风险审计任务中（如幻觉检测、偏见识别）的实际可用性。
- **RLHF 伪影的残余问题**：对“Okay!”等对话填充词，即使过滤后，ESCI 仍存在较高的幻现率（Triv. Comp. 40.8%），暴露了基于 RLHF 先验的输出难以被归因的固有困难。
