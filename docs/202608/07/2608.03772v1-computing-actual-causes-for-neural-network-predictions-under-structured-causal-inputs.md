## 摘要
解释神经网络的预测是可信任人工智能中的一个核心挑战。现有的解释方法，例如基于特征归因或最小充分集的方法，通常将输入特征视为独立的，当输入表现出结构化依赖时，这可能会产生误导性的解释。我们通过将解释形式化为Halpern-Pearl (HP)实际原因，并使用布尔结构因果模型(SCMs)对输入依赖进行建模来解决这一问题。我们通过应用边界传播和分支定界技术来计算HP原因，同时提供完整性和最小性的形式保证。我们的实验表明，在可扩展性方面，我们显著优于暴力基线和ILP基线，并且随着图规模的增大，性能优于启发式搜索，在搜索空间高达$2.3\times10^{13}$个候选(原因，偶然性)对的实例上，在包含多达28个节点的SCMs上，在每次实例180秒的预算内，计算出所有最小实际原因。在一个案例研究中，我们进一步表明，忽略输入依赖会使报告的原因数量膨胀，其中14.9%在我们的SCM下是虚假的。

## Abstract
Explaining the predictions of neural networks is a central challenge in trustworthy AI. Existing explanation methods, such as those based on feature attribution or minimal sufficient sets, typically treat input features as independent, which can yield misleading explanations when inputs exhibit structured dependencies. We address this by formalizing explanations as Halpern-Pearl (HP) actual causes, modeling input dependencies using Boolean Structural Causal Models (SCMs). We compute HP causes by applying bound propagation and branch-and-bound techniques, while providing formal guarantees of completeness and minimality. Our experiments show that we substantially outperform brute-force and ILP baselines in scalability, and outperform heuristic search as graph size grows, computing all minimal actual causes on instances with search spaces of up to $2.3\times10^{13}$ candidate (cause, contingency) pairs, on SCMs with up to 28 nodes, within a 180s per-instance budget. In a case study, we further show that ignoring input dependencies inflates the number of reported causes, 14.9% of which are spurious under our SCM.

## 1. 核心问题与整体含义（研究动机和背景）

- 论文旨在解决 **神经网络预测解释在输入特征具有结构化因果依赖时失效** 的问题。
- 现有解释方法（如特征归因 LIME/SHAP、最小充分集等）普遍隐含 **特征独立** 假设，但在实际场景中，输入特征往往存在因果依赖（如医疗症状约束诊断、高支出导致负现金流等）。忽略这些依赖，反事实解释可能直接改动下游变量而掩盖真正的根因，甚至产生虚假解释。
- 论文将解释形式化为 **Halpern–Pearl（HP）实际原因**，并使用 **布尔结构因果模型（SCM）** 对输入依赖进行显式建模，从而将"解释"定义为：**一组最小变量集合，在某个偶然性（contingency）下将其干预为反事实值，即可改变预测结果**。
- 核心挑战在于：同时搜索候选原因集合、偶然性组合、以及 NN 的预测变化，计算复杂度极高（该问题在布尔模型下为 NP 完全，一般模型下为 ΣP₂/DP₂ 完全）。现有工作要么只处理离散因果/逻辑模型，要么只解释无 SCM 结构的 NN，二者结合尚属空白。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：将"候选原因 + 偶然性"的枚举搜索转化为 **区域（region）级推理**。不是逐个检查干预与偶然性组合，而是将多个角色分配（自然/偶然/未定）打包成区域，通过边界传播判断整个区域是否可确认（确认因果成立）、可剪枝（因果不成立）或需继续细化。
- **SCM 建模**：使用布尔 SCM，每个内生变量由结构方程（AND/OR/NOT/XOR 组合）与外部变量（通过 XOR）决定；实际上下文确定所有变量的实际值及预测输出。
- **区间传播**：
  - 将布尔门函数松弛为 **多线性连续函数**（如 OR(a,b)=a+b−ab、AND(a,b)=ab、XOR(a,b)=a+b−2ab），在布尔输入下精确无误差；多线性函数在区间角点取得极值，保证区间紧致性。
  - 边界按 SCM 拓扑序传播，得到所有变量的区间；
  - 再通过 **区间边界传播（IBP）** 穿过神经网络（仿射层用区间算术，ReLU 映射为 [max(0,ℓ), max(0,h)]），得到输出边界 [ℓ, h]。
- **分支定界（BaB）**：
  - 对每个候选原因集 C（按大小递增枚举），初始区域中 C 变量取"原因"角色，其余变量为"未定"（同时涵盖自然与偶然两种可能）；
  - 对区域计算 NN 输出边界：若 [ℓ,h] ⊆ S（S 为接受集，如阈值区间），区域中所有输入仍满足 φ，则剪枝；若 [ℓ,h] ∩ S = ∅，则区域中的所有输入都推翻 φ，确认该候选为原因并记录最小偶然性；否则选择未定变量进行分裂（自然/偶然两个子区域），递归处理。
  - 候选按大小递增枚举，任何已确认原因的超级集被跳过，保证 AC3 最小性；已确认的最小偶然性用于剪枝更大偶然性区域，保证返回最小基数偶然性。
- **正确性**：定理 1 证明算法终止、返回所有满足 AC1–AC3 的实际原因、并为每个原因返回最小基数偶然性；该保证在 kmax 限制下保持（仅限不超过 kmax 的原因）。
- **复杂度**：最坏情况搜索空间为 O(3^|V|)（每个变量可为原因/偶然/自然），与全枚举同阶但额外产生内部未定区域；实际加速依赖分支剪枝提前掐断指数爆炸。

## 6. 主要结论与发现

- **CausEx BaB 在可扩展性上显著优于基线**：
  - 在 BA 图上，n ≤ 28 时全部在 180s 内完成（中位运行时间从 3.6s 增长到 34.5s）；n=30 时 33% 超时，n=32 时 88.9% 超时，n≥34 全部超时。
  - BF 在 n=20 勉强完成（中位 92.0s，而 CausEx BaB 为 5.8s），n≥22 全部超时；
  - ILP 从 n=8 起 89% 超时、n≥10 全部超时；
  - ACI 在小图上最快（n≤10），但 n=12 起急剧恶化，n≥16 全部超时。
  - 在 n=28、kmax=8 的实例上，最坏搜索空间达到 2.3×10^13 候选（原因，偶然性）对，CausEx BaB 可在 180s 内完成。
- **最小原因非唯一是普遍现象**：115 个成功运行中，68.7% 产生多个最小原因，13.0% 恰好一个，18.3% 无原因。因此，返回"所有"最小原因对审计与调试是必要的。
- **忽略输入依赖会产生大量虚假/非最小原因**：
  - 合成基准中，独立假设多找到 59% 的原因（平均大 20%），仅 33% 为真实最小原因；74.3% 在 SCM 下有效但非最小，5.0% 为虚假。
  - SNAP 案例中，独立假设使原因数从 23 翻倍到 50，其中 14.9% 在 SCM 下为虚假（重新计算派生节点后无法翻转预测）。
- **kmx 限制的实用性**：限制 kmax=8 时，CausEx BaB 扩展到 n=38 几乎全部完成，n=56 仍有个别实例在预算内；但 kmax=8 仅覆盖 59.4% 的未限制搜索找到的原因，说明需要权衡可扩展性与完整性。
- **分支选择显著影响效率**：默认的 width_large（选择最大区间宽度的未定变量）平均每个剪枝分支解决 51.2% 的未定变量，远超其他策略（3.7–16.9%），在最大规模下零超时。
- **运行时间对图密度、NN 大小不敏感**，主要由节点数驱动。

## 7. 优点

- **形式化框架清晰**：将 NN 解释问题严格对应到 HP 实际因果性的 AC1–AC3 条件，给出明确的形式化定义，并证明算法的完备性与最小性。
- **算法设计精巧**：利用布尔门多线性松弛在区间上保持精确极值，结合 IBP 与 BaB，将指数级枚举转化为大规模区域剪枝，理论复杂度与全枚举同阶但在实际中大幅剪枝。
- **完备性保障**：返回**所有**最小实际原因并提供最小基数偶然性（这是大多数启发式方法无法保证的），并与暴力枚举在全部共同完成实例上验证一致。
- **实验设计全面且公平**：对比基线包含暴力、ILP 和启发式三类；BF 进行了同等优化（超集剪枝、GPU 批处理、JIT 编译）；在 BA 和 ER 两类图上验证；进行了统计显著性检验；提供了大量消融与鲁棒性实验（分支策略、密度、连通性、kmx、NN 规模）。
- **案例研究具有实际意义**：SNAP 是真实决策系统，SCM 从法规逐条构建，直接展示"忽略依赖导致虚假原因"的实际危害，增强了工作的应用价值。
- **可操作副产品**：最小偶然性搜索直接得到 Halpern 责任度（1/(N+1)），提供额外信息。

## 8. 不足与局限

- **布尔 SCM 范围有限**：方法只适用于布尔（二值）变量，不能直接推广到连续 SCM；论文承认连续域需要重新定义干预空间与最小性，是重要的后续工作。
- **对 SCM 质量的依赖**：假设 SCM 忠实于真实领域且已给定。SCM 构建错误时，因果关系解释的正确性无从保证（论文在 SNAP 案例中也承认其 SCM 是简化版，忽略了一些扣减、州豁免等）。
- **NN 分析的精度限制**：依赖 IBP 区间传播，边界可能松弛；论文尝试了 β-CROWN 但未改善（单次计算更慢）。在布尔设定下 IBP 够用，但对于更紧边界或连续输入，仍需更精密的验证方法。
- **可扩展性上限仍然存在**：n=30 时已出现 33% 超时，n≥34 全部超时（未限制 kmax 时）；即使 kmax=8，n=56 也只 11% 完成。对更大图/更深网络仍有挑战。
- **实验统计力度有限**：每个配置仅 3 图 × 3 上下文，对高度随机化的 SCM/NN 生成过程，置信区间可能偏宽；某些配置因超时配对不足无法做显著性检验。
- **原因/偶然性的可解释性限制**：返回的原因可能包含派生节点（如 SNAP 的 eligible），实际决策者无法直接干预这些节点，降低可操作性；论文承认"返回的原因不是唯一正确或最可操作的解释"。
- **未披露完整算力成本**：未说明训练所有学生网络的总 GPU 时数、L40S 使用数量等，复现成本难以精确估计。
- **SNAP 案例样本偏差**：仅 11 个去重画像，且均为已认证家庭，不覆盖全部申请人群；14.9% 虚假率对该 SCM/预测器特定，不能一般化为 SNAP 总体估计。
