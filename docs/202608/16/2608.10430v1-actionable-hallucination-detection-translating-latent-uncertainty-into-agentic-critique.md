## 摘要
部署为AI智能体的大型语言模型（LLM）经常出现用户规范 grounding 失败，执行幻觉性的、非期望的动作以强行解决问题，而不是表达不确定性。现有检测方法无法提供可操作的实时纠正，因为它们要么无法定位幻觉，要么产生过高的推理延迟。我们引入了潜在批判器（Latent Critic），一种轻量级低秩适配器（LoRA），它与冻结的基础LLM生成过程并发运行，主动重构Transformer的残差流——放大潜在 grounding 信号并将其转化为同一序列内的局部化自然语言反馈。通过细化基础模型固有的不确定性信号，这种对潜在空间的操作实现了可靠的、细粒度的检测，而无需二次推理循环的开销。通过激活修补和逐层探测进行的机制分析表明，这种秩不变行为将预先存在的不确定性几何结构重构为线性可分离的表示，其迁移比仅使用基础模型表示更可靠。以工具调用作为细粒度幻觉的实例，我们验证了Latent Critic架构在基于Qwen和Llama的模型上实现的检测和下游改进。我们的方法展示了优越的实时效能，在隔离幻觉方面显著优于同等规模的微调外部检测器、语义熵基线和被动内部探针，实现了0.966 AUROC和>80%的定位准确率（例如，无根据的：日期）。当部署在闭环ReAct环境中时，批判器充当一个可忽略延迟的护栏，在执行前拦截幻觉以防止非期望动作，同时利用这种特定的局部化反馈来实现高效的智能体自我纠正。

## Abstract
Large Language Models (LLMs) deployed as AI agents frequently exhibit user specification-grounding failures, executing hallucinated, undesired actions to force a resolution rather than expressing uncertainty. Existing detection methods fail to provide actionable, real-time correction as they either do not localize the hallucinations, or incur prohibitive inference latency. We introduce the Latent Critic, a lightweight low-rank adapter (LoRA) that operates concurrently with a frozen base LLM's generation to actively restructure the transformer's residual stream---amplifying latent grounding signals and translating them into localized, natural language feedback within a single sequence. By refining the base model's native uncertainty signals, this manipulation of the latent space enables reliable, granular detection without the overhead of secondary inference loops. Mechanistic analysis via activation patching and layer-wise probing shows that this rank-invariant behavior restructures pre-existing uncertainty geometry into a linearly separable representation that transfers more reliably than base model representations alone. Using tool-calling as an instantiation of granular hallucinations, we validate the detection and downstream improvements enabled by the Latent Critic architecture across Qwen and Llama-based models. Demonstrating superior real-time efficacy, our approach significantly outperforms equivalent-scale fine-tuned external detectors, semantic entropy baselines, and passive internal probes in isolating hallucinations, achieving 0.966 AUROC and >80% accuracy in localization (e.g., ungrounded: date). When deployed in a closed-loop ReAct environment, the Critic acts as a negligible latency guardrail, intercepting hallucinations before execution to prevent undesired actions while simultaneously leveraging this specific localized feedback to enable efficient agent self-correction.

## 1. 核心问题与整体含义（研究动机与背景）

LLM 智能体在真实场景中面临**用户规范 grounding 失败（user specification-grounding failure）**：当用户的指令存在信息缺失或歧义时，模型不会停下来表达不确定性，而是倾向于“脑补”参数、强行完成任务，产生**未在对话历史中得到支持（explicitly 或 implicitly）的幻觉性动作**。这类幻觉与事实性幻觉不同——一个参数即使语义合理甚至事实正确（如猜了一个合法日期），只要用户从未提供，它依然是幻觉。

现有检测范式存在三重不足：
- **外部评估器（LLM-as-a-judge）和多次采样方法（如语义熵）**：基于表层文本，需要二次推理，延迟不可接受，无法满足智能体实时性要求；
- **被动内部探针（probing）**：只输出标量置信度，缺少可操作的局部化定位信息，无法支撑智能体精准自纠错；
- **不确定性采样方法**：由于模型对幻觉动作常常“自信满满”，输出的熵很低，检测容易失效——模型内部的潜在表示比表面 logits 携带更多 grounding 信息，但既有方法无法将其提取为行动指令。

## 2. 方法论

**研究问题（RQ）**：
- RQ1（检测）：能否通过修改残差流获得优于现有方法的幻觉定位能力？
- RQ2（机制）：适配器如何重构内部几何结构，将不确定性转化为可操作反馈？
- RQ3（部署）：智能体能否利用局部化反馈实现零样本自纠错？

**Latent Critic 架构核心设计**：
- 一个轻量 **LoRA 适配器**与冻结基座 LLM **并发**运行（multi-adapter serving），权重零初始化，初始前向与基座一致；
- 在工具调用语法生成期间，适配器接收相同输入 token 并修改隐藏状态、放大不确定性信号，但此时输出被忽略；
- 工具调用结束处追加**触发 token `[POS]`**，充当注意力汇聚点（attention sink），迫使适配器聚合并输出局部化诊断结果，如 `ok`、`wrong_tool`、`ungrounded: [parameter_name]`；
- 训练采用**掩码诊断目标（masked diagnostic objective）**：基座的工具调用生成部分被完全掩码，梯度只回传到 `[POS]` 及其后的标签 token，确保适配器仅作为“不确定性提取器”而非语法生成器；
- 推理时零额外推理循环，只增加单序列内 `[POS]` 及少数标签 token 的生成成本。

**机制层面的技术发现**（基于激活修补、层间探测、SVM 可分性分析等）：

## 6. 主要结论与发现

- **RQ1（检测）**：Latent Critic 是当前最强检测器——Qwen3-4B 上 ID AUROC 0.966、OOD 0.925；精确参数匹配率 >80%；1% FPR 下捕获 38.7% 幻觉（远超 Judge 28.3% 和 Probe 3.8%）。OOD F1 下降主要是基础率变化（35.0%→20.7%），并非检测能力退化。跨模型优势在 Llama-xLAM-2-8B 上对 passive probe 显著复制，但对外部 judge 的优势在漂移下呈现模型依赖性。
- **RQ2（机制）**：grounding 信号是后期层的几何特征，基座原始表示中已存在但脆弱、不可迁移；掩码诊断目标将之重塑为秩不变的、线性可分的、漂移稳定的几何结构；适配器对低秩线性投影足够，证明信号处于低维子空间。
- **RQ3（部署）**：局部化反馈（specific）远优于通用拦截（generic）——ID F1 提升至 61.2%、假拦截率 2.9%（比 generic 低 3×以上）、恢复率相对提升 54.8%、失败重试次数显著下降。检测误差主要源于基座自身生成崩溃（如 runaway generation）导致的信号污染，而非提取缺陷；部分“误报”实为更严格但对齐安全的判定（如未授权的内容填充）。
- **总体**：通过改造潜在表示，可以把幻觉检测从“事后观察”推进到“实时执行前拦截”，实现无需二次推理循环的可操作护栏。

## 7. 优点

- **定位-实时性兼顾**：在一个序列内既做检测又输出局部化参数名，打破了“检测准↔慢推理”与“定位↔低延迟”的二选一困境；
- **保留基座能力**：基座完全冻结，只挂轻量 LoRA，代理任务能力零损失，还天然可迁移到其他结构化任务；
- **机制证据链完整**：不止报指标，还用逐层探针、秩消融、跨轨迹激活修补证明“做什么、怎么做、为什么有效”，层次深且因果性强；
- **实验公平性严谨**：Judge 在完全对等的设置（数据、LoRA 超参、标签格式、训练时长）下训练，隔离了“读哪一层信息”这一核心变量；bootstrap、McNemar、操作点分析等细节到位；
- **正视失败并刻画边界**：主动披露了检测对基座状态质量的依赖、OOD 下与外部 judge 的差距、模拟用户标签的局限等，可信度高。

## 8. 不足与局限

- **基座状态依赖**：Critic 读到的是基座的内部状态，若基座自身未内化规范缺口（如生成崩溃、混乱的残差流），检测信号即被破坏——检测可靠性被基座能力“上界”锁定；
- **OOD 泛化的非对称性**：内部访问对 passive probe 的优势在跨模型（Llama）下显著，但对 external judge 的优势在漂移下不稳定，说明内部信号质量依赖具体模型；OOD 轨迹成功率接近基座天花板（~2%），只能做参数级改善，无法弥补基座规划与工具调用能力不足；
- **标签质量的残余风险**：训练集依赖程序化 + 模拟用户管道，评估集仅由一名标注者人工复核，主观偏差（如关于“可接受推测”的边界判断）未经多标注者一致性检验；
- **任务范围有限**：实验限定在结构化工具调用的参数 grounding，开放域文本生成中的 span 级幻觉定位仍是未解问题；wrong_tool 类的 OOD 评估因样本过小（n≈16）而统计力受限；
- **无真实世界部署验证**：所有闭环评估均在模拟环境中完成，现实用户的交互复杂度和环境噪声未被覆盖；恢复率仍然偏低（37% ID / 29.3% OOD），说明基座原生策略未能充分吸收反馈信息，尚需专门的恢复策略训练；
- **词法决定的混杂风险**：虽然论文做了词法可判定性分析反驳字符串匹配假说（词法基线 AUROC 仅 0.670/0.731），但该分析与“隐式推导”的语义边界判定仍依赖主观标注，存在定义边界上的模糊地带。
