## 摘要
当语言模型遵循上下文条件规则（如“如果P(x)则A否则B”）时，它是否会组装一个运行时电路，其中一个模块测试谓词，另一个模块路由答案？我们通过一种四供体设计的激活修补来探测这一点，其中两个交换规则供体使条件和答案词不一致，因此每一层都揭示其携带的两者中的哪一个。在来自两个家族的三个开放模型和共享一个固定题库的六种语言中，一个中堆栈残差带携带谓词的真值：修补它会以接近1.0的谓词结果翻转和接近0.0的映射翻转重新路由答案，在18个单元中的17个中满足严格的预先指定的隔离标准，并且相同的定位在五个谓词家族中成立。路由器显示出相反的轮廓。一个学习到的子空间在训练对内近乎完美地翻转A和B，但在每个模型中转移到新对时约为0，而在Gemma-3-4B（唯一跨语言探测的模型）中，它转移到其他语言的同一对时约为0.98。在我们运行的每次探测下，路由器方向都是绑定令牌且不可转移的（在Gemma中主要是答案读出，在Qwen中是对特定的），而不是一个抽象的路由模块。测试是模块化的；在这些探测下，路由不是。

## Abstract
When a language model follows an in-context conditional rule such as "if P(x) then A else B," does it assemble a runtime circuit with one module that tests the predicate and another that routes the answer? We probe this with activation patching under a four-donor design whose two swapped-rule donors make the condition and the answer word disagree, so each layer reveals which of the two it carries. Across three open models from two families and six languages sharing one fixed item bank, a mid-stack residual band carries the predicate's truth value: patching it reroutes the answer with predicate-outcome flip near 1.0 and mapping flip near 0.0, meeting a strict pre-specified isolation criterion in 17 of 18 cells, and the same localization holds across five predicate families. The router shows the opposite profile. A learned subspace flips A and B near-perfectly within the trained pair yet transfers to a new pair at approximately 0 in every model, while in Gemma-3-4B (the only model probed cross-lingually) it transfers at approximately 0.98 to the same pair in other languages. Under every probe we ran, the router direction is token-bound and non-transferable (largely answer-readout in Gemma, pair-specific in Qwen) rather than an abstract routing module. Test is modular; under these probes, route is not.

## 1. 论文的核心问题与整体含义

本文属于**机制可解释性（Mechanistic Interpretability）**研究，核心问题是：

> 当语言模型执行一个上下文条件规则（in-context conditional rule），如"如果P(x)则输出A，否则输出B"时，它是否会将这一计算分解为两个独立的模块——一个用于**测试谓词（TEST）**，另一个用于**路由答案（ROUTE）**？

这一问题的意义在于：
- 大多数已解析的电路（如间接宾语识别电路、归纳头）是**权重存储型**（weight-stored）的，即预训练阶段固化的可复用机制；而条件规则的文本、谓词和答案映射全部在推理时提供，执行它的电路必须**在运行时组装**，这属于更前沿的研究方向。
- 实际部署的提示词中充满这类条件逻辑（护栏、工具路由、条件策略），弄清"哪一半是模块化的"决定了哪些部分可以被审计和可移植地操控。
- 行为评估无法回答这一问题（正确的补全与两种组织方式都一致），必须借助因果干预手段。

**核心发现一句话概括**：测试是模块化的（可分离、可定位、跨模型跨语言稳定），而路由在这些探测下不是模块化的（token绑定、不可跨标签对转移）。

## 2. 论文提出的方法论

### 2.1 核心思想：四供体激活修补设计

论文的核心创新是**四供体（four-donor）激活修补设计**。对每个基础项（predicate TRUE, 答案 dog），构建四个提示词，交叉规则映射（标准/交换）与查询结果（TRUE/FALSE）：

| 供体 | 规则 | 查询 | 谓词真值 | 答案 | 作用 |
|------|------|------|----------|------|------|
| BASE | 标准 | TRUE | TRUE | dog | 参考运行 |
| O-DONOR | 标准 | FALSE | FALSE | cat | 仅翻转谓词结果 |
| MAP-DONOR | 交换 | TRUE | TRUE | cat | 仅翻转映射 |
| MAP-NULL | 交换 | FALSE | FALSE | dog | 大幅扰动但答案同BASE |

关键之处在于：在 **MAP-DONOR** 和 **MAP-NULL** 中，谓词真值与答案词**不一致**，因此修补某一层后观察输出跟随哪一方，就能揭示该层携带的是条件（TEST）还是答案（ROUTE）。

### 2.2 修补操作与指标

- **修补操作**：将供体在层 ℓ 的最后一个 token 位置的残差流向量复制到 BASE 运行中。
- **指标一：二向翻转概率**（带标签质量门控，≥0.30 才计为翻转，避免破坏性修补被误判）
- **指标二：摆动恢复分数**：R = (LD_patched − LD_base) / (LD_donor − LD_base)，其中 LD = logit(A) − logit(B)

### 2.3 路由分析的两类探针

1. **贪心头组修补**：对每个模型的读出带（readout band）内的注意力头做贪心累积。
2. **DAS-lite**（分布式对齐搜索的低秩变体）：在一个残差位点学习秩为 k ∈ {1,2,4,8} 的正交基，通过交换目标训练，用交换干预准确率（IIA）评分。

### 2.4 关键控制组

- 行为门控（准确率≥0.85）、供体正确性门控
- 扰动匹配的 2×2 隔离检验
- 子空间错觉防护（真实方向 vs 等范数随机方向）
- **跨标签对迁移控制**（路由器分析的决定性检验）：将 dog/cat 上训练的子空间应用于 fox/owl
- 相干零假设（NULL_CROSS）与向量零假设（NULL_VEC）

## 3. 实验设计

### 3.1 数据集与任务

- **任务**：规范的 if-then-else 条件规则模板（"如果数字大于5，输出dog，否则输出cat"），附8个上下文演示和一个数字查询，模型补全单个 token 答案。
- **共享题库**：一个固定的 250 项规范题库，所有实验单元（每个模型 × 每种语言）共用，避免不同随机样本的混淆。
- **多语言**：六种语言（英语、中文、印地语、印尼语、泰米尔语、僧伽罗语），覆盖四种文字系统；规则文本翻译，但**数字与答案 token（dog/cat）保持拉丁字母形式不变**，使翻转指标可解释且读出方向跨语言共享。
- **谓词家族**：数值阈值 t∈{3,5,7}、集合成员 x∈{2,3,5,7}、元音起始（词法谓词，非数值）。
- **扩展场景**：三输出变体（dog/cat/cow，循环旋转映射）、多 token 答案（子词拆分与双词短语）、策略-动作标签对（block/allow, flag/approve）。

### 3.2 模型

三个开源模型，跨两个家族：

## 6. 论文的主要结论与发现

1. **TEST 是可分离的模块**：在 18 个单元中的 17 个中，单个中堆栈残差带修补 O-DONOR（仅翻转谓词真值）后以 ≈1.0 概率重路由答案，而 MAP-DONOR 几乎不翻转（≈0.0），满足严格隔离标准。TEST 峰值跨语言、跨家族稳定（Gemma-4B L21–22、Gemma-12B L27–28、Qwen L23–27）。

2. **存在清晰的阶段边界**：以 Gemma-3-4B 为例，L22→L23 处模式反转——带内修补遵循条件，带外遵循答案；谓词先在查询数字位（L14–15）计算，再移至最后 token。

3. **ROUTE 不可分离、不可迁移**：DAS-lite 子空间在训练对内 IIA=1.00，但转移至新标签对时 ≈0（三个模型全部如此）。**如果没有迁移控制，这个完美的对内结果会错误地认证一个虚假路由器**。方向性质因模型家族而异：Gemma 中与答案读出方向中等对齐（cosine 0.15–0.39），Qwen 中与读出方向近乎正交（0.01–0.09）。

4. **路由器方向是 token 绑定但语言不变的**：英语训练的 dog/cat 子空间迁移到新标签对失败（≤0.013），但迁移到泰米尔语和中文的同一对时几乎完美（0.97–1.00）。

5. **机制是通用谓词测试**，而非特定于"大于5"：五个谓词家族（含非单调集合成员、非数值元音谓词）均产生相同的 TEST 带。

6. **三输出规则扩展成功**：同样的 TEST 带（L18–22）和 L22→L23 边界在 dog/cat/cow 三输出变体中复现。

## 7. 优点

- **方法论创新性强**：四供体设计让条件和答案词"不一致"，从而逐层读出携带的是条件还是答案——这是对传统激活修补的巧妙推广，且可泛化到三输出（循环旋转）。
- **跨维度验证的系统性**：3 模型 × 6 语言 × 5 谓词家族 × 2 标签对 × 多 token × 三输出，覆盖面广，且共享固定题库消除了抽样混淆。
- **控制组设计严谨**：预注册阈值、行为门控、供体正确性门控、子空间错觉防护、相干零假设、标签质量门控——将虚假信号的可能来源逐一排除。
- **迁移控制是点睛之笔**：指出"对内 IIA=1.00 就声称找到路由器"是幻象，跨对迁移失败揭穿了虚假子空间，这对整个可解释性领域有方法论的警示价值。
- **跨语言设计巧妙**：答案 token 保持拉丁字母，将"语言"变量与"读出接口"解耦，使跨语言比较干净可信；泰米尔语和僧伽罗语首次进入机制定位研究。
- **实操指向明确**：讨论了谓词级 vs 答案级操控的可移植性差异，为实际部署中的激活引导提供了参考。

## 8. 不足与局限

- **模型覆盖面有限**：仅三个开源中等规模模型（最大 12B），无法修补闭源模型，不能断言前沿规模的结论。
- **任务高度合成化**：刻意控制的模板任务（固定句式、拉丁答案 token），与真实自由形式补全有距离；本地文字的答案标签、组合谓词、自由补全仍待研究。
- **12B 路由器证据较弱**：Gemma-3-12B 的全带头部修补近乎无效（Φ=0.09），其迁移负结果仅依赖子空间方法。
- **跨语言探测不完整**：仅 Gemma-3-4B 做了跨语言迁移；每个语言的子空间训练未重复，小样本声明（32 训练/16 测试）虽有追加大样本验证但仍属单一种子、单一站点。
- **Qwen 的方向性质未完全解释**：论文称其方向"既不对齐读出也不迁移"，但未深入阐明这对特定方向到底是什么、如何产生。
- **语言覆盖非类型学完整**：六种语言在脚本和资源上有差异，但远未覆盖类型学空间。
- **IOI 对比只是暗示性证据**：Gemma-3-4B 中 IOI mover 本身弱且分布化，对比结论"建议性而非决定性"。
- **未做跨阈值修补实验**：作者自认"跨阈值修补"才能最终证明 TEST 带携带的是"被评估的真值"而非"被重定位的查询数字"。
- **单一种子**：每个单元报告中单次运行，虽有 McNemar 检验支撑显著性，但无法完全排除随机波动。

**总体评价**：这是一项方法严谨、证据多层次的机制可解释性研究，核心贡献在于提出"让条件与答案不一致"的供体设计并以此揭示了 TEST/ROUTE 的不对称模块性；其"可迁移性检验"思路对子空间识别类研究具有广泛的方法论价值，但模型规模和任务范围的限制使其结论的普适性仍有待验证。
