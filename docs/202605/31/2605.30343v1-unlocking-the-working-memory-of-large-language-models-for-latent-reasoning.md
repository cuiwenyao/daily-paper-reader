## 摘要
为了提升大语言模型的推理能力，通常会在最终答案之前生成中间令牌来扩展测试时计算。然而，这将推理与自回归生成耦合在一起，从而混淆了内部计算与外部通信。相比之下，人类认知可以利用工作记忆在内部保持和操作信息，而无需将中间思考外化。基于这一原理，我们引入了记忆推理（RiM），这是一种潜在推理方法，用记忆块取代推理步骤的自回归生成。这些记忆块是固定序列的特殊令牌，能够解锁大语言模型的工作记忆容量。由于它们是固定的而非生成的，因此可以在单次前向传播中处理，从而实现计算高效的潜在推理。为了操作这些记忆块，我们采用了两阶段课程。首先，通过在每个记忆块后预测显式推理步骤来对它们进行接地。其次，丢弃这种步骤级别的监督，并在每个记忆块后迭代优化最终答案。我们在推理基准上的实验表明，对于不同系列和大小的语言模型，RiM在避免自回归生成思考的同时，匹配或超越了现有的潜在推理方法。这些结果表明，大语言模型可以被训练为使用工作记忆作为潜在推理的有效机制。

## Abstract
To improve the reasoning capabilities of large language models, test-time compute is typically scaled by generating intermediate tokens before the final answer. However, this couples reasoning to autoregressive generation and thereby conflates internal computation with external communication. In contrast, human cognition can use working memory to hold and manipulate information internally without the need to externalize intermediate thoughts. Drawing on this principle, we introduce Reasoning in Memory (RiM), a latent reasoning method that replaces the autoregressive generation of reasoning steps with memory blocks. These memory blocks are fixed sequences of special tokens that unlock the working-memory capacity of large language models. Since they are fixed rather than generated, they can be processed in a single forward pass, enabling compute-efficient latent reasoning. To operationalize these memory blocks, we employ a two-stage curriculum. First, we ground them by predicting explicit reasoning steps after each memory block. Second, we discard this step-level supervision and iteratively refine the final answer after each memory block. Our experiments on reasoning benchmarks show that, across language models of different families and sizes, RiM matches or exceeds existing latent reasoning methods while avoiding the autoregressive generation of thoughts. These results demonstrate that large language models can be trained to use working memory as an effective mechanism for latent reasoning.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有大语言模型（LLM）推理方法通常通过自回归生成中间token（如Chain-of-Thought）来扩展测试时计算，但这将内部计算与外部通信耦合，导致计算效率低下，且部分计算被用于生成语法流畅的文本而非纯粹推理。虽然潜在推理方法（如Coconut）用连续表示代替离散token，但仍遵循自回归生成范式，无法避免逐步生成的外部化开销。
- **核心问题**：能否让LLM像人类一样，利用“工作记忆”（working memory）在内部保持和操作任务相关信息，而无需将中间思考过程外化？
- **整体含义**：本文提出**Reasoning in Memory (RiM)**，证明LLM可以被训练使用固定记忆块作为潜在工作记忆进行推理，从而解耦内部计算与自回归生成，实现计算高效、可并行化的潜在推理。

## 2. 方法论

- **核心思想**：用**固定序列的特殊token（记忆块，memory blocks）** 替代自回归生成的推理步骤。这些记忆块是固定的输入token（如`<b> <m> <m> </b>`），但它们的上下文表示随任务变化，可编码中间推理信息。由于记忆块固定，整个序列可在单次前向传播中处理，避免了自回归生成瓶颈。
- **关键技术细节**：
  - 记忆块由分隔符`<b>`、`</b>`和多个`<m>` token组成（默认M=2个`<m>`）。
  - 冻结预训练token嵌入，只更新特殊token的嵌入，避免干扰。
  - 使用**自定义注意力掩码**：记忆块可关注问题和之前记忆块，但推理步骤读出头不能关注其他读出头，保证所有读出头可在单次前向传播中训练而无信息泄漏。
  - **两阶段课程**：
    - **Stage 1（推理步骤监督）**：每个记忆块后监督预测下一个推理步骤，强迫模型将中间计算存入记忆块。采用加权负对数似然损失，监督强度随训练步数线性退火。
    - **Stage 2（最终答案精炼）**：去除推理步骤监督，每个记忆块后直接预测最终答案，使用固定数量的记忆块（默认K=8），鼓励模型利用已学的工作记忆逐步改进答案。
  - 阶段切换时重置优化器状态和学习率调度器，并使用较低学习率和增加dropout。

## 6. 主要结论与发现

1. **RiM有效诱导潜在计算**：表征分析显示，记忆块表示在训练中变得结构化、块特异且样本相关，证明模型确实使用记忆块作为工作记忆进行潜在推理。
2. **性能优越**：在贪心准确率和Pass@8上，RiM的最终块读出头一致优于Coconut和SFT w/o CoT，且任意块读出头接近甚至超过SFT w/ CoT（但后者延迟高27倍）。例如，Llama-3.2-1B上，RiM在GSM8K达到42.1%（Coconut w/ Stage 0为36.9%），GSM-Hard达到10.5%（Coconut为8.5%）。
3. **延迟极低**：RiM的TTFT与SFT w/o CoT相同（如Llama-3.2-1B均为16.1ms），而Coconut慢约7倍，SFT w/ CoT慢约27倍。
4. **鲁棒性强**：Stage 2后，改变记忆块数量或大小，准确率保持稳定（约43%）。
5. **两阶段课程必要性**：单独Stage 1或Stage 2效果均不如完整两阶段；第1阶段接地记忆块，第2阶段转换优化方向。
6. **线性探针可识别正确答案**：从记忆块表示中可高置信度选择正确读出头（准确率90%），揭示正确性信息存储在潜在状态中。

## 7. 优点

- **创新性**：首次将“工作记忆”概念引入LLM潜在推理，用固定记忆块替代自回归生成，从根本上改变推理计算模式。
- **高效性**：单次前向传播即可完成推理，避免序列生成瓶颈，实现计算并行化，显著降低推理延迟。
- **简单性**：两阶段课程仅使用标准下一token预测损失，无需额外模块或复杂蒸馏路径，便于实现和复现。
- **通用性**：在GPT-2和Llama系列上均有效，且跨模型规模表现一致。
- **实验严谨性**：采用交叉验证、选择过拟合防护、丰富消融和表征分析，结果可信度高。

## 8. 不足与局限

- **评估范围有限**：仅测试数学推理（GSM8K系列），未验证在科学、常识、符号推理等更广泛任务上的推广性。
- **可解释性挑战**：潜在推理过程隐藏于记忆块表示中，不如显式CoT可审计，可能影响可信度与调试。
- **模型规模上限未探索**：仅测试到3B模型，更大模型（如7B、70B）上的表现未知；小模型上可能无法充分利用工作记忆。
- **训练成本**：尽管推理高效，但Stage 1需要完整推理步骤作为监督数据，对于没有显式步骤标注的任务可能难以应用。
- **Stage 2固定记忆块数量**：论文固定K=8，但对更复杂问题可能需要更多记忆块，最优数量如何自适应选择未研究。
- **潜在偏见**：训练数据GSM8K-Aug为结构化数学表达式，与自然语言推理可能有差异；且训练集可能存在数据分布偏差。
- **阶段切换敏感性**：需要精确控制第一阶段训练步数，过早或过晚切换可能影响性能（实验中通过消融验证但未提供自动切换策略）。
