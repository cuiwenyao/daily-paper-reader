## 摘要
在高风险领域部署的LLM面临根本性的可靠性挑战：幻觉、不一致和隐私漏洞会带来不可接受的风险，因为错误会产生法律、财务或安全后果。本文提出了一种混合验证架构，将形式符号方法与神经语义分析相结合，为LLM生成的内容提供互补的保证。该架构采用逻辑推理进行输入验证，利用完备性属性对结构化需求提供可判定的保证。对于输出验证，基于嵌入的语义相似性检测形式方法缺乏表达能力的上下文幻觉。这种分离在一个并行的、基于角色的管道中实现，解决了基于提示的自验证方法的局限性，后者继承了产生幻觉的分布偏差。所提出的架构和类型感知验证方法通过HAIMEDA（一个通过行动设计研究开发的真实世界医疗设备损坏评估报告系统）进行了验证。评估显示，对结构化实体的幻觉检测率超过83%，对语义捏造的检测率为72%，报告创建时间减少了30%，表明神经符号架构可以为数据敏感领域的LLM部署提供原则性的保障。

## Abstract
LLMs deployed in high-stakes domains face fundamental reliability challenges: hallucinations, inconsistencies, and privacy vulnerabilities introduce unacceptable risks where errors carry legal, financial, or safety consequences. This paper presents a hybrid verification architecture combining formal symbolic methods with neural semantic analysis to provide complementary guarantees for LLM-generated content. This architecture employs logical reasoning for input verification, leveraging completeness properties to provide decidable guarantees on structured requirements. For output validation, embedding-based semantic similarity detects contextual hallucinations where formal methods lack expressiveness. This separation is realized in a parallel, actor-based pipeline, addressing limitations of prompt-based self-verification approaches, which inherit the distributional biases that produce hallucinations. The proposed architecture and type-aware verification method are validated with HAIMEDA, a real-world medical device damage assessment reporting system developed through Action Design Research. Evaluation shows hallucination detection rates of over 83% for structured entities and 72% for semantic fabrications, with a 30% reduction in report creation time, demonstrating that neuro-symbolic architectures can provide principled safeguards for LLM deployment in data-sensitive domains.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）在医疗、法律、金融等数据敏感领域部署时面临根本性可靠性挑战：幻觉（3%-10%）、信息不一致、隐私泄露，这些错误会带来法律、财务或安全后果。

- **研究目标**：提出一种混合验证架构，将形式符号方法（可判定、完备的约束检查）与神经语义分析（捕获语义相似性）相结合，为LLM生成内容提供原则性保障，并在真实数据敏感场景中验证。

## 2. 论文提出的方法论：核心思想与关键技术

### 核心思想
- **任务分解**：形式逻辑用于输入验证（提供可判定保证），神经语义用于输出验证（处理自然语言不确定性），两者通过并行、基于角色（actor model）的管道隔离执行。
- **类型感知验证**：结构化实体（日期、标识符、数值）使用确定性符号比较；自由文本语句使用嵌入相似度评分，两者按验证确定性赋予不同权重。

### 关键技术细节
1. **表格法（Tableaux）输入验证**（Algorithm 1）：
   - 将验证条件编码为命题逻辑公式，通过α展开（与）和β展开（或）分解为集合操作（交、并、补）。
   - 核心条件（C）程序化求值；高阶条件（H）通过表格法推理得出满足状态。
   - 硬停止规则：必需条件必须全部满足；软警告规则：累计极性不匹配数量不超过阈值。
   - 示例：`φ_cready ≡ (c_devtype ∧ c_serial ∧ c_category) ∨ (c_category ∧ c_damage_desc ∧ c_party)` 表示两种备选证据路径。

2. **基于角色的并发模型**：
   - 采用Erlang虚拟机（BEAM）上的Elixir语言实现，每个验证组件作为独立actor，通过消息传递通信。
   - 监督树管理：单个组件失败（如嵌入超时）仅重启该worker，不污染其他符号验证状态。
   - 功能不可变性保证数据流可重复，避免竞态条件。

3. **混合验证策略**：
   - **预处理门控**：表格法验证通过后才允许LLM推理。
   - **后处理验证**：实体提取后，结构化实体用正则模式匹配（确定性），语句用Sentence-BERT嵌入（余弦+欧氏+TF-IDF+关键词）共识评分，分为5级（Exact/Strong/Moderate/Weak/No match）。
   - **并行混合缩小**：符号查询提取案卷ID、章节类型，先过滤语料范围，再神经排序，减少小模型对检索噪声的敏感度。
   - **隐私保护**：全部本地推理、嵌入、验证；敏感数据替换为占位符；审计日志只记录决策不记录内容。

4. **领域适应**：使用LoRA对Llama3-DiscoLeo-Instruct-8B进行参数高效微调，训练语料899份历史医疗设备评估报告，全在本地硬件完成。
