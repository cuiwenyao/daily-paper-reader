## 摘要
大型语言模型（LLMs）常面临幻觉问题，并且在需要多跳领域知识的复杂推理任务中表现挣扎。虽然集成知识图谱（KGs）提供了结构化且可验证的信息源，但当前KG增强的LLM范式通常依赖单智能体路径提取和固定提示，缺乏适应性并面临巨大的搜索空间。为应对这些挑战，我们提出了RACER，一种用于知识图谱可解释推理的强化智能体协作框架。RACER采用语义感知的动作剪枝和教师引导的强化学习机制，从大规模KG中高效提取高质量的推理路径。此外，为缓解单路径生成的缺陷，我们引入了跨任务累积共享记忆图，并配以注意力驱动的多路径知识精炼模块。最后，RACER通过四角色多智能体协作系统（GraphAgent、TemplateAgent、AnswerAgent和CriticAgent）编排这些组件，以动态优化提示并评估答案。在CommonsenseQA和OpenBookQA数据集上的广泛实验表明，RACER显著优于最先进的KG增强LLM基线，平均提升5%，提供了稳健且高度可解释的推理能力。

## Abstract
Large Language Models (LLMs) often suffer from hallucination and struggle with complex reasoning tasks requiring multi-hop domain knowledge. While integrating Knowledge Graphs (KGs) provides a structured and verifiable information source, current KG-enhanced LLM paradigms usually rely on single-agent path extraction and fixed prompting, lacking adaptability and facing huge search spaces. To address these challenges, we propose RACER, a Reinforced Agent Collaboration framework for Explainable Reasoning on knowledge graphs. RACER employs a semantic-aware action pruning and teacher-guided reinforcement learning mechanism to efficiently extract high-quality reasoning pathways from large-scale KGs. Furthermore, to mitigate single-path generation pitfalls, we introduce a cross-task accumulated shared memory graph paired with an attention-driven multi-path knowledge refinement module. Finally, RACER orchestrates these components through a four-role multi-agent collaboration system (GraphAgent, TemplateAgent, AnswerAgent, and CriticAgent) to dynamically refine prompts and evaluate answers. Extensive experiments on CommonsenseQA and OpenBookQA datasets demonstrate that RACER significantly outperforms state-of-the-art KG-enhanced LLM baselines with an average improvement of 5\%, offering robust and highly interpretable reasoning capabilities.

## 2. 论文提出的方法论

- **总体架构**：RACER 由三大模块组成，并以四角色多智能体系统协作执行完整推理流程：
  1. **语义剪枝知识图谱强化学习（Semantic-Pruning KG RL）**
  2. **共享记忆图与注意力驱动的知识精炼（Shared Memory Graph + Dual Attention）**
  3. **多智能体协作推理框架（Multi-Agent Collaboration）**
- **核心思想与技术细节**：
  - **语义感知动作空间剪枝**：将查询、候选实体和关系编码到统一语义空间，用余弦相似度计算每个动作的复合得分：
    \[
    \text{score}(n_i, r_i) = \alpha \cdot \text{sim}(r_i, q) + \beta \cdot \text{sim}(n_i, q) + \gamma \cdot \text{sim}(n_i, g)
    \]
    选择 Top-K 动作，显著压缩搜索空间，同时保证候选与查询语义对齐。
  - **教师引导的策略梯度训练**：使用 BFS 计算的最短路径作为教师轨迹，以概率 \(p_{\text{teacher}}\) 跟随教师动作，其余概率通过 RL 策略采样，并在教师步给予固定奖励 \(R_{\text{teacher}}=1.0\)，加速策略收敛并提升泛化能力。
  - **复合奖励函数**：由四项组成：
    - 基础步数惩罚 \(r_{\text{step}}\)（负常数，避免过长路径）
    - 关系相似度奖励 \(r_{\text{rel}} = \lambda_{\text{rel}} \cdot \text{sim}(r_t, q)\)
    - 目标导向稠密奖励 \(r_{\text{goal}} = \lambda_{\text{goal}} \cdot (\text{sim}(v_{t+1}, g) - \text{sim}(v_t, g))\)
    - 到达目标奖励 \(r_{\text{reach}}\)（成功到达时给予正奖励）
    - 总奖励：\(R = r_{\text{step}} + r_{\text{rel}} + r_{\text{goal}} + r_{\text{reach}}\)
  - **共享记忆图**：为每条边记录统计量 \(\{\text{succ}, \text{fail}, \text{reject}\}\)，计算边质量分数：
    \[
    \text{score}(e) = \frac{\text{succ}(e)+1}{\text{freq}(e)+2} - \gamma \cdot \frac{\text{reject}(e)}{\text{total}(e)}
    \]
    用于重新排序候选动作，缓解局部最优，并实现跨任务知识积累。
  - **多路径生成**：前半段使用温度采样增强多样性，后半段使用贪心策略保证质量，生成 N 条候选路径。
  - **注意力驱动的路径精炼**：使用双注意力网络（跨路径自注意力 + 查询-路径交叉注意力），并引入可学习的路径重要性评分器，综合选出 Top-k′ 条高质量路径，输入后续模板生成。
  - **四角色多智能体协作**：
    - **GraphAgent**：负责RL路径搜索与知识精炼，输出知识三元组序列；
    - **TemplateAgent**：将三元组转为自然语言知识段落（3-6句）；
    - **AnswerAgent**：基于知识段落与问题，输出最终答案（单一字母）；
    - **CriticAgent**：审查推理过程，输出决策 ACCEPT/UNSURE 和置信度；若为 UNSURE 则触发反馈循环，让 GraphAgent 探索其他分支，同时在共享记忆图中记录失败路径以避免重复循环。
  - 协作过程设有最大轮数（max_turns=3）以防止死循环。
