## 摘要
符号回归寻求发现简洁的数学表达式，以表示数据中的基本关系，其可解释性和科学理解超越了黑盒模型。然而，遗传编程等传统方法面临可扩展性挑战且对噪声高度敏感，而SINDy等稀疏回归技术则严重依赖于预定义的特征库。在这项工作中，我们提出了一个神经符号回归框架，将神经网络视为符号发现的函数预处理器。我们的方法采用解耦流程：神经网络首先在交互感知的非线性特征空间中学习目标函数的光滑、抗噪声近似。然后应用LASSO提取稀疏、可解释的闭式表达式。通过集成分布式超参数优化与Ray Tune和ASHA调度来提高预测精度和符号保真度。在Nguyen基准测试集上的实验表明，我们的方法在均方根误差、噪声鲁棒性和分布外泛化方面始终优于SINDy和未调优的神经基线。消融研究证实了特征交互、神经网络深度和调优策略的重要性。总体而言，本研究提出了一个可扩展且可理解的神经符号框架，为科学机器学习中的神经逼近与稀疏方程发现之间建立了坚实的联系。

## Abstract
Symbolic Regression (SR) seeks to find succinct mathematical expressions that represent the fundamental relationships within data, providing interpretability and scientific understanding that exceeds that of black-box models. Nevertheless, traditional methods like Genetic Programming face challenges with scalability and are highly sensitive to noise, while sparse regression techniques such as SINDy rely significantly on predetermined feature libraries. In this work, we present a Neural Symbolic Regression (NSR) framework that treats neural networks as functional preconditioners for symbolic discovery. Our approach uses a decoupled pipeline: a neural network first learns a smooth, noise-robust approximation of the target function in an interaction- aware nonlinear feature space. LASSO is then applied to extract sparse, interpretable closed-form expressions. To improve predictive accuracy and symbolic fidelity by integrating distributed hyperparameter optimization with Ray Tune and ASHA scheduling. Experiments on the Nguyen benchmark suite show that our approach consistently outperforms SINDy and non-tuned neural baselines in RMSE, noise robustness, and out-of-distribution generalization. Ablation studies confirm the significance of feature interactions, neural depth, and tuning strategies. In general, this study presents a scalable and understandable neural-symbolic framework, creating a solid link between neural approximation and the discovery of sparse equations for scientific machine learning.

## 1. 核心问题与研究背景
符号回归（Symbolic Regression, SR）的核心目标是自动发现能够描述数据内在规律的简洁数学公式，从而提供黑箱模型无法比拟的可解释性和科学洞察力。其研究动机与背景如下：

- **传统方法的局限**：
  - **遗传编程（Genetic Programming）**：虽具有高表达力，但收敛速度慢、计算开销大、易产生代码膨胀（code bloat），且在高维或含噪真实数据上扩展性受限。
  - **稀疏建模方法（如SINDy）**：将符号回归转化为基于预定义非线性特征库的稀疏回归问题，规避了组合搜索的困难，但其性能高度依赖人工设定特征库的表达能力，难以捕捉复杂的非线性交叉关系。
- **深度学习驱动的符号回归方法**（如DSR、AI Feynman等）：虽然提升了灵活性和扩展性，但通常将函数逼近与符号发现耦合在单一优化流程中，导致训练不稳定、计算成本高，且难以保持符号解释性的可控性。
- **与NSR的关系**：NSR受神经符号混合方法启发，但在理念上做出显著调整——不再让神经网络直接生成符号表达式，而是将其视为符号回归的函数预处理器，服务于后续的稀疏提取。
- **配套技术背景**：论文还借助了压缩感知、LASSO稀疏回归、超参数自动优化（Ray Tune + ASHA）等既有技术，构建了完整的混合流水线。

## 2. 研究方法（Methodology）

### (1) 核心思路
NSR采用**解耦流水线**：先用神经网络对目标函数做平滑抗噪的近似逼近，再从该近似中通过LASSO回归提取符号表示，实现**神经逼近与符号发现的显式功能分离**。

### (2) 完整流程（对应Algorithm 1）
1. **构建主特征库** Φ(X)：对输入各维度施加基础函数集 F = {恒等, sin, cos, exp, log(1+x), x², x³, tanh}。
2. **加入相互作用项** Φ⁽²⁾(X)：生成形如 fₚ(xₐ)·f_q(x_b) 的二阶交叉特征（a≠b）。
3. **形成完整特征矩阵** Φ_full = Φ ∪ Φ⁽²⁾，总维度为O(kd + k²C(d,2))；使用Joblib并行加速构建。
4. **神经网络预逼近**：训练MLP以Φ_full为输入拟合目标y，通过GPU（CUDA/MPS）加速。
5. **LASSO稀疏提取**：对训练好的目标拟合执行LASSO回归，获得稀疏系数β。
6. **符号重建**：用SymPy将非零系数对应的项组合为解析表达式。

### (3) 关键实现细节
- **神经网络结构**：L∈{1,2,3}个隐藏层，宽度H∈{32,64,128}，ReLU/GELU激活，配合dropout和权重衰减。优化器为AdamW，目标函数为 MSE + α‖θ‖₂²。
- **LASSO目标**：β\* = argminᵦ(‖Φ_full(X)β − y‖₂² + λ‖β‖₁)。理论依据是压缩感知的RIP条件，支撑稀疏恢复的可行性。
- **超参数搜索空间**：
  - 学习率η ∈ LogUniform(10⁻⁴, 10⁻²)
  - 隐藏层宽度H ∈ {32, 64, 128}
  - 层数L ∈ {1, 2, 3}
  - LASSO正则λ ∈ {10⁻⁴, 10⁻³, 10⁻²}
  - 批大小 ∈ {32, 64, 128}
- **剪枝策略（ASHA）**：若试验当前验证损失优于中位数的一定比例—— mᵢ < γ·median(m)，则继续训练，否则提前终止。

## 6. 主要结论与发现

- **预测精度**：调优后的NSR在Nguyen-1、Nguyen-2、Nguyen-3上均优于PySR和SINDy，获得最低RMSE；尽管PySR在Nguyen-4上表现更佳，但其在含噪多项式任务上稳定性欠佳，而NSR表现更为稳健。

- **噪声鲁棒性**：在噪声水平增大的情况下，NSR的误差增幅比SINDy更平缓，显示神经网络预平滑过程确实能提升抗噪能力。
- **OOD外推能力**：训练区间[−1,1]推广至[−2,2]的过程中，NSR仍保持了良好的预测性能，而SINDy出现明显偏差。说明NSR学到的是函数结构而不是简单记忆训练数据。
- **超参数优化的价值**：Ray Tune+ASHA有效缩短收敛时间并提高最优精度与符号简洁性；消融结果显示未调优模型RMSE显著上升（0.004→0.019），所选符号项数也不理想。
- **特征库与交互项**：完整库与二阶交互项对多变量基准的恢复至关重要（若移除交互项RMSE从0.004升至0.037；特征库简化后高达0.142）。
