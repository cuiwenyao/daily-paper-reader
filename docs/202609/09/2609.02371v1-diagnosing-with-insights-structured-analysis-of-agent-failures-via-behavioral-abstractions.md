## 摘要
随着LLM智能体的激增，理解和诊断智能体失败的能力对于实现卓越的有效性和可信度至关重要。由于智能体失败通常通过漫长而复杂的轨迹体现，手动在大量数据中寻找线索是不可行的。然而，传统软件缺陷诊断技术难以应对LLM智能体失败，而完全依赖LLM作为评判者则会产生不可靠的诊断结果。为克服这些挑战，本文提出AGENTSCOPE，一种用于智能体失败模式诊断的新型神经符号方法。AGENTSCOPE的关键原则是基于智能体的轨迹，将其行为抽象为结构化表示。此外，AGENTSCOPE引入神经不变量的概念来指定智能体行为属性。AGENTSCOPE利用基于LLM引导的推理，在结构化表示上对照神经不变量，精确定位轨迹中的失败步骤及其类型。我们在公开可用的智能体失败数据集（Who&When）以及我们创建的更全面的数据集（AgentErrata）上展示了AGENTSCOPE的有效性，其中AGENTSCOPE在故障定位和归因准确性上显著优于当前最先进方法。我们的工作表明，将结构化抽象与LLM引导推理相结合，能够为智能体失败提供有效、可靠且可解释的诊断。

## Abstract
With the proliferation of LLM agents, the ability to understand and diagnose failures in agents is essential to achieving superior effectiveness and trustworthiness. As agent failures often manifest via long and complex trajectories, manually finding the needles in the haystack is untenable. However, traditional diagnosis techniques for software bugs can hardly address LLM agent failures, while completely relying on LLMs as the judge yields unreliable diagnosis results. To overcome these challenges, this paper presents AGENTSCOPE, a new neuro-symbolic approach for agent failure mode diagnosis. The key principle of AGENTSCOPE is to abstract agent behavior, based on its trajectories, into structured representations. Furthermore, AGENTSCOPE introduces the concept of neural invariants to specify agent behavior properties. AGENTSCOPE leverages LLM-guided reasoning atop the structured representation against neural invariants to pinpoint both the failure step and its type in the trajectory. We show the effectiveness of AGENTSCOPE on publicly available agent failure datasets (Who&When) and a more comprehensive dataset created by us (AgentErrata), where AGENTSCOPE significantly outperforms the current state of the art in fault localization and attribution accuracy. Our work shows that integrating structured abstractions with LLM-guided reasoning enables effective, reliable, and interpretable diagnosis for agent failures.

## 2. 方法论：AGENTSCOPE

### 2.1 核心思想
- 将智能体轨迹从原始文本抽象为**结构化行为图（Reasoning-Action Graph, ReAG）**，再通过**神经不变量**（neural invariants）形式化刻画行为正确性，由LLM在ReAG上进行受控推理，检测不变量违反，从而定位根因步骤并归因失败类型。

### 2.2 关键技术细节

#### （1）行为抽象：ReAG
- ReAG定义为有向无环图 \(G=\{V,E\}\)。
  - 顶点 \(v_i = \langle id_i, r_i, c_i, I_i\rangle\)，分别表示步骤ID、角色、操作内容、**中间语义表示（ISR）**。
  - 边表示步骤间的控制/数据依赖关系。
- ISR由三部分构成，用于克服长上下文和冗余问题：
  - \(C_i\)：意图与上下文（任务目标、指令、步骤目的）；
  - \(R_i\)：推理与动作（决策摘要、工具调用、输出）；
  - \(S_i\)：信号与验证（知识使用、置信度、终止信号）。
- 通过API/工具/日志插桩构造图节点，再以LLM进行语义解析，统一非结构化日志为带注释的结构图。

#### （2）神经不变量
- 扩展传统程序不变量概念，允许用**神经函数**（即调用通用LLM的任务特定提示）来编码语义条件，用于验证行为正确性。
- 依据失败模式分类法（三类十种）定义对应不变量违反：
  - **推理类**：Wrong Context、Instruction Unfollowing、Insufficient Context、Context Miss；
  - **控制流类**：Termination Miss、Premature Termination、Step Loop；
  - **动作类**：Action Mismatch、Invocation Issue、Execution Failure。
- 示例：Action Mismatch违反条件为存在动作节点 \(n_t\) 与前序推理节点 \(n_{t-1}\) 不满足 `aligned(purpose, action, tool_name, tool_args)`。每个神经函数都有专门设计的prompt（如aligned()的prompt模板），要求输出JSON格式（是否违规及原因）。

#### （3）三阶段流水线
1. **ReAG构建**：将运行时轨迹转换为统一、对齐的结构化表示，降低原始文本的脆弱性；
2. **失败模式检测**：将多种神经不变量检查分别作用于ReAG上对应节点和上下文，输出**候选失败集**（而非直接给单一结论），保留多假设；
3. **决定性错误判定**：基于全轨迹和任务上下文，从候选中选出对最终结果影响最大的“决定性错误”，该策略与标注偏好有关（可扩展为选择首次异常、不可恢复点等）。

- 优点：避免一端到端整体推理的“长上下文迷失”，减少位置敏感性；通过多个独立检查提供可审计、可解释的证据。

## 3. 实验设计

### 3.1 基准数据集
- **Who&When**（公开数据集）：针对故障定位，含两个子集：Algo-Generated（126条）和Hand-Crafted（58条），共184条有人工标注轨迹。
- **AgentErrata**（自建数据集）：包含303条高质量轨迹，覆盖现有分类法全部失败类型，来自OpenManus、OWL、Mini SWE Agent等框架，以及BrowseComp、SWE-Bench Lite、WebArena等基准任务。通过分类法引导的故障注入生成，并人工验证，同时标注失败步骤与失败类型。

### 3.2 对比方法与基线
- **W&W All-at-once**：整条轨迹单次交给LLM判断失败。
- **W&W Step-by-step**：每一步结合其前缀上下文逐步判断。
- **LLM-as-Judge基线**：All-at-once中加入failure taxonomy信息的变体。
- AGENTSCOPE与上述方法在相同骨干模型下对比。

### 3.3 骨干模型与配置
- GPT-4o、GPT-5.1、DeepSeek-V3.2；temperature=0.01，max_tokens=4096。

### 3.4 评测指标
- **Step-level Accuracy (SLA)**：预测根因步骤与真实步骤精确一致的比例；
- **Step-level Accuracy with Tolerance (SLAT)**：允许偏差δ（T±0/T±1/T±3）内的准确率；
- **Classification Accuracy (CA)**：预测的若干失败类型中是否有与真实类型匹配（用于归因评价）。
- 未采用原Who&When中的Agent-level Accuracy，理由是步骤级已反映责任agent且更具信息量。

### 3.5 实验维度
1. 故障定位性能（SLA/SLAT），在AgentErrata和Who&When两个数据集上；
2. 是否提供原始任务ground-truth solution（w/ Solution vs w/o Solution）；
3. 故障归因性能（SLAT与CA）； 
4. 不同骨干模型（GPT-4o、GPT-5.1、DeepSeek-V3.2）的影响；
5. 运行时开销分析（20条采样轨迹，按token数、失败模式分解等）。

## 6. 主要结论与发现

- AGENTSCOPE显著优于现有LLM-as-judge类方法，在AgentErrata上SLA约28.38%~34.98%，基线最高不到18%；CA达到41.58%~45.87%，而LLM-as-Judge基线仅18.15%~20.63%。
- Who&When上，AGENTSCOPE在Hand-Crafted子集优势明显；在GPT-5.1的Algo-Generated上接近最强基线，论文将此归因于数据集的标注策略差异（标注“第一个错误”而非“决定性错误”）。
- **跨模型稳定性好**：不同骨干模型下SLA波动区间约5个百分点；基线方法对模型敏感（GPT-5.1下Step-by-step骤降到1.32%）。
- 模型通用能力不等于诊断能力：GPT-5.1并非始终优于DeepSeek-V3.2，结构化诊断机制比模型规模更关键。
- 结构化分解（graph+invariant+staged verdict）提升的是“诊断过程”本身，而非依赖有无ground-truth solution的提示泄露。
- 运行时开销可控：步数越多开销越大，Step Loop和Invocation Issue/Execution Failure检查最耗时；并指出并行化、调用合并是主要优化方向。

## 7. 优点

- **方法创新性**：将“行为抽象+神经不变量”引入智能体失败诊断，兼具符号系统的可验证性与神经语义的灵活性；可扩展新失效模式只需增加相应不变量。
