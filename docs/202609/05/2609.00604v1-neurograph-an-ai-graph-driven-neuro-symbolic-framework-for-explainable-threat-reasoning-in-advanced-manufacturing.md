## 摘要
先进制造中网络物理攻击面的日益复杂使得网络威胁情报分析变得越来越困难。尽管大型语言模型和检索增强生成改进了CTI工作流程，但基于文本的方法仍然容易产生幻觉，并且对跨互联威胁的结构化推理支持有限。基于图的RAG减少了其中一些限制，但现有方法通常缺乏本体一致的多跳推理，以及跨异构网络安全数据的透明证据追踪。本文提出了一种基于图的神经符号框架，该框架集成了本体感知的符号查询生成、知识图谱检索和神经语言生成，以支持在信息技术和运营技术环境中的准确且可解释的威胁分析。该框架采用双大型语言模型架构：第一个模型将自然语言问题转换为可执行的Cypher查询以进行符号图检索，而第二个模型严格基于检索到的图证据生成答案。使用公开可用的网络威胁情报基准进行的实验评估显示，在推理准确性方面相比已发表的基线有持续改进，同时还减少了幻觉，加强了多跳推理，并提高了对对抗性扰动的鲁棒性。运行时和可解释性分析进一步证明，该框架保持了交互式推理性能，并暴露了基于图的推理工件，使分析师能够检查和验证分析的每个阶段。总体而言，结果强调了基于图的神经符号推理作为下一代工业5.0环境中网络威胁情报的一种可扩展、可解释且可靠方法的潜力。

## Abstract
The growing complexity of cyber-physical attack surfaces in advanced manufacturing has made cyber threat intelligence analysis increasingly difficult. Although large language models and retrieval-augmented generation have improved CTI workflows, text-based approaches remain vulnerable to hallucinations and provide limited support for structured reasoning over interconnected threats. Graph-based RAG reduces some of these limitations, but existing approaches often lack ontology-consistent multi-hop reasoning and transparent evidence tracing across heterogeneous cybersecurity data. This paper proposes a graph-grounded neuro-symbolic framework that integrates ontology-aware symbolic query generation, knowledge graph retrieval, and neural language generation to support accurate and explainable threat analysis across information technology and operational technology environments. The framework adopts a dual-large language model architecture: the first model translates natural-language questions into executable Cypher queries for symbolic graph retrieval, while the second generates answers strictly from the retrieved graph evidence. Experimental evaluation using publicly available cyber threat intelligence benchmarks shows consistent improvements over the published baseline in reasoning accuracy, while also reducing hallucinations, strengthening multi-hop reasoning, and improving robustness to adversarial perturbations. Runtime and explainability analyses further demonstrate that the framework maintains interactive inference performance and exposes graph-grounded reasoning artifacts that allow analysts to inspect and verify each stage of the analysis. Overall, the results highlight the potential of graph-grounded neuro-symbolic reasoning as a scalable, interpretable, and reliable approach to cyber threat intelligence for next-generation Industry 5.0 environments.

## 2. 论文提出的方法论

**核心思想**
- GRICS 采用**“符号优先”的神经-符号检索**：LLM 不直接产生答案，而是先把自然语言问题转成基于本体约束的 **Cypher 查询**，在 **BRIDG-ICS 知识图谱**上执行；只有图执行返回的证据才能进入下游语言生成，从而限制幻觉并实现可审计推理。
- 采用**双 LLM 架构**（Cypher-LLM + Answer-LLM）分离“查询生成”与“答案生成”两个阶段：
  1. **Cypher-LLM**：将分析师的自然语言问题翻译为可执行 Cypher 语句；
  2. **Answer-LLM**：只根据检索到的图证据，生成自然语言解释/答案。

**知识图谱与本体**
- 基于作者之前工作的 **BRIDG-ICS** 本体构建，链接工业资产、软件/厂商、CVE、CWE、CAPEC、MITRE ATT&CK、OT 安全域等。
- 主要推理链：`Industry 5.0 Assets → CVE → CWE → CAPEC → MITRE ATT&CK`。
- 图模型表示为 \(G=(V,E,R)\)；关系采用类型化边，例如 `has_Vulnerability`、`has_CWE`、`use_Technique`、`located_In(Zone)`、`COMMUNICATES_WITH` 等，相关边还携带 `pExploit`、`riskWeight`、`controlStrength`、`costAttack` 等属性，支持漏洞传播的定量分析。

**符号检索与“受控回退”机制**
1. Cypher-LLM 先生成最多 3 个候选 Cypher 查询，经过去重与语法校验；
2. 依次在图谱 \(G\) 上执行，得到证据 \(R=\mathrm{EXEC}(c,G)\)；只要任一查询成功就返回；
3. 若全部失败，则仅**触发嵌入回退**：将问题嵌入后对图谱节点做余弦相似度检索，选出最相关的“图锚节点”
   \[
   \hat v=\arg\max_{v'\in V}\cos(f_{\mathrm{emb}}(q),f_{\mathrm{emb}}(v'))
   \]
4. 图锚**不能直接作为答案**，而是送回 Cypher-LLM 重新生成一个本体合规的 Cypher 查询并重新执行；仍必须经过符号图遍历后才会进入答案生成。
- 因此，“嵌入检索辅助符号推理，而不是替代符号推理”。后续生成中仍可用 `CONTAINS` 分割长查询等问题；所用嵌入模型为 `all-MiniLM-L6-v2`（384 维），存储在向量数据库中。
- Cypher-LLM 使用基于 BRIDG-ICS schema 的提示，包含“仅使用 schema 中的节点标签、关系类型和属性”的约束；Answer-LLM 只接收原问题和检索到的子图证据，提示其“不得引入未受支持的外部知识”，从而降低幻觉。

**推理算法**
- Algorithm 1 描述了：符号 Cypher 执行 → 失败则嵌入回退 → 重新锚定 → 再次符号执行的流程。
- Algorithm 2 描述了长查询分段（以 `CONTAINS` 过滤）与 Cypher 生成策略。
- 知识图谱数据来自 CVE、CPE、CWE、CAPEC、MITRE ATT&CK、真实 IIoT/OT 测试床；数据经过源抽取、实体规范化、关系映射和图入库四步处理，最终在 Neo4j 中以 property graph（LPG）形式保存。

## 6. 主要结论与发现

- **准确率提升**：Full GRICS 在三个 benchmark 上取得最佳结果：
  - CTI-RCM 2024：Acc 87.60%，F1 0.930；
  - CTI-RCM 2021：Acc 90.40%，F1 0.949；
  - CTI-ATE：Acc 77.15%，F1 0.871。
  - 所有测试配置 Precision 均为 100%，说明预测“一旦解决就能找到正确实体”，差别主要来自查询能否被解析/能否检索到足够证据。
- **消融结论**：
  - 图 grounding（Base KG-RAG 相对 Base LLM）本身带来显著提升；
  - Cypher 微调（FT）尤其提升关系复杂任务（CTI-ATE）的 query 生成有效性；

- **消融结论**（续）：
  - Cypher 微调（FT）尤其提升关系复杂任务（CTI-ATE）的 query 生成有效性；但微调集仅覆盖 450 条对齐 BRIDG-ICS schema 的样本，因此对 schema 可迁移性的贡献有限。
  - 嵌入回退（EF）对实体/属性查询的恢复能力有一定补充，但对复杂多跳语义约束帮助不大，且若单独使用，无法避免“相似但不准确”的检索结果进入生成阶段。
  - 移除任意一个组件（符号执行、微调、嵌入回退）都会导致性能下降，说明三者在 Full GRICS 中是互补的；但图执行成功与否仍然是决定最终准确率的主要瓶颈。

- **多跳推理与可解释性**：
  - 在 1-hop 查询上，Full GRICS 的命中率（HR）与查询验证率（QVR）很高；跳数增加后（3–5 hop），HR 和 QVR 明显下降，约束违规与截断错误增多，说明当前方法对长链推理仍不稳定。
  - 在成功检索到完整路径的样本中，Answer-LLM 可以被约束为基于子图证据回答问题，生成的答案支持逐跳回溯；但论文未设置“仅依靠 LLM 推理多跳”的强对照，因此图证据相对于模型内部知识的具体增益只能通过消融间接推断。

- **运行时与资源权衡**：
  - 100 个代表性查询中，简单实体查询和 1-hop 查询延迟最低；多跳查询随路径长度增加逐步升高；**attack path analysis 平均约 6.42 s**，主要来自多条候选 Cypher 的重复执行与较大子图物化。
  - 单阶段延迟与 GPU/RAM 占用均被报告，显示 4-bit LLM + 向量检索 + Neo4j 的组合在单卡上可运行，但并未提供高并发或大规模图谱的压测数据。

- **对抗鲁棒性**：
  - 在文本注毒/语义扰动下，Full GRICS 相比 Base LLM 能降低部分攻击成功率，但语义攻击下 ASR 仍约为 74.9%，说明图 grounding 能抑制“凭空捏造”却无法根除“问题本身被带偏”的风险。
  - 与 PoisonRAG、GRAPPOISON 的比较是定性层面的：由于知识图谱、注入比例和评估协议不一致，只能说明“在本框架内，符号约束比纯文本 RAG 更鲁棒”，不能作为跨系统优劣的严格证据。

- **总体结论**：GRICS/NeuroGraph 的核心价值在于证明了“用图作为 LLM 推理的符号锚”在工业 CTI 场景中可行且有效：显式中间表示（Cypher）限制了 LLM 的自由生成空间，使系统在标准 benchmark 上取得当前最优或接近最优的成绩，同时提供了比纯向量 RAG 更透明的证据路径。但论文也承认，它并不能完全解决对抗扰动下的可靠性问题，也还不能替代分析师对关键结论的最终判断。

## 7. 主要优点与可改进之处

**主要优点**
1. **问题定义清晰、动机扎实**：从真实 ICS 攻击事件出发，说明只做文本级 CTI 分析不够，需要跨 IT/OT 和物理域的结构化推理，这个定位准确且具有现实意义。
2. **方法设计具有组合创新性**：将 Text2Cypher、符号图执行、嵌入回退、受限答案生成串联成一个完整 pipeline，避免让 LLM 直接输出结论，在架构层面回应了“图数据库 + LLM 可解释检索”的核心难点。
3. **评估维度较全面**：不仅报告准确率，还从消融、少样本、噪声、多跳、延迟、内存、攻击路径等维度给出证据；对每一类指标都做了较明确的操作性定义，增加可复现性。
4. **知识本体有延续性**：BRIDG-ICS 不是临时构造，而是基于已有工业安全本体工作；CVE→CWE→CAPEC→ATT&CK 的链路与攻击分析实务一致，具有较好的知识表示基础。
5. **对可解释性的讨论不过度夸大**：作者明确指出符号证据链只是可解释性的必要不充分条件，最终仍需要分析师判断，这种态度值得肯定。

**可改进之处**
1. **数据集规模偏小**：65 个 CVE、450 条 QA 样本及单张图的规模，难以说明框架在真实企业级知识图谱（数十万节点、跨多年多源数据）上的表现；三跳以上性能明显下降也与此有关。
2. **缺少人工评估与可用性研究**：论文没有报告安全分析师对答案可信度、证据可读性或决策有用性的主观评分，因而“可解释性”更接近技术层面的 traceability，而非认知层面的 explainability。
3. **Cypher-LLM 对 schema 的强依赖是双刃剑**：它降低幻觉，但也使系统难以适配新本体；微调数据集若需随知识图谱更新而重建，维护成本值得讨论。
4. **与已有 Graph-RAG 工作的比较不够直接**：虽然提到 GraphRAG、RAG 等基线，但实验主要和 CTIBench 公布结果及自建消融比较，缺乏在相同问答集上与 LightRAG、GraphRAG、HyDE 等方法同等条件下的完整对比。
5. **对抗鲁棒性实验不充分**：语义攻击下 ASR 仍较高且只与 PoisonRAG/GRAPPOISON 做定性比较；缺少对“知识图谱层面注入”的防御实验。
6. **工程部署细节不足**：未给出多用户并发、索引策略、增量更新、Cypher 注入防护等实际部署问题，也未报告训练/推理能耗，影响工业落地评估。

## 8. 总结性评论

NeuroGraph/GRICS 是一篇“工程完成度较高、问题意识明确”的图基 LLM 系统论文。它最有价值的贡献不是某一种新算法，而是系统化地展示了“用符号图执行来约束神经生成”在工业 CTI 场景中能同时带来准确率与可审计性的提升。这种设计本质上是对纯 RAG 与 LLM 幻觉问题的一种务实修正：不让模型回答它不知道的问题，而是让它在知识图谱中找证据后再开口。

不过，也应看到其边界。三跳以上推理质量的明显下降、对抗扰动下 ASR 的高位徘徊，以及数据规模有限等问题，说明图 grounding 并不是解决 LLM 不可靠性的银弹，而更像是在工程上把错误从“生成端”前移到“检索/映射端”。在这一点上，论文没有回避，反而通过详细的错误分析让读者意识到：真正的瓶颈可能已不再是 LLM 本身的推理能力，而是工业知识图谱的完整性、更新频率和 schema 设计。

总体而言，该论文适合作为工业安全领域引入 Graph-RAG/神经符号推理的参考架构，尤其对“需要向用户展示证据链”的决策支持类场景有较强的借鉴意义。但它要想在真实 SOC/CSIRT 环境中落地，还需要补充更大规模知识图谱、分析师参与评估、实时知识更新机制和对抗风险更严格的测试。
