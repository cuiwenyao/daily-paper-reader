## 摘要
将用户定义的概念学习为约束网络已在约束获取（CA）文献中得到广泛研究。然而，现有方法通常依赖与人类 oracle 的大量交互，使得学习过程在时间和查询次数上代价高昂。本文提出一种用于自动 CA 的神经符号框架，通过引入神经 Oracle Transformer 模型来显著减少用户参与，这些模型学习模拟用户响应并泛化概念知识。在先前可用的示例上训练后，学习到的 oracle 与专用 CA 引擎 FastCA 交互，后者系统地将 oracle 的响应细化为一个健全、一致且可解释的约束网络。这种神经符号交互使得无需先验领域知识即可从数据中恢复结构化的符号模型。我们的结果表明，这种神经符号相互作用有效地将数据驱动的模式识别与符号推理对齐，为组合领域中的模型构建自动化提供了一种稳健方法。

## Abstract
Learning user-defined concepts as constraint networks has been extensively studied in the constraint acquisition (CA) literature. However, existing approaches typically rely on intensive interactions with a human oracle, making the learning process costly in terms of time and number of queries. In this paper, we propose a neuro-symbolic framework for automatic CA that significantly reduces user involvement by introducing neural Oracle Transformer models which learn to emulate user responses and to generalize conceptual knowledge. Trained on previously available examples, the learned oracle interacts with a dedicated CA engine, FastCA, which systematically refines the oracle's responses into a sound, consistent, and interpretable constraint network. This neuro-symbolic interaction enables the recovery of structured symbolic models from data without prior domain knowledge. Our results demonstrate that this neuro-symbolic interplay effectively aligns data-driven pattern recognition with symbolic reasoning, offering a robust approach to automating model construction in combinatorial domains.

## 2. 方法论

- **总体思想**：训练 T-Oracle 判断完整或部分赋值是否满足目标概念；FastCA 在约束偏置空间中主动查询 T-Oracle，并根据回答删除或确认候选约束，最终得到约束网络。
- **T-Oracle 架构**：
  - 采用 Transformer 编码赋值序列。
  - **值嵌入**：将离散域值映射为连续向量，公式为 \(E_v = W_v[v]\)。
  - **位置嵌入**：为每个变量位置学习表示 \(P_i\)。
  - **组合输入**：第 \(i\) 个变量表示为值嵌入与位置嵌入之和 \(e_i = E_{x_i} + P_i\)。
  - **交叉变量注意力**：学习约束矩阵 \(M \in \mathbb{R}^{n \times n}\)，表示变量对之间是否存在结构依赖。
  - **值交互矩阵**：通过 Query/Key 投影计算 \(V_{ij} = \sigma(q_i \cdot k_j / \sqrt{d_k})\)，衡量变量值对之间的冲突或相关性。
  - **依赖分数**：对活跃变量对应子矩阵 \(M^*\) 求平均，得到 \(S\)。
  - **分类输出**：Transformer 路径先给出概率 \(p\)，再用可学习阈值 \(\tau\) 调制：\(\text{output} = p \times \sigma(\tau - S)\)。
- **T-Oracle 三个变体**：
  - **TO 1**：仅用完整赋值训练，正负样本各 5000 左右。
  - **TO 2**：混合完整赋值与不同规模的部分赋值训练，增强不完整信息泛化。
  - **TO 3**：使用约束特定部分赋值训练，即对每个目标约束采样其关系内和违反元组，偏向局部约束级监督。
- **FastCA 算法流程**：
  - 输入候选约束偏置 \(B\)，输出学习网络 \(L\)。
  - 当 \(B\) 非空：选取约束 \(c\)，再选一个违反 \(c\) 的部分赋值 \(e\)，向 oracle 查询 \(\text{Ask}(e)\)。
  - 若回答“是”，则从 \(B\) 中删除 \(c\)。
  - 若回答“否”，调用 FindC 找到 \(vars(c)\) 上的有效约束，并从 \(B\) 中删除作用域被包含的候选约束。
  - 在归一化 CSP 中，每轮最多两个查询，删除一或两个约束。
- **理论保证**：
  - FastCA 满足**可靠性、完备性和终止性**，最终 \(sol(L)=sol(T)\)。
  - 查询复杂度上界为 \(|B|\)，有界元数 \(k\) 下为 \(O(n^k t)\)，二元约束网络为 \(O(n^2 t)\)。
  - 时间复杂度与偏置大小 \(|B|\) 线性相关。
  - FastCA 对噪声 oracle 更鲁棒：错误分类不会像 QuAcq 类顺序方法那样导致搜索假设失效，但会影响精度或召回。

## 3. 实验设计

- **Benchmark 场景**：共 10 个基准，覆盖经典谜题、随机约束网络和实际调度/排班：
  - Sudoku、JSudoku、LSquare、JobShop、Murder、Zebra、Rand122、Rand495、ExamTT、NurseR。
  - 变量数从 20 到 120，域大小从 5 到 90，偏置规模从 1,140 到 57,120 个候选约束。
- **数据划分**：每个 oracle 使用 80% 数据训练，20% 评估，随机划分。
- **数据生成**：
  - TO1：每个基准生成 5,000 个解和 5,000 个非解。
  - TO2：100 个解 + 100 个非解，并补充 1,000 个部分正例和 1,000 个部分负例，作用域从 2 到 \(n\)。
  - TO3：对每个目标约束采样比例 \(\theta\) 的正元组，并取等量负元组，\(\theta\) 从 20% 到 80%，并平衡不同约束类型。
- **对比方法**：
  - CA 学习器：QuAcq、MQuAcq、GrowAcq、FastCA。
  - Oracle 变体：TO 1、TO 2、TO 3。
- **研究问题**：

  - RQ3：不同 oracle 与 CA 学习器组合的获取性能如何？
