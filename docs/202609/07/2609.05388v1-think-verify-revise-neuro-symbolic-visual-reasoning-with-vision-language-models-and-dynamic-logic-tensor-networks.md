## 摘要
视觉推理任务要求系统同时感知视觉内容并应用形式化关系约束——这种组合纯神经方法或纯符号方法均难以独立妥善处理。本文提出一种神经符号（NeSy）框架，通过将用于自动一阶逻辑（FOL）规则归纳的视觉语言模型（VLM）与用于可微规则验证的动态逻辑张量网络（D-LTN）紧密耦合，在闭环迭代反馈回路中弥合这一差距。VLM接收少量带标签的视觉示例，并依据严格语法提出候选FOL规则（思考）；D-LTN在运行时根据这些规则自动组装，并基于CNN生成的视觉嵌入对其进行评估与验证（验证）；验证失败信息被反馈以引导VLM的下一轮假设（修订）。在ViSudo-PC基准上跨越四个视觉域（MNIST、EMNIST、KMNIST、FMNIST）的评估表明，该系统仅使用三个训练示例作为视觉上下文即可归纳出有效的数独约束规则。所提方法取得的AUC分数与先前方法（NeuPSL、LTN）相当或更优，展示了通过VLM实现自动规则发现的潜力。代码可在https://github.com/homayoun-afshari/nesy获取。

## Abstract
Visual reasoning tasks require a system to jointly perceive visual content and apply formal relational constraints---a combination that neither pure neural nor purely symbolic approaches handle well in isolation. This paper proposes a Neuro-Symbolic (NeSy) framework that closes this gap by tightly coupling a Vision-Language Model (VLM) for automatic First-Order Logic (FOL) rule induction with a Dynamic Logic Tensor Network (D-LTN) for differentiable rule verification, in a closed iterative feedback loop. The VLM receives a small set of labelled visual examples and proposes candidate FOL rules conforming to a strict grammar (Think); the D-LTN is automatically assembled from these rules at runtime and evaluates them grounding on CNN-produced visual embeddings (Verify); and verification failures are fed back to guide the VLM's next hypothesis (Revise). Evaluated on the ViSudo-PC benchmark across four visual domains (MNIST, EMNIST, KMNIST, FMNIST), the system induces valid Sudoku constraint rules using only three training examples as visual context. The proposed method achieves AUC scores matching or outperforming previous methods (NeuPSL, LTN), showing the potential for automatic rule discovery through VLM. Code is available at https://github.com/homayoun-afshari/nesy.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉推理任务要求系统同时具备视觉感知能力（确认视觉内容，如识别数独格子中的数字）和符号逻辑推理能力（应用形式化关系约束，如判断数独是否满足行、列、宫的唯一性约束）。纯神经网络方法在逻辑关系外推上表现不佳，而纯符号方法依赖手工规则，存在透明度、灵活性与泛化性之间的矛盾。
- **关键挑战——规则从何而来**：传统神经符号系统通常需要人类专家为每个新任务手工编写逻辑规则，缺乏自动从视觉数据中归纳出既机器可验证、又可跨域泛化的形式化规则的能力。
- **研究意义**：该论文旨在解决视觉推理中“感知”与“逻辑”的融合难题，提出一个能够自动发现符号规则、同时保持逻辑模型可解释性的闭环框架，推动神经符号推理的自动化与实用化。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 总体框架：“思考—验证—修订”（Think–Verify–Revise）闭环

- **核心思想**：将 VLM 从静态规则书写工具转变为**溯因推理器**，其假设由可微符号验证器——动态逻辑张量网络（D-LTN）持续评估和修正。验证结果反馈给 VLM，指导下一轮假设，形成闭环机制。
- **四大组件协同**：
  - **规则生成器（Rule Generator，即 VLM，对应 Think）** ：接收任务文本描述和少量视觉样本，输出符合预设语法的一阶逻辑规则。
  - **视觉编码器（Visual Encoder，CNN）** ：提取图像中的视觉嵌入，用于逻辑符号的语义接地。
  - **规则验证器（Rule Verifier，D-LTN，对应 Verify）**：在运行时将 VLM 生成的 FOL 规则解析为计算图，自动组装为 LTN，对视觉嵌入进行可微逻辑推理并输出规则的满足度。
  - **反馈回路（Feedback Loop，对应 Revise）**：将验证结果（含规则的符合性性能和语法错误）反馈给 VLM，促进下一轮改进。

#### 关键技术细节与算法流程

- **语法约束式 Prompt 设计**：
  - 通过严格的 FOL 语法模板将 VLM 的输出空间限制在预定谓词内（如 `P_same_row`、`P_same_col`、`P_same_block`、`P_same_loc`、`P_same_value`）。
  - 定义逻辑连接词符号映射：`&`（AND）、`|`（OR）、`!`（NOT）、`implies`、`iff`、`forall`、`exists`。
  - 限制模型中每条规则仅使用一个公式且不含常量与函数；将历史上各次尝试提取的规则及正确率（即验证模块的反馈）拼接在系统提示词中，实现迭代自我修正；VLM 遵循“链式思考”后按模板输出形如 `EXTRACTED_RULE:"..."` 的规则表达式。
- **规则动态编译流程**：
  - 对 VLM 输出做后处理（RegEx 提取），经规则解析器转化为语法树，再用 LTN Builder 将语法树节点转化为定制类的计算图，实现 D-LTN 的动态构建。
  - D-LTN 以模糊逻辑为据点，基于 CNN 提取的视觉嵌入做谓词接地：结构化谓词（同行/同列/同宫/同位）使用二元相似度；感知谓词 `P_same_value` 在高维嵌入空间使用指数相似度；逻辑连接词采用 Goguen 乘积 t-norm 等模糊逻辑算子。
  - CNN 提取特征并与行列位置索引拼接（embed_dims=64），支持端到端（可训练）模式，梯度经由逻辑约束回传到 CNN 参数。
- **终止条件**：
  - 设置用户定义阈值 τ；当 D-LTN 输出规则满足度 ≥ 决策阈值，或在测试集上平均 AUC ≥ 0.95 时停止迭代并判定规则有效；否则将失败反馈构造下一轮 prompt，直至满足条件或达最大迭代次数（20次）。
- **训练目标**：采用二元标签 y∈{0,1} 定义损失函数（有效板则最大化逻辑规则的满足度，无效板则最小化），促进视觉编码器和逻辑验证器的联合优化（多规则知识库场景留待未来工作）。

### 6. 主要结论与发现

- 提出的闭环“VLM 规则归纳 + D-LTN 可微验证”框架能在三个视觉域（MNIST、EMNIST、KMNIST）仅凭 3 个带标签样本即成功归纳出与参考规则逻辑等价的数独唯一性约束；尽管语法形式有变化（如合取次序交换、蕴含方向翻转等），规则语义均一致。
- 与已报道的基线相比：在 MNIST 上达到 0.94±0.10（持平 LTN-IND C 最佳），EMNIST 达到 0.93±0.10（大幅超越各基线），KMNIST 0.88±0.10、FMNIST 0.87±0.09（均超越或持平最佳基线），说明 CNN+D-LTN 结构本身（独立于 VLM 归纳）表现出较好的鲁棒性。
- 性能提升原因：视觉编码器在高维 embedding 空间而非 logit 层做感知谓词接地，使退化更平缓（尤其对 EMNIST），并且做了比前人更广的超参数搜索。

- 总体而言，该工作验证了 VLM 可结合形式校验机制做自动符号知识获取。这为减少人工规则，构建可解释、可泛化的神经符号推理系统迈出了一步。

### 7. 优点

1. **新颖闭环范式**：将“生成—验证—修订”机制应用于视觉推理，充分利用 VLM 的抽象假设生成能力和 LTN 的正式语义评估，是一种值得推广的设计；与强化学习/溯因推理机制存在显著串联思路。
2. **语法受限 Prompt 策略**：通过约束输出语言，显著过滤非法规则，减少 VLM 幻觉，保证下游 D-LTN 解析可行性——这是工程上实用且易复现的设计。
3. **动态构建 D-LTN 机制**：将任意合法 FOL 字符串自动装配为“可训练式” LTN 计算图（运行时规则解析 + 语法树定制化节点类），实现端到端的符号层梯度回传到 CNN。
4. **结果稳健且可比**：在低样本（3 个实例、少数 VLM 交互）下跨数据集取得结果与 SOTA 基线相当或更优，且规则评价采用逻辑等价性（数学推导）而非字面对齐，增强了评估的客观深度。
5. **开放透明**：论文提供了可复现性较充分的代码仓库链接，并且清晰的限定了验证模型（同 GPT-4o / Llama 类 API）以满足研究的可复演性。
6. **跨域测试设计合理**：通过四个复杂度递增的视觉数据集考察方法在不同视觉域中的迁移能力，这有助于揭示 VLM 视觉抽象能力的边界。

### 8. 不足与局限

1. **符号集固定**：系统假设谓词/常量词典预先给定，仅自动归纳规则，不自动学习需 ground 的视觉概念，尚不足以应对开放式场景。
2. **单规则脚本**：只面向单一逻辑规则的场景验证（数独约束），并未扩展到多规则知识库，从而限制其在更复杂真实视觉推理（如含因果或空间序列推理）上的应用。
3. **仅一个 benchmark**：单一数独任务难以证明方法的一般性，缺少 CLEVR、RPM、VideoABC 等更丰富的基准。
4. **超参数依赖**：选择良好 CNN 配置的过程需要使用一个手工 FOL 规则进行调参，这种依赖在一定程度上弱化了“全自动发现规则”的卖点。
5. **未做消融分析**：未能分解验证闭环、反馈信息、端到端训练每个设计决策的贡献；CNN/逻辑层的效果分别归因不够清晰。
6. **计算代价记录不全**：缺少对 GPU 型数量、训练耗时、VLM API 调用成本等的详细度量，制约了工程落地评估。对 FMNIST 失败解释（如高视觉复杂度）仅为假设，没有提供量化的证据或消融实验来支撑。
7. **架构替换的扩展性尚存不确定性**：虽然自称可扩展到 NeuPSL 等其他 NeSy 框架，但缺少代码级/实验级的证明；对多源视觉域、预训练模型的策略也仅停留在未来展望上。
