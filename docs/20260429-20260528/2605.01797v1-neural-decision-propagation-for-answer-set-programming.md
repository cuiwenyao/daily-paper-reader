## 摘要
将回答集编程（ASP）与神经网络集成已成为神经符号AI中一种有前景的工具。现有方法虽然将ASP的能力扩展到现实世界领域，但其推理流程依赖于经典求解器，这成为可扩展性的瓶颈。为解决此问题，我们提出了一种计算稳定模型的新方法，称为决策传播（DProp），该方法交替进行假性决策和真值传播。成功的DProp计算能够捕捉稳定模型语义。随后我们开发了神经DProp（NDProp），它是DProp的可微扩展，其中决策采用神经计算，传播采用模糊评估。我们评估了NDProp在学习决策启发式以及神经符号集成方面的能力，并将其与现有的神经符号方法进行了比较。结果表明，NDProp能够学习高效计算稳定模型，并在神经符号基准测试中提高了准确性和可扩展性。

## Abstract
Integration of Answer Set Programming (ASP) with neural networks has emerged as a promising tool in Neuro-symbolic AI. While existing approaches extend the capabilities of ASP to real world domains, their reasoning pipelines depend on classical solvers, which is a bottleneck for scalability. To tackle this problem, we propose a new method to compute stable models, called decision-propagation (DProp), which alternates falsity decisions and truth propagations. Successful DProp computations are shown to capture the stable model semantics. We then develop Neural DProp (NDProp), a differentiable extension of DProp with neural computation for decisions and fuzzy evaluation for propagations. We evaluate the capabilities of NDProp for learning decision heuristics as well as neuro-symbolic integration, and compare it with existing neuro-symbolic approaches. The results show that NDProp can learn to efficiently compute stable models, and it improves accuracy and scalability on neuro-symbolic benchmarks.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想：决策-传播（DProp）及其神经扩展NDProp

- **DProp**：一种计算稳定模型的新方法，交替进行两个阶段：
  - **决策（Decision）**：从未定原子中非确定性选择一个（或一组）原子设置为假（加入假集F）。
  - **传播（Propagation）**：在给定假集F下，通过立即后果算子\(C_{P, A\setminus F}\)（迭代至不动点）推导出所有真原子（加入真集T）。
  - 初始状态：\(T_0 = C^\infty_{P,A}(\emptyset)\)，\(F_0 = \emptyset\)，\(U_0 = A \setminus (T_0 \cup F_0)\)。迭代直至\(U = \emptyset\)且\(T \cap F = \emptyset\)，则成功终止，T即为一个稳定模型。
  - **理论保证**：定理1证明，成功DProp计算的结果恰是稳定模型。

- **NDProp**：DProp的可微扩展，分决策和传播两阶段，均使用连续值：
  - **决策阶段**：每个原子有真度\(\tau_i\)和假度\(\phi_i\)，未定度\(\mu_i = 1 - (\tau_i \oplus \phi_i)\)。使用RNN网络根据当前状态\([\tau, \phi, \mu]\)生成决策得分\(\delta = \sigma(d)\)，然后更新假度：\(\phi^{t+1} = \phi^t + (\mu^t \odot \delta^t)\)。
  - **传播阶段**：使用t-范数和t-余范数进行模糊推理，定义软立即后果算子\(C_{P,\phi}(\tau)\)，迭代直至收敛得到新的真度\(\tau^{t+1}\)。
  - **成员得分**：\(p_i = \frac{1}{2}(\tau_i + 1 - \phi_i)\)，当输出为二元时（即每个原子要么(1,0)要么(0,1)），则对应稳定模型。定理2证明，二元输出状态保证稳定模型语义。
  - **关键性质**：当所有变量为二元时，NDProp退化为DProp（命题1）。NDProp支持批量决策（Remark 1），允许一次决策多个原子。

### 关键技术细节

- 使用t-范数（如Gödel、Product）实现模糊合取，t-余范数实现模糊析取。
- 传播迭代停止条件：最大变化低于阈值或达到预设最大迭代次数。
- 损失函数：使用二元交叉熵（BCE）损失，迫使输出接近二元（从而稳定）。
- 逻辑维度（logical dimension）：模型维护多个逻辑状态，最终选择最接近二元的状态。

## 3. 实验设计

### 数据集/场景

1. **随机逻辑程序**：用于评估NDProp学习求解ASP问题的能力。
   - 负二元文字（N2L）程序：线性模型\(L(N_2, c_1, c_2)\)，每个规则形如\(a \leftarrow not\ b\)或\(a \leftarrow not\ a\)，按概率出现。
   - k-LP程序：3-LP生成器（硬实例，规则数/原子数约5时相变）。按原子数分为easy（5–10）、medium（11–50）、hard（51–100）三组。
   - 每个数据集1000训练+100验证+100测试。

2. **神经符号任务（MNIST算术推理）**：评估NDProp与现有ASP神经符号系统的比较。
   - 六个任务：Addition（2位数字加法）、Addition2（2个两位数加法）、Add2x2（2×2网格行/列和）、Apply2x2（含运算符号的表达式）、Member3（3数字成员判断）、Member5（5数字成员判断）。
   - 每个任务提供MNIST图像和算术标签，监督仅来自最终结果，无每张图像标签。
   - 对比方法：NeurASP、SLASH。

3. **视觉数独（不完整数据推理）**：评估NDProp在神经网络预测不完美时的推理能力。
   - 4×4数独，每格有MNIST数字（0–4，0为空）。预训练MNIST分类器（使用100%、50%、10%、5%、1%训练数据），用其预测作为输入。
   - 对比方法：直接使用ASP求解（预测作为事实）、纯神经网络预测。

### Benchmark/评估指标

- 随机程序：求解成功率（找到稳定模型的百分比）。
- 神经符号任务：识别准确率（数字识别）、推理准确率（最终输出正确率）、训练时间、测试时间。
