## 摘要
基础模型驱动的智能体在长时域规划中常因纯提示推理的瞬时性而受限。现有技能归纳方法通过将经验提炼为无状态参数化脚本来缓解这一问题，但未能捕捉动态环境下稳健执行所需的条件逻辑。本文提出神经符号技能归纳（NSI），一种将交互轨迹提升为模块化、逻辑驱动程序的框架。通过合成显式控制流和动态变量绑定，NSI使智能体能够发现何时以及为何行动。该范式实现了高效泛化，使智能体能够从少样本示例中归纳技能，并灵活适应未见目标。在一系列智能体任务上的实验表明，NSI持续优于最先进基线，使智能体能够自我进化为逻辑驱动技能的构建者。

## Abstract
Foundation model-driven agents often struggle with long-horizon planning due to the transient nature of purely prompting-based reasoning. While existing skill induction methods mitigate this by distilling experience into state-blind parameterized scripts, they fail to capture the conditional logic required for robust execution in dynamic environments. In this paper, we propose Neuro-Symbolic Skill Induction (NSI), a framework that lifts interaction traces into modular, \textit{logic-grounded} programs. By synthesizing explicit control flows and dynamic variable binding, NSI empowers agents to discover \textit{when} and \textit{why} to act. This paradigm enables the efficient generalization, allowing agents to induce skills from few-shot examples and flexibly adapt to unseen goals. Experiments on a series of agentic tasks demonstrate that NSI consistently outperforms state-of-the-art baselines, empowering agents to self-evolve into architects of logic-grounded skills.

## 2. 方法论

- **核心思想**：将技能定义为神经符号三元组 `π_ω = (θ_ω, φ_ω, G_ω)`，其中：

- **关键技术细节**：

  - **渐进诱导算法**：先进行**轨迹内合并（Intra-Trajectory Consolidation）**，为每条轨迹合成局部专家 `π_τ`；再进行**轨迹间合并（Inter-Trajectory Skill Consolidation）**，通过贪心迭代合并局部专家为全局技能，使用四个结构算子：**Branching**（插入条件分支）、**Crossover**（模块嫁接）、**Lifting**（常量提升为参数）、**LoopFold**（循环折叠）。
  - **在线进化**：通过反思规划（Reflective Planning），当技能执行失败时，利用失败节点返回的符号诊断信息生成纠正轨迹，并将该轨迹嫁接（graft）到失败节点，形成新的条件分支（Skill Honing）。若纠正成功，则增长技能图；若失败，则更新技能文档限制其适用条件。

  2. 对每条轨迹，使用 LLM 迭代合成局部专家 π_τ（通过结构合并解决错误点）。
  3. 贪心迭代：找出当前全局技能覆盖最差的局部专家 π_hard，调用 Consolidate(π_glb, π_hard) 生成候选技能，若候选技能满足可行性支配（严格扩大覆盖且保持一致性）则接受。
  4. 部署阶段：在遇到失败时，执行 Reflective Planning → 若恢复成功，将恢复轨迹嫁接为技能的新分支（标记为临时，多次成功则固化）；若恢复失败，更新技能文档。

## 6. 主要结论与发现

- NSI 在所有三个基准上**一致且显著**超过最强基线：ALFWorld 成功率 98.0%（AWM 91.3%），WebShop 得分 76.5%（AWM 49.2%），TextCraft 成功率 95.2%（AWM 92.5%）。

- **在线进化机制有效**：通过 Reflective Planning 将运行时失败转化为永久技能分支（如图3示例），使技能图从简单线性结构逐步生长为带条件分支的鲁棒网络。去除在线进化后，NSI 性能下降（如 ALFWorld 从 98.0% 降至 93.5%）。
- 结论：该工作实现了从 System-2（慢思考规划）到 System-1（快反射技能）的认知转变，使智能体具备自主逻辑发现能力。
