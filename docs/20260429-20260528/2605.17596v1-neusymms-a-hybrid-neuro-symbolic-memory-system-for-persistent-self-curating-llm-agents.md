## 摘要
我们提出了NeuSymMS，一种自适应记忆系统，通过混合神经符号架构使大语言模型（LLM）智能体能够跨会话学习、记忆和推理用户信息。NeuSymMS将来自非结构化的对话的神经事实提取与基于CLIPS的专家系统相结合，在显式生命周期规则下对事实进行分类、去重和协调。该系统将知识表示为存储在关系数据库管理系统中的主语-关系-宾语三元组，支持用户/智能体/智能体间的范围界定，并实现了基于访问提升和基于时间剪枝的双视界短期/长期记忆模型。NeuSymMS在保持记忆连续性的同时避免了上下文窗口膨胀和跨实体污染。我们认为该架构为生产级智能体系统提供了一条实现可信、可审计记忆的实用途径，并讨论了其相对于日志检索、摘要和键值方法的创新性。

## Abstract
We present NeuSymMS, an adaptive memory system that enables large language model (LLM) agents to learn, remember, and reason about users across sessions via a hybrid neuro-symbolic architecture. NeuSymMS couples neural fact extraction from unstructured dialogue with a CLIPS-based expert system that classifies, deduplicates, and reconciles facts under explicit lifecycle rules. The system represents knowledge as subject-relation-value triples stored in relational database management system, supports user/agents/agent-to-agents scoping, and implements a dual-horizon short-term/long-term memory model with access-based promotion and time-based pruning. NeuSymMS maintains continuity of memory while avoiding context-window bloat and cross-entity contamination. We argue that this architecture offers a practical path to trustworthy, auditable memory for production agentic systems and discuss its novelty relative to log retrieval, summarization, and key-value approaches.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程
### 核心思想
- **混合神经符号架构**：将LLM作为**神经事实抽取器**（仅处理自然语言理解），将CLIPS专家系统作为**确定性推理引擎**（处理分类、矛盾检测、生命周期管理），两者通过统一的数据模型和API集成。
- **知识表示**：所有记忆知识表示为**主语-关系-宾语三元组**（类似RDF），存储于关系数据库（PostgreSQL），支持用户级、智能体级、流程级三范围隔离。
- **双视界记忆模型**：短期记忆（short-term）和长期记忆（long-term），基于**访问计数提升**（访问≥3次升为长期）和**时间剪枝**（24小时内未访问的短期事实被停用），模拟认知巩固过程。

### 关键技术细节
- **LLM事实抽取**：使用轻量LLM（如gpt-4.1-mini）从对话片段中提取JSON数组候选事实，包含subject, relation, value, confidence, scope。强制低温度(0.1)、最多10个事实/轮、否定关系显式编码（如no_longer_has, lost）。
- **CLIPS规则引擎**：使用CLIPSPy（Python绑定）运行CLIPS 6.4。每请求重新实例化环境，避免污染。定义三个核心模板：memory-fact（已有知识）、candidate-fact（候选事实）、engine-decision（待执行数据库操作）。分三阶段（由规则优先级控制）：
    1. **分类阶段**：基于模式和关键字将候选事实归入9个语义类别（personal, preference, task, relationship, skill, context, instruction, temporal, other）。
    2. **矛盾检测与真值维护**：对相同subject-relation的事实，使用归一化比较和Levenshtein距离（阈值0.85）检测矛盾。单值关系采用“最新值优先”，多值关系仅更新匹配项。否定关系自动触发撤回原事实，不持久化否定事实。
    3. **提升与存储阶段**：丢弃低置信度(<0.3)和精确重复的事实；根据类别自动将personal/preference/instruction/skill事实存入长期；其他先存短期，访问计数达阈值后提升。后台任务定期停用过时短期事实。
- **读取路径**：查询活跃的user-scoped事实，按memory_type（长期优先）、access_count、时间排序，限30个，格式化为文本块注入LLM系统提示。
- **技术栈**：Django REST Framework + PostgreSQL + CLIPSPy + LiteLLM（多LLM提供商网关）。前端提供React/TypeScript记忆管理UI。
