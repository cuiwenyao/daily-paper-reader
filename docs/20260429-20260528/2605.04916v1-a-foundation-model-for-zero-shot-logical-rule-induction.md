## 摘要
归纳逻辑编程（ILP）从数据中学习可解释的逻辑规则。现有方法是直推式的：它们学习到的参数绑定到特定谓词，并且每个新任务都需要重新训练。我们提出神经规则归纳器（NRI），这是一个用于零样本规则归纳的预训练模型。NRI不编码文字标识，而是使用领域无关的统计属性来表示文字，例如类条件率、熵和共现，这些属性能够跨变量标识和数量泛化，无需重新训练。该模型由一个统计编码器和一个基于平行槽的解码器组成。平行解码保留了逻辑析取的排列不变性；而自回归解码器则会强加一个任意的子句顺序。积T-范数松弛使规则执行可微分，从而允许仅基于预测准确率进行端到端训练。我们在规则恢复、对标签噪声和虚假相关性的鲁棒性以及零样本迁移到真实世界基准上评估了NRI，并相信这项工作为符号推理的基础模型开辟了可能性。代码和参考检查点可在https://github.com/phuayj/neural-rule-inducer获取。

## Abstract
Inductive Logic Programming (ILP) learns interpretable logical rules from data. Existing methods are transductive: their learned parameters are bound to specific predicates and require retraining for each new task. We introduce Neural Rule Inducer (NRI), a pretrained model for zero-shot rule induction. Rather than encoding literal identities, NRI represents literals using domain-agnostic statistical properties such as class-conditional rates, entropy, and co-occurrence, which generalize across variable identities and counts without retraining. The model consists of a statistical encoder and a parallel slot-based decoder. Parallel decoding preserves the permutation invariance of logical disjunction; an autoregressive decoder would instead impose an arbitrary clause order. Product T-norm relaxation makes rule execution differentiable, allowing end-to-end training on prediction accuracy alone. We evaluate NRI on rule recovery, robustness to label noise and spurious correlations, and zero-shot transfer to real-world benchmarks, and we believe this work opens up the possibility of foundation models for symbolic reasoning. Code and the reference checkpoint are available at https://github.com/phuayj/neural-rule-inducer.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的归纳逻辑编程（ILP）方法学习可解释的逻辑规则，但它们属于**直推式（transductive）**，即学习到的权重与特定谓词（如 Parent、Protein）绑定。当面对新任务（新谓词集、不同变量数量）时，必须从头重新训练，无法实现零样本跨任务泛化。
- **研究动机**：在高风险领域（如医疗、金融），可解释的规则至关重要。作者希望构建一个**基础模型（foundation model）**，它能从任意布尔数据中**零样本（zero-shot）** 地归纳出正确的逻辑规则，而不需要针对每个新数据集的重新训练。
- **核心假设**：选择哪些变量（布尔属性）应基于其**统计特征**（如类条件概率、熵、共现），而非其名称。这些统计特征在不同领域间具有不变性，因此可以支持零样本迁移。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：NRI 将规则归纳问题建模为元学习：训练时仅使用合成布尔公式，学习从数据统计模式到逻辑规则的映射；推理时，对任意新领域的布尔数据直接输出 DNF（析取范式）规则。
- **关键技术细节**：
  1. **统计编码器（Literal Statistics Encoder）**：对每个文字（正/负出现）计算 18 维统计特征向量，包括：
     - 正/负示例中的真值率、熵、出现率；
     - 极性（正/负）；
     - 与其他文字的平均共现强度等。
     这些特征不依赖文字的具体标识，实现维度无关。
  2. **示例条件编码（Example-Conditioned Encoding）**：通过多头注意力将文字特征与每个示例的标签、文字值向量融合，恢复支持集模式信息。对于维数变化问题，采用零填充或随机扩展（仅影响辅助分支）。
  3. **FiLM 调制**：为每个子句槽（clause slot）应用可学习的仿射变换（γ, β），打破槽间对称性，使不同子句可以分化。
  4. **并行槽解码器（Parallel Slot-Based Decoder）**：使用固定数量的可学习子句查询向量，通过 Transformer 解码器并行生成多个子句，保持逻辑析取的置换不变性（避免自回归生成的顺序偏见）。
  5. **可微 T-范数执行**：使用积 T-范数将逻辑合取/析取连续化：合取 = 乘积；析取 = 1 - ∏(1 - 值)。规则执行完全可微，支持端到端训练，无需子句标签。
  6. **多目标损失函数**：包含覆盖损失（BCE）、子句负载均衡损失（借鉴 MoE）、最大间隔损失、反事实必要性损失（Lnec + Lspur）等，以引导规则选择因果相关文字、避免虚假相关。
- **算法流程**：统计编码 -> 示例条件编码 -> FiLM 调制 -> 并行解码生成文字门和子句门 -> T-范数评估 -> 反向传播。
