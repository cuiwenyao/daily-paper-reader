## 摘要
我们提出了智能模式记忆（ISM），一个自我演化的记忆增强系统，在硬性情景重置的持续学习下改进冻结的LLM的数学推理。ISM维护一个紧凑的、自我精炼的策略模式库，从成功和失败的情景中学习，并带有符号工具检查中间步骤和验证答案。在不更新模型参数的情况下，ISM在MATH-Hard和OlympiadBench上优于被动、检索和反思基线，分别使用了比最强被动基线少64%和86%的模式。这些结果表明，在严格的情景隔离下，小规模、主动维护和验证的策略记忆可以支持可靠的持续数学推理。代码库可在https://github.com/pdx97/ISM获取。

## Abstract
We propose Intelligent Schema Memory (ISM), a self-evolving memory-augmented system that improves mathematical reasoning for a frozen LLM under continual learning with hard episodic resets. ISM maintains a compact, self-refined bank of strategy schemas learned from both successful and failed episodes, with symbolic tools that check intermediate steps and certify answers. Without updating model parameters, ISM outperforms passive, retrieval, and reflection baselines on MATH-Hard and OlympiadBench, using 64% and 86% fewer schemas respectively than the strongest passive baseline. These results show that small, actively maintained, and verified strategy memories can support reliable continual mathematical reasoning under strict episodic isolation.The codebase is available at https://github.com/pdx97/ISM .

## 1. 核心问题与整体含义（研究动机和背景）

大型语言模型在独立解决数学问题上表现优异，但在面对跨领域的连续问题流时，由于每个新问题都从相同的冻结参数开始，前一个任务获得的洞察在下一个任务开始前就丢失了。这突显了在冻结骨干网络下的持续学习核心挑战：任何累积改进必须完全存在于模型外部的外部知识库中。数学推理因其清晰的结构规则和可验证的正确性，成为研究这一动态的理想试验台。现有方法如反思法、检索增强和技能库系统存在反馈不可复用、存储无限增长、缺乏验证与合并机制等问题，无法在可控方式下自我改进。ISM旨在让冻结的LLM通过主动维护的、有界的、可验证的外部记忆来自我演化数学推理能力。

### 2.1 核心思想
ISM维护一个紧凑的策略模式库，每个模式分为内容部分（策略描述、解决方案模板、启发式规则）和特征挂钩（检索信号，包括操作符类型、结构模式、启发式签名、数量签名、嵌入质心、成功率和使用次数）。这种分离解耦了“做什么”和“何时应用”，使检索随经验自适应优化而策略内容保持稳定。

## 3. 实验设计

### 3.1 数据集与场景
- **MATH-Hard**：MATH数据集的最高难度（Level-5）问题，涵盖代数、几何、数论，高中竞赛级别，简短数字或符号答案。
- **OlympiadBench**：国际和国家奥林匹克级数学问题，难度显著高于MATH-Hard，要求多步推理。
- 持续学习流：300情景，按领域分块，块间硬性转移，每情景硬性情景重置（除外部记忆外无上下文继承）。

### 3.2 Benchmark与对比方法
对比五个基线：
1. Vanilla LLM：无外部记忆的冻结模型。
2. Static Schema：固定提示模板，无检索和更新。
3. RAG-over-Examples：存储所有过去情景，按嵌入相似度检索最近示例。
4. Reflexion：每次情景后追加简短言语反思到增长缓冲区。
5. Passive Schema Memory：与ISM相同但关闭七个自我改进机制。

- 最终准确率（300情景平均）。
