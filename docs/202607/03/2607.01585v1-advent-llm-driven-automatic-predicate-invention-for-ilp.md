## 摘要
谓词发明（PI），即创建新谓词以扩展假设空间，仍然是归纳逻辑编程（ILP）中的一个关键瓶颈。现有方法依赖领域专业知识，并产生语义模糊的谓词，阻碍了对不熟悉领域的适应和跨任务复用。我们提出ADVENT，一种用于ILP的LLM驱动的PI机制。ADVENT将LLM的溯因生成与Prolog演绎验证相结合，形成一个迭代循环，其中具体的执行结果引导LLM优化候选谓词。该机制利用大语言模型识别结构化关系数据中的隐含模式，并赋予辅助谓词有意义的名称和定义。发明出的谓词和学习到的规则积累到一个知识池中，用于跨任务复用。在七个LLM上对九个扑克牌手概念的实验表明，LLM驱动的PI在ILP单独完全失败的情况下达到了58%的成功率，形式验证将其提升至80%，知识池带来了高达31个百分点的增益，同时生成了人类可解释的规则。这些结果表明，ADVENT为自动化谓词发明和实现ILP中跨任务知识复用提供了有前景的方向。

## Abstract
Predicate invention (PI), the creation of new predicates to extend the hypothesis space, remains a critical bottleneck in Inductive Logic Programming (ILP). Existing methods rely on domain expertise and produce semantically opaque predicates, hindering adaptation to unfamiliar domains and cross-task reuse. We present ADVENT, an LLM-driven PI mechanism for ILP. ADVENT pairs LLM abductive generation with Prolog deductive verification, forming an iterative loop in which concrete execution results guide the LLM to refine candidate predicates. The mechanism leverages Large Language Models to identify implicit patterns in structured relational data and invent auxiliary predicates with meaningful names and definitions. Invented predicates and learned rules accumulate in a knowledge pool for cross-task reuse. Experiments on nine poker-hand concepts across seven LLMs show that LLM-driven PI achieves 58% success rate where ILP alone fails entirely, formal verification raises this to 80%, and the knowledge pool yields gains up to +31 percentage points, while producing human-interpretable rules. These results suggest that ADVENT offers a promising direction for automating predicate invention and enabling cross-task knowledge reuse in ILP.

## 1. 核心问题与整体含义（研究动机和背景）
归纳逻辑编程（ILP）在关系型概念学习中具有独特优势，能生成人类可解释的逻辑规则。然而，ILP 高度依赖预定义的背景知识（BK），**谓词发明（PI）**——即创建新谓词以扩展假设空间——是 ILP 长期以来的关键瓶颈。现有 PI 方法存在两个根本缺陷：
- **依赖领域专家**：需要人工提供元规则或模式声明来引导搜索，否则会退化为穷尽枚举。
- **语义不透明**：仅通过符号操作生成无名谓词（如 inv_1, inv_2），难以评估其与当前任务的相关性，也阻碍跨任务复用和组合。

大语言模型（LLM）在代码生成、溯因推理和逻辑程序合成方面表现强劲，有望自动识别结构化数据中的隐含模式并生成带语义的谓词。但 LLM 输出存在不可靠性（如语法错误、过拟合）。论文受“LLM + 形式验证”迭代改进思路启发，提出 **ADVENT** 机制，将 LLM 的溯因生成与 Prolog 演绎验证结合，用于自动化谓词发明并支持跨任务知识复用。

## 2. 方法论：核心思想、关键技术细节、算法流程
### 2.1 总体框架（四阶段流水线）
ADVENT 嵌入在神经符号流水线中，模拟皮尔士的“溯因-演绎-归纳”三元推理循环：

1. **Stage 1: 初始假设空间表示检查 (Representation Check, RC)**
   - 轻量级启发式方法：从正例和负例中各采样10%，再从正例子集中取1%作为种子，执行受限变量级搜索（将具体常量替换为变量，如 “相同形状”）。
   - 若所有种子仅能生成覆盖自身的地面子句（无其他正例），则判定当前 BK 缺乏必要表示能力，触发 PI；否则直接跳到 Stage 4。

2. **Stage 2: LLM 谓词发明循环（核心）**
   - **LLM 生成**：接收提示，包含当前任务 BK 模式、少量正负例样本、知识池中已有谓词列表（名称+定义）。LLM 溯因式地提出候选谓词（Prolog 定义、元数、参数类型、输入/输出模式）。
   - **Prolog 演绎验证**：分两层：
     - 语法/结构验证：加载定义，捕获运行时错误、不可满足子句、未定义谓词。
     - 行为验证：在正负例子集上执行候选谓词，返回每个例子的布尔结果或值元组，以对比方式呈现给 LLM，促使迭代修正。
   - 最大迭代次数限制（实验中为3次）。

3. **Stage 3: PI 后表示检查**
   - 再次应用 RC 检查扩展后的假设空间。若通过则进入 Stage 4；否则记录失败。

4. **Stage 4: ILP 规则归纳**
   - 将发明出的辅助谓词注入原 BK，由 ILP 系统（Aleph）进行常量级搜索，补全具体值。

### 2.2 跨任务知识积累
成功诱导出的谓词和规则累积在**知识池**中。新任务开始时，知识池作为初始 BK 的扩展提供给 LLM，LLM 可判断哪些已有谓词相关并复用或组合。

## 6. 主要结论与发现
- **RQ1**：LLM 可有效驱动谓词发明。在位置自由模式下 ILP 完全失败（0/9），而 LLM PI（无验证）平均成功率 58%，证明 LLM 能识别隐含模式并扩展表示能力。
- **RQ2**：形式验证显著提升性能。ADVENT（形式验证）平均 80% [76–84%]，LLM 自批评 73% [68–78%]，无验证 58%。形式验证优于自批评，因为 Prolog 提供具体执行结果而非模型自我评估。
- **RQ3**：知识池支持跨任务复用和组合，对组合概念（同花顺、皇家同花顺）增益高达 +31 百分点；但对简单概念（同花）有干扰（−9 百分点），说明需选择性检索。
- 发明谓词的语义可解释性强，如 has_duplicate_rank, has_consecutive_ranks。
