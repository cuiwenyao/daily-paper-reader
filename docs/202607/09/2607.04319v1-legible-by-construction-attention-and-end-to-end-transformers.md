## 摘要
一篇配套论文表明，可以将Transformer的前馈层从显式的模糊集合运算（交集、集合差以及自遗忘序列量词）中重建出来，从而在不损失语言模型质量的前提下，使其隐藏单元作为命名的逻辑运算符被解读。这留下了Transformer的另一半不透明性。这里我们将相同的思路引入注意力机制，并将两者结合为一个模型。其机制极为精简：将头的值通过sigmoid函数，使得每个值通道成为可读的检测器，用于判断某个特征是否存在于某个词元上。这不会增加参数，且其余部分保持标准头的结构不变。布尔变体更进一步，将值重构为显式的词元内交集和具备取反能力的集合差。在这两种设计中，输出投影保持自由状态，不与词汇表绑定——这是关键的决策：约束头检测的内容，同时不约束其写入的内容，会产生选择性检测器；而约束写入则不会。通过两种选择性压力——稀疏激活和沿边界上的决定性激活——将受限值塑造为可读的检测器，但具体设计所需的选择性压力并非通用。在五种125M参数的专业化注意力设计中，44%至62%的值通道成为清晰、上下文相关的选择性检测器，其可解释性随深度增加而提升，而非仅仅在标点上固化。语言模型质量与传统基线相当。最后，我们将布尔注意力与可解释前馈层耦合，训练了一个基准性能相当的端到端可解释构造语言模型：其前馈层始终是命名的集合与量词运算，我们可以选取其生成的一个词元，并读取构成该词元的命名单元。

## Abstract
A companion paper showed that a transformer's feed-forward layer can be rebuilt from explicit fuzzy set operations - intersection, set-difference, and a self-forgetting sequence quantifier - so its hidden units read as named logical operators at no cost to language-model quality. That left the other half of the transformer opaque. Here we carry the same idea into attention and join the two into one model. The mechanism is minimal: a head's value is passed through a sigmoid, so each value channel becomes a readable detector of whether a feature holds at a token. This adds no parameters and leaves the standard head otherwise untouched. A Boolean variant goes further, restructuring the value into an explicit within-token intersection and negation-capable set-difference. In both designs the output projection is left free, not tied to the vocabulary, which is the load-bearing decision: bounding what a head detects while leaving what it writes unconstrained yields selective detectors, whereas constraining the write does not. A bounded value is shaped into a readable detector by two selectivity pressures - one for sparse firing, one for decisive firing at the rails - and which a design wants is not universal. Across five specialized-attention designs at 125M parameters, 44 to 62 percent of value channels become crisp, contextually selective detectors, and their legibility rises with depth rather than crystallizing only on punctuation. Language-model quality is at parity with a conventional baseline. Finally, we couple the Boolean attention to the legible feed-forward layer and train an end-to-end legible-by-construction language model at benchmark parity: its feed-forward units are named set and quantifier operations throughout, and we can take a token it generates and read the named units that compose to produce it.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：**约束什么检测（value），而非约束什么写入（output projection）**。  
  - 将注意力头的值向量通过 sigmoid 函数限制到 [0, 1]，使每个值通道成为“特征是否存在”的**模糊隶属度检测器**。  
  - 输出投影（WO）保持自由、不绑定到词汇表——避免数值坍塌（如绑定到词汇表会导致头部输出退化为无上下文常数）。
- **两种具体实现**：
  1. **Membership Value Head**：直接对标准值投影加 sigmoid：\(V_h = \sigma(X W_v^h) \in [0,1]^{T \times d_h}\)，不增加参数。
  2. **Boolean Value Head**：将值投影拆分为两个半维投影 \(W_a^h, W_b^h\)，计算交集 \(A \odot B\) 和构造差集 \(A \odot (1 - B)\)，完整保留原参数总量，使值成为**显式逻辑运算的组合**。
- **选择性压力（Selectivity Pressures）**：
  - **稀疏性（Sparsity）**：\(\lambda_s \sum_{t,c} |v_{t,c}|\)，迫使通道默认关闭，仅在必要时激活。
  - **清晰性（Crispness）**：\(\lambda_c \sum_{t,c} v_{t,c}(1 - v_{t,c})\)，推动值贴近 0 或 1（边缘决策）。
  - 不同设计所需组合不同：单一隶属度头需要两者；布尔交运算头（因交天然稀疏）只需清晰性，加稀疏压力会导致可读单元死亡。
- **端到端模型**：将布尔注意力（100%）与可读前馈层（Oskin 2026，包含模糊集运算 + 自遗忘量词）耦合，形成统一的可读 Transformer。

## 6. 论文的主要结论与发现

1. **注意力值可读性可被构造**：125M 参数下，44%–62% 的值通道成为清晰、上下文选择性检测器，且可解释性**随深度增加**（深层可达 70%–95%），直接反驳了“注意力头仅对标点符号结晶”的流行观点。
2. **约束位置至关重要**：约束检测（value）而非写入（output projection）是成功的关键；绑定写入会导致坍塌。
3. **选择性压力需按设计匹配**：单一隶属度头需同时使用稀疏与清晰压力；布尔交运算符仅需清晰压力，加稀疏压力会令操作数死亡。
4. **端到端可读模型质量与基线持平**：最佳变体在 LAMBADA、BLiMP 上位于基线性能带，ARC-Easy 略有下降但可接受。采用清晰性压力的端到端模型前馈层操作数保持活跃，可命名为语法/语义特征（如比较级、否定、完成体等）。
5. **存在训练稳定性边界**：Membership-75% 设计（9 个有界头 + 3 个无界头）会因“饥饿的无界少数”导致发散；而全有界或均匀拆分稳定。
6. **可读性可用来“阅读一次预测”**：以“it was the best of times, it was the”生成“worst”为例，可通过前馈层命名操作（最级 ∩ 否定 → “worst”）直接归因。

## 8. 不足与局限

- **实验样本量有限**：所有结果基于**单种子**，无法评估方差和统计显著性；仅覆盖 125M 规模，可解释性在更大模型（如 1B+）是否保持未验证。

- **注意力可读性受深度依赖**：浅层注意力在端到端模型中大量坍缩为常数（CONSTANT），特别是耦合可读 FFN 后，浅层注意力几乎不贡献可读信息。

- **缺乏实际应用验证**：仅展示了“阅读预测”的示例，未做编辑、监控、审计等具体行动任务的量化评估。
- **训练稳定性边界未完全解决**：特定的混合比例（如 75%）会发散，而全有界或全无界则稳定，这限制了设计选择的灵活性。
