## 摘要
我们提出MiSS，一个黑盒、基于查询的框架，通过扰动相关的充分性推理来解释3D点云分类器。MiSS将超点分区视为可解释的抽象层，并询问在指定扰动分布下，能否从几何区域的最小联盟中认证原始预测。与需要布尔特征空间或预测器白盒逻辑编码的溯因解释器不同，MiSS将候选提议与验证分离：加权MaxSAT程序使用启发式自适应基数下限、经过认证的精确大小回退、安全收紧的上界、阻塞子句以及从先前预言机评估中学习的代理获取启发式来提出联盟，而黑盒统计预言机则根据预测查询决定充分性。该系统返回一个统计验证的充分联盟作为二元归因，当经过认证的搜索完成时保证最小基数。在ModelNet40和ShapeNet上使用PointNet和PointMLP分类器的实验表明，在大多数设置下，与基于规则的基线相比，具有更高的精确度和覆盖率，且解释时间低于穷举搜索。

## Abstract
We present MiSS, a black-box, query-based framework for explaining 3D point cloud classifiers through perturbation-relative sufficiency reasoning. MiSS treats a superpoint partition as an interpretable abstraction layer and asks whether the original prediction can be certified from a minimal coalition of geometric regions under a specified perturbation distribution. Unlike abductive explainers that require Boolean feature spaces or white-box logical encodings of the predictor, MiSS separates candidate proposal from verification: a weighted MaxSAT procedure proposes coalitions using a heuristic adaptive cardinality floor, certified exact-size fallback, a safely tightened upper bound, blocking clauses, and a surrogate acquisition heuristic learned from previous oracle evaluations, while a blackbox statistical oracle decides sufficiency from prediction queries. The system returns a statistically verified sufficient coalition as a binary attribution, with minimum cardinality guaranteed when certified search completes. Experiments on ModelNet40 and ShapeNet with PointNet and PointMLP classifiers show higher precision and coverage than rule-based baselines in most settings, with lower explanation time than exhaustive search.

**问题**：3D点云分类器（如PointNet、PointMLP）是自动驾驶、机器人等关键应用的基础，但作为深层神经网络，其决策过程难以解释。现有解释方法（如SHAP、LIME、Grad-CAM）大多提供特征级别的归因分数，无法给出“预测为何保持不变”的充分性保证。尽管溯因解释（Abductive Explanation）能给出最小充分特征子集，但其基于布尔特征空间和完整逻辑编码的假设，无法直接应用于连续、非结构化的点云数据。因此，亟需一种能输出**逻辑驱动、最小充分、且可验证**的解释方法，用于点云分类器。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **抽象层**：将点云过分割为**超点**（superpoint），每个超点作为不可分割的解释单元。
- **扰动相对充分性**：定义Minimal Sufficient Set (MiSS)为：保留该超点联盟时，在给定扰动分布下，分类器预测不变的概率≥阈值τ，且任何真子集都不满足该条件。
- **分离候选与验证**：利用**加权MaxSAT**搜索候选联盟，由**黑盒统计预言机**（基于KL置信区间）验证充分性。两者交替迭代，直到找到最小充分集或资源耗尽。

### 2.2 关键技术细节
1. **几何分割**：使用曲率增强K-Means将点云划分为K个超点。
2. **扰动算子**：对不保留的超点，从训练集中采样同构的局部补丁替换，保持数据流形。
3. **加权MaxSAT建模**：
   - **硬约束**：自适应基数上下界（ℓcur ≤ |C| ≤ Lcur）、阻塞子句（避免重复搜索）、失败子集剪枝子句。
   - **软约束**：每个超点对应一个软子句(¬xi, qi)，qi = round(α_soft(1-wi))，wi是代理模型给出的包含倾向权重。代理模型用历史评价数据训练样本加权岭回归，预测每个超点的充分性概率。
4. **搜索策略**：
   - 使用**启发式自适应基数下限**：通过当前窗口内失败次数提升下限，跳过明显不充分的尺寸。
   - 当单次搜索窗口UNSAT时，调用**认证回退**，保证最小基数。
   - **代理获取启发式**：利用全部历史评价拟合回归权重，优先选择高权重超点。
5. **黑盒统计预言机**（Algorithm 4）：
   - 逐批采样扰动输入，更新成功计数。
   - 使用KL置信区间（置信度δtest）判断充分性是否高于τ。
   - 返回充分性决策、经验精度、使用样本数。

### 2.3 算法流程（核心Algorithm 1）
1. 初始化：评估所有单超点联盟，初始化历史、基数窗口、代理模型权重。
2. 循环（满足时间和查询预算）：
   - 构建加权CNF（含当前约束和软子句）。
   - MaxSAT求解得到候选联盟C。
   - 若UNSAT则中断（此时可认证当前窗口内无充分集）。
   - 调用预言机验证C：若充分，记录并收紧上界Lcur ← |C|-1；若不足，添加剪枝子句。
   - 更新下限、重新拟合代理模型。
3. 返回所有已验证充分联盟中基数最小的一个，或∅。
