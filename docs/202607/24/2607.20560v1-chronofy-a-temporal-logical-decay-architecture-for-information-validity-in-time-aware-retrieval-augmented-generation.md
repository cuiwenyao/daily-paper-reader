## 摘要
检索增强生成（RAG）系统检索并集成外部知识以支持大型语言模型（LLM）的输出。然而，当前的RAG架构将所有检索到的事实视为同等有效，而不考虑时间来源，导致时间幻觉——看似合理但过时的事实污染输出。昨天进行的临床实验室检测结果具有可操作性；而六个月前的同一检测结果则是噪音。我们提出了Chronofy，一个三层神经符号框架，实现了时间-逻辑衰减架构（TLDA），将时间有效性直接嵌入到RAG系统的表示、检索和推理层中。第一层在套娃嵌入中保留一个专用时间子空间，使事实的年龄在结构上不可从表示中移除。第二层将可学习的指数衰减函数集成到基于图的检索中，其中衰减系数β_j基于贝叶斯决策理论，近似为潜在过程均值回归速率的两倍。第三层应用信号时序逻辑（STL）鲁棒性函数来评估检索知识的时间有效性（而非LLM输出置信度），并强制执行可能性最弱链原则，以推理链中衰减最严重的证据来约束输出置信度。我们在时间知识图谱预测基准、TimE时间问答基准以及特定领域敏感性分析上评估了Chronofy，结果表明显式的时间衰减建模提高了检索精度，减少了时间幻觉，并在时间上下文不足时实现了有原则的数据重新获取触发。

## Abstract
Retrieval-Augmented Generation (RAG) systems retrieve and integrate external knowledge to ground large language model (LLM) outputs. However, current RAG architectures treat all retrieved facts as equally valid regardless of temporal provenance, leading to temporal hallucination, where plausible but obsolete facts corrupt the output. A clinical lab reading from yesterday is actionable; the same reading from six months ago is noise. We present Chronofy, a three-layer neuro-symbolic framework implementing the Temporal-Logical Decay Architecture (TLDA) that embeds temporal validity directly into the representation, retrieval, and reasoning layers of RAG systems. Layer 1 reserves a dedicated temporal subspace within Matryoshka embeddings to make fact age structurally irremovable from the representation. Layer 2 integrates learnable exponential decay functions into graph-based retrieval, where the decay coefficient $β_j$ is grounded in Bayesian decision theory as an approximation of twice the latent process mean-reversion rate. Layer 3 applies Signal Temporal Logic (STL) robustness functions to evaluate the temporal validity of retrieved knowledge, not LLM output confidence, and enforces the possibilistic weakest-link principle to bound output confidence by the most decayed evidence in the reasoning chain. We evaluate Chronofy on temporal knowledge graph forecasting benchmarks, the TimE temporal QA benchmark, and a domain-specific sensitivity analysis, demonstrating that explicit temporal decay modeling improves retrieval precision, reduces temporal hallucination, and enables principled data re-acquisition triggers when temporal context is insufficient.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：当前检索增强生成（RAG）系统将所有检索到的事实视为同等有效，忽略其时间来源，导致“时间幻觉”——即模型使用过时但语义匹配的事实输出看似合理但错误的答案。例如，临床系统中6个月前的钾离子检测结果被当作当前值使用。
- **背景**：现有工作（如TempValid、STAR-RAG、Mao et al.）分别解决了时间衰减、时间感知检索或时序逻辑验证中的某个片段，但缺乏在表示、检索和推理三个层次系统性地嵌入时间有效性的统一框架。Chronofy旨在填补这一空白，使RAG能够基于事实的时效性进行有原则的推理，并在上下文不足时触发数据重新获取。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
Chronofy是一个三层神经符号架构（TLDA），将时间有效性直接嵌入RAG的表示层、检索层和推理层：
- **Layer 1**：在嵌入中保留专用时间子空间，使事实年龄在结构上不可被忽略。
- **Layer 2**：在基于图的检索中集成可学习的指数衰减函数，按事实类型动态调整衰减速率。
- **Layer 3**：应用信号时序逻辑（STL）鲁棒性函数评估检索知识的时间有效性，并通过“最弱链原则”约束输出置信度。

### 技术细节

#### Layer 1：时间子空间嵌入
- 每个证据为元组 `e = (c, t_e, q, m)`（内容、时间戳、来源可靠性、元数据）。
- 嵌入 `e = [e_temp; e_sem]`，其中 `e_temp` 由时间投影模块生成，使用LoRA微调和CKA对比损失，确保截断后年龄信息保留。
- `t` 个维度专用于时间，其余用于语义。

#### Layer 2：衰减加权图检索
- 基于STAR-RAG的规则图构建（Apriori + MDL），但将指数衰减函数集成到遍历权重中：
  ```
  w(e_ij) = q_e · c(tr_j) · exp(-β_j · (T_q - T_f))
  ```
- 其中 `β_j` 是事实类型特定的可学习参数，`c(tr_j)` 是规则基础语义置信度。
- 边缘权重低于阈值 `τ` 的会被剪枝（认知滤波器），确保陈旧证据被结构性地排除。

#### Layer 3：STL知识有效性验证
- 跟踪推理链每一步用到的事实，定义每步的时间有效性信号：
  ```
  v(s_i) = min_{e ∈ facts(s_i)} [q_e · exp(-β_j(e) · (T_q - t_e))]
  ```
- STL规范：`φ_valid = G[0,n] (v(s_i) ≥ γ)`，鲁棒性评分 `ρ = min_i (v(s_i) - γ)`。若 `ρ < 0`，则输出“数据重新获取”的指令，而非低置信度预测。
- **定理1（最弱链边界）**：推理链的最大可靠输出置信度被所有证据中最小的时间有效性值所上界，证明基于可能性逻辑的 min-聚合。

#### 决策理论基础（命题1）
- 假设潜在状态服从奥恩斯坦-乌伦贝克（OU）过程，信息价值随 `exp(-2κ_j·Δt)` 衰减，因此最优衰减系数 `β_j = 2κ_j`（κ_j 为均值回归速率）。
- 当 `κ_j → 0`（如血型、基因标记），`β_j → 0`，即时间稳定事实得以保留（性质2：时间不变性保证）。

## 6. 主要结论与发现

1. **显式时间衰减建模比静态或纯新近检索更优**：在所有实验中，优化β均优于无时间或仅新近的方法。
2. **最优衰减率因事实类型而异**：从β=0（诊断）到β=10（政治事件），需按领域学习。
3. **时间嵌入与衰减重排序互补**：Layer1单独提升12.7%，Layer2单独提升66.3%，两者结合提升73.9%。

5. **β的决策-理论解释成立**：临床实验中，β*排序与临床直觉一致（诊断<生命体征≈处方<实验室），也符合OU过程性质。
6. **端到端准确性提升**：通过更好的时间感知检索，Oracle proximity将TimE准确率从0.450提升至0.488（+8.4%）。

## 7. 优点

- **系统性**：首次在表示、检索、推理三个层次统一处理时间有效性，形成完整的三层流水线。

## 8. 不足与局限

- **指数衰减的局限**：无法捕获非单调生命周期（如药物失效后再激活）或突发性状态转移；作者提到skew-normal（Chronocept）或非参数方法可替代，但未实现。
