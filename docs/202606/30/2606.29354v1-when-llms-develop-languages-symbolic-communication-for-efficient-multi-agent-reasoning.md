## 摘要
思维链（CoT）虽能提升大语言模型（LLMs）在困难推理任务上的表现，但往往产生冗长的自然语言推理过程，难以与高效的机器推理对齐。我们提出通信语言符号路由（CLSR），一种测试时框架，其中多个LLM智能体自主发明、演化并共享紧凑的语言符号框架（LSFs），同时一个无潜在变量的路由器根据查询自适应地选择和组合这些语言，以优化准确率-词元数权衡。与优化表面指令的提示优化不同，CLSR将每个LSF视为一个可复用的符号协议，包含紧凑符号、使用规则和消息传递契约，并通过由正确性和词元成本驱动的演化循环加以改进。推理时，路由器可调用单个低成本的LSF调用、集成多个LSF，或在较难的查询上执行多轮LSF组合协议。在多个挑战性基准上，与标准CoT相比，CLSR将面向延迟的生词元完成量减少3至6倍，同时保持准确率。我们进一步推导了任意符号主义下词元成本的信息论下界，并证明在解释器可实现的假设下，多轮LSF协议有条件地包含程序执行流水线。代码已公开（https://github.com/pzqpzq/LSF_MDia）。

## Abstract
Chain-of-Thought (CoT) improves large language models (LLMs) on difficult reasoning tasks, but it often incurs long natural-language rationales that are poorly aligned with efficient machine reasoning. We propose Communicative Language Symbolism Routing (CLSR), a test-time framework in which multiple LLM agents autonomously invent, evolve, and share compact Language Symbolism Frameworks (LSFs), while a latent-free router adaptively selects and composes these languages per query to optimize the accuracy-token trade-off. Unlike prompt optimization that refines surface instructions, CLSR treats each LSF as a reusable symbolic protocol with compact symbols, usage rules, and a message-passing contract, and improves it through an evolutionary loop driven by correctness and token cost. At inference time, the router may invoke a single low-cost LSF call, ensemble multiple LSFs, or execute a multi-round LSF composition protocol on harder queries. Across challenging benchmarks, CLSR reduces latency-oriented generated token completion by $3\sim 6\times$ compared to standard CoT while maintaining accuracy. We further derive an information-theoretic lower bound on token cost under arbitrary symbolism and show that, under an interpreter-realizability premise, multi-round LSF protocols conditionally subsume program-execution pipelines. Code is publicly available (https://github.com/pzqpzq/LSF_MDia).

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：尽管Chain-of-Thought（CoT）显著提升了LLM在困难推理任务上的表现，但其产生的自然语言推理链冗长、与高效机器推理不匹配，尤其在不考虑推理成本或部署预算受限的场景下，这种冗长是不必要的。
- **核心问题**：能否让LLM自主发明新的符号语言进行更高效的推理？现有方法（如提示优化、程序执行、RL压缩、神经符号方法）要么只优化自然语言指令，要么依赖外部执行器，或需要昂贵训练，未能实现可复用的、可跨任务迁移的符号通信系统。
- **整体含义**：提出CLSR（Communicative Language Symbolism Routing）框架，让多LLM代理自主发明、演化和共享紧凑的符号语言协议（Language Symbolism Framework, LSF），在测试时通过路由器自适应选择/组合LSF，在保持准确率的同时大幅减少生成词元数，实现准确率-效率帕累托前沿的提升。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将LLM推理视为一个多代理符号通信过程：多个代理作为黑盒LLM实例，共同发明和演化可复用的LSF，LSF是包含紧凑符号、语法和使用规则的推理协议。
- 通过进化学习（evolutionary bootstrapping）不断优化LSF：基于正确性和词元成本进行选择、变异和继承，使得高信息密度的符号协议被保留。
- 测试时使用一个无潜在变量的LLM路由器（latent-free router），根据查询自适应选择单个LSF、集成多个LSF（类似self-consistency）或多轮组合LSF，以优化准确率-词元权衡。

### 关键技术细节
1. **LSF定义**：每个LSF S_k = (V_k, G_k, R_k, ψ_k, ρ_k)，包含符号库存、语法、使用规则、语义映射和经验档案（成本、准确率、领域等）。LLM通过给定少量样本自动生成LSF（无人工程编辑）。
2. **LSF进化循环**：
   - 将训练集分为M组；用第一组生成初始LSF池；在后续组评估、选择“高杠杆”（正确且词元高效）的推理轨迹；以此为上下文让LLM变异/重组合成下一代LSF；保留精英LSF跨代。
3. **路由策略**：
   - 离线汇总每个LSF的简档（profile）为压缩描述。
   - 测试时，LLM路由器先输出计划（单LSF直接回答/多LSF集成/隐式多轮组合），然后按计划执行。所有生成词元计入成本。
