## 摘要
多模态大语言模型在视觉推理方面表现出色，但依赖基于文本的思维链，缺乏可解释的视觉中间表示。现有方法使用不透明标记或外部工具，缺失关键属性。我们提出Gen-VCoT框架，利用专家视觉模型生成RGB图像作为推理中间表示。该框架包含三个阶段：视觉定位（SAM分割）、几何推理（Marigold深度图）和语义推理（Qwen2-VL集成）。自适应路由器选择推理深度。评估显示Gen-VCoT在空间（提升25%）和深度（提升50%）问题上表现更好，但可能损害简单的事实查询。在CLEVR上，文本思维链优于视觉中间表示（91.2% vs 62.5%），表明最优表示依赖于任务。Gen-VCoT为可解释的多模态推理建立了新范式。

## Abstract
Multimodal large language models (MLLMs) excel at visual reasoning but rely on text-based chain-of-thought (CoT), lacking interpretable visual intermediates. Existing methods use opaque tokens or external tools, missing key properties. We propose Gen-VCoT, a framework using expert vision models to generate RGB images as reasoning intermediates. It has three stages: visual grounding (SAM segmentation), geometric reasoning (Marigold depth maps), and semantic reasoning (Qwen2-VL integration). An adaptive router selects reasoning depth. Evaluations show Gen-VCoT improves spatial (25% better) and depth (50% better) questions, but may hurt simple factual queries. Text CoT outperforms visual intermediates on CLEVR (91.2% vs 62.5%), showing task-dependent optimal representations. Gen-VCoT establishes a new paradigm for interpretable multimodal reasoning.

- **核心问题**：多模态大语言模型在视觉推理中主要依赖文本链式思维，缺乏显式、可解释的中间视觉推理步骤。现有方法如使用连续视觉令牌（不可解释）或调用外部工具（依赖稀疏几何图元、不能端到端）均无法同时满足可解释性、端到端训练和密集像素级表示。
- **研究动机**：受 Google DeepMind 的 Vision Banana 工作启发，该工作证明图像生成模型可以作为通用视觉学习者，即“生成即理解”。作者假设从图像生成分割图或深度图的过程本身编码了视觉理解，因此可以将其作为推理的中间产品。
- **整体含义**：本文首次系统性地使用专家模型生成的 RGB 图像作为视觉推理中间表示，建立了一种全新的可解释多模态推理范式，并通过自适应路由器动态选择推理深度，实现效率与质量的平衡。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：将视觉推理分解为三个可解释的阶段，每个阶段生成 RGB 图像作为中间证据，最后交给 MLLM 整合回答。
- **阶段 1：视觉定位（Where）**  —— 使用 SAM（Segment Anything Model）生成实例分割图。
    - 输入：原始图像 I。
    - Prompt 策略：均匀采样 N×N 网格点（N=8，共 64 个点）作为 SAM 的点提示，每个点生成候选掩码，选择最高 IoU 的掩码。
    - 后处理：过滤面积小于 τ_area=100 像素的掩码；剩余掩码分配高对比度颜色。
- **阶段 2：几何推理（How）** —— 使用 Marigold（扩散深度估计器）生成伪彩色深度图。
    - 利用预训练的 Stable Diffusion 先验，采用 LCM（Latent Consistency Model）变体，仅 4 步推理，集成 5 次预测取平均以增强鲁棒性。
    - 深度图归一化后通过彩虹色映射（红→近，紫→远）可视化。
- **阶段 3：语义推理（What）** —— 使用 Qwen2-VL-7B-Instruct 进行多图像推理。
    - 输入：原始图像 + 分割图 + 深度图，按多图像输入方式喂给 MLLM。
    - 提示：明确告知模型三种图像的含义，要求基于视觉证据简洁回答。
- **自适应推理路由器**：
    - 架构：BERT-base 分类器（1.1 亿参数），输入问题文本，输出三类推理路径：path_1（仅分割）、path_1+2（分割+深度）、full（全部三个阶段）。另有一个 baseline 路径（跳过所有中间步骤）。
    - 训练损失：交叉熵 + λ×step_count（效率惩罚），鼓励选择最简单的有效路径。
    - 决策：路由器首先选择路径，然后按 Algorithm 1 执行对应步骤。

### 3. 实验设计

- **数据集/场景**：
    1. **三张合成场景**（室内、街道、公园）：每张场景设计 8 个问题，共 24 个 question-scene 对，覆盖 6 个类别（识别、空间关系、深度感知、计数、属性、复杂推理）。
    2. **CLEVR 风格场景**：生成 10 个合成场景，每场景含 2-4 个彩色 3D 物体，共 80 个问题（存在性、计数、属性查询、形状查询、空间推理），具有确定答案。
- **基准方法**：
    - Baseline：直接 MLLM 推理（仅原图）。
    - No Depth：原图 + 分割图。
    - No Seg：原图 + 深度图。
    - Full（Gen-VCoT）：原图 + 分割 + 深度。
    - 额外对比：Text CoT（提供结构化文本描述，无视觉中间产品）。
- **评价指标**：答案准确率（精确匹配或包含匹配）、推理延迟、总吞吐量。

### 4. 资源与算力

- **硬件**：单张 NVIDIA RTX 3090（24GB VRAM），所有模型顺序加载以节省内存。
- **模型**：SAM ViT-Large（1.3GB）、Marigold LCM fp16（3GB）、Qwen2-VL-7B-Instruct（16.6GB）。
- **时间**：
    - 预处理（每张图像）：SAM 加载 1.1s + 推理 1.1s；Marigold 加载 2.1s + 推理 2.5s；Qwen 加载 11.9s。
    - 每问题推理：Gen-VCoT 0.8s，Baseline 0.3s。

### 5. 实验数量与充分性

### 6. 主要结论与发现

1. **对复杂空间推理有效**：Gen-VCoT 在空间关系（+25%）和深度感知（+50%）问题上显著提升，总体准确率 78.9% vs Baseline 68.4%。
2. **对简单事实查询可能有害**：在 CLEVR 基准上，Gen-VCoT（62.5%）劣于 Baseline（85.0%），原因在于中间表示引入噪声（SAM 无关掩码、Marigold 在合成场景中无意义梯度）。
3. **文本 CoT 在事实查询上更优**：Text CoT 在 CLEVR 达到 91.2%，优于全部视觉方法，表明对于简单属性查询，结构化文本比视觉中间表示更精确。
4. **最优表示依赖于任务**：空间/深度任务应选视觉中间表示；事实查询应选文本描述或直接推理。这一发现为自适应路由器的设计提供了强动机。
5. **分割与深度互补**：消融实验证明，两个中间表示各有侧重，同时使用效果最好。
6. **实用推理速度**：通过批处理优化，每问题推理时间可降至约 5.2 秒，具备实用性。

### 7. 优点

- **可解释性**：中间表示为 RGB 图像，可直接被人类理解，比连续令牌或文本描述更直观。
