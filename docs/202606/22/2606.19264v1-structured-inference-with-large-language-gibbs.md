## 摘要
大语言模型（LLMs）中编码的知识可作为描述复杂世界变量的结构化推理基础，但以概率一致的方式访问这些知识构成了一个困难的推理问题。我们提出大语言模型吉布斯采样（Large Language Gibbs），一种利用LLM的条件分布作为转移算子的结构化概率推理方案。不同于通过单遍自回归生成来采样结构化对象，我们使用LLM的下一个标记条件概率迭代地重新采样以其他变量为条件的单个变量。这种方法避免了顺序依赖偏差，并产生一个反映所有局部条件概率之间权衡的平稳分布。我们将此方法应用于从合成分布采样、一致推理任务和贝叶斯结构学习。结果表明，在可通过带噪声的LLM条件概率访问的世界先验下，使用MCMC中的LLM条件概率是用于结构化概率推理的单遍生成的一种实用替代方案。

## Abstract
The knowledge encoded in large language models (LLMs) can serve as a substrate for structured reasoning over variables describing a complex world, but accessing this knowledge in a probabilistically coherent manner poses a difficult inference problem. We propose Large Language Gibbs, a scheme for structured probabilistic inference that uses conditional distributions of an LLM as transition operators. Rather than sampling structured objects through single-pass autoregressive generation, we iteratively resample individual variables conditioned on others using an LLM's next-token conditionals. This approach avoids order-dependent biases and produces a stationary distribution that reflects a compromise between all local conditionals. We apply this approach to sampling from synthetic distributions, consistent reasoning tasks, and Bayesian structure learning. The results suggest that the use of LLM conditionals in MCMC is a practical alternative to one-pass generation for structured probabilistic inference under a world prior accessible through noisy LLM conditionals.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）内部编码了丰富的世界知识，可用于对描述复杂世界的结构化变量（如标签分配、表格数据、因果图等）进行推理。然而，如何以概率一致的方式从 LLM 中提取这些知识，尤其是对于高维联合分布，是一个困难问题。
- **现有方法的不足**：常用的单遍自回归生成（从左到右依次生成所有变量）会引入顺序依赖偏差（如“近因效应”和“中间丢失”），导致生成的样本偏离目标联合分布。即使批量生成（batch sampling）能改善边缘分布，但样本间存在高自相关，不满足独立同分布假设。
- **核心动机**：本文提出使用 LLM 的条件分布作为马尔可夫链蒙特卡洛（MCMC）中的吉布斯转移算子，通过迭代地重新采样每个变量（给定其他变量的当前值），避免固定顺序的偏差，并产生一个反映所有局部条件一致性的平稳分布。

## 2. 论文提出的方法论

### 2.1 核心思想
- **大语言模型吉布斯采样（Large Language Gibbs）**：将每个变量 \(X_i\) 与自然语言描述 \(c_i\) 关联，利用 LLM 的下一词条件分布 \(p_{\text{LM}}(\cdot)\) 来近似吉布斯采样中的条件概率 \(q_i(X_i \mid X_{-i})\)。
- **基本版本**（§3.1）：对每个待重采样的变量 \(X_i\)，将其他变量 \(X_{-i}\) 按随机排列序列化作为上下文，然后使用 LLM 生成 \(X_i\) 的条件分布。通过随机排列移除顺序偏差。
- **公式表示**：
  \[
  q_{\text{LM}}^i(X_i \mid X_{-i}) = \mathbb{E}_{\sigma_{-i}}\left[ p_{\text{LM}}\big(X_i \mid \text{seq}(X_{-i}, \sigma_{-i}) \oplus [c_i]\big) \right]
  \]
  其中 \(\sigma_{-i}\) 是除 \(i\) 外所有变量的随机排列。

### 2.2 关键理论分析
- 该链的平稳分布 \(q^*\) 是一个唯一分布。在假设“联合似然对变量序列中最后一个变量排列不变”（Assumption 3.1）时，该平稳分布等于对称化联合分布 \(q_{\text{sym}}(X) = \mathbb{E}_{\sigma}[p_{\text{LM}}(\text{seq}(X, \sigma))]\)。
- 即使局部条件不兼容，该过程仍能收敛到唯一平稳分布。

### 2.3 两种判别式预测核（§3.2）
- **Barker 吉布斯**：从简单提议分布（如均匀分布）抽样候选值，然后使用 LLM 以 Barker 规则计算接受概率（对比当前值和候选值的似然）。
- **Gambling 吉布斯**：将接受决策转化为“赌博”任务——询问 LLM 是否愿意下注一定金额赌候选值更合理；通过贪婪解码（无需校准概率）即可实现。

### 2.4 实践变体（§3.3）
- **Sweeping Gibbs**：按固定顺序循环更新变量（非随机选择），可能加速收敛。
- **Block Gibbs**：一次重采样一组变量（B>1），有助于逃逸高相关变量的局部模式。

### 2.5 算法流程
1. 初始化所有变量 \(X_1,\dots,X_n\)（可用自回归生成）。
2. 对 \(t=1,\dots,T\)：
   - 均匀选取一个变量索引 \(i\)。
   - 均匀采样一个排列 \(\sigma_{-i}\)。
   - 用 LLM 条件分布采样新 \(X_i\)。
   - 记录当前状态。
3. 进行烧入（burn-in）和稀疏采样（thinning）得到最终样本集。

### 3.3 任务三：贝叶斯结构学习（§5.2）

## 6. 论文的主要结论与发现

1. **Gibbs 采样优于单遍生成**：在简单分布采样中，Gibbs 显著降低偏差和自相关；batch sampling 虽有更好边缘但自相关高。
2. **一致推理任务**：Large Language Gibbs 在 TruthfulQA 和 GSM8K-Verification 上全部超越零样本、1-pass、4-pass 和 ICM，且随上下文大小增加性能单调提升（最高 n=64 时准确率提高 10~20%）。
3. **贝叶斯结构学习**：使用 Gibbs 生成的合成数据作为先验，在大多数数据集上优于 uniform 先验和 Direct 采样；但元数据描述不充分时（如 algalactivity2）效果反而下降。
4. **判别式核的有效性**：Barker-Gibbs 和 Gambling-Gibbs 在部分场景有效，但 Gambling-Gibbs 在小模型上表现不佳（指令微调导致校准差），大模型+推理链能改善。
5. **理论保证**：证明了在排列不变性假设下，该链以对称化联合分布为平稳分布。

## 7. 优点

## 8. 不足与局限

- **计算成本高**：Gibbs 需多次迭代（如 burn-in+thinning），比单遍生成更耗时。论文承认了这一点。
- **模型规模限制**：实验仅使用 ≤32B 参数模型，未探索更大模型（如 70B+）的效果。
- **假设不完全成立**：Assumption 3.1（排列不变性）在实践中很难精确满足，理论只是近似。
- **结构学习任务规模小**：最多 15 节点，未在真实高维因果发现问题上验证。
- **一致推理的 baselines 可能被低估**：ICM 本包含 ground-truth 逻辑约束，移除后性能下降，但论文已说明。
- **偏差风险**：LLM 有训练数据偏见，通过 Gibbs 传播可能放大；论文虽提及安全性，但未量化。
- **超参数敏感**：γ（先验权重）对结构学习影响大，调参可能较繁琐。
