## 摘要
几何问题求解越来越采用神经符号范式，将神经直觉与符号严谨性相结合。然而，当前框架在两个核心阶段存在严重瓶颈：自动形式化（将多模态翻译视为与下游求解器兼容性解耦的静态任务）和定理预测（求解器由于固定的规则库而频繁陷入演绎困境）。为解决这些问题，我们提出SD-GPS，一种基于求解器的框架，它在形式化和演绎过程中都将符号求解器视为执行预言机。首先，基于求解器的自动形式化将监督式形式语言适应和可解性引导的强化学习统一到基于QwenVL3-2B的单个模块中，使得可执行性成为核心训练信号。第二，验证的定理提议引入了一个意识到困境的智能体，从当前证明状态提出局部辅助引理，并通过符号验证过滤所有提议来确保健全性。在Geometry3K和PGPS9K上的实证评估表明，SD-GPS在标准完成、多项选择和跨模态参考设置中始终优于现有的MLLM、神经和神经符号方法，证明了在多模态感知和符号执行之间闭合循环显著改善了几何推理，为神经智能体如何通过形式系统接地以实现可验证的解题能力提供了深刻见解。

## Abstract
Geometry Problem Solving have increasingly adopt the neuro-symbolic paradigm, combining neural intuition with symbolic rigor. However, current frameworks suffer from severe bottlenecks in two core stages: autoformalization, which treats multimodal translation as a static task decoupled from downstream solver compatibility, and theorem prediction, where solvers frequently hit a deductive impasse due to fixed rule libraries. To address these, we propose SD-GPS, a solver-driven framework that treats the symbolic solver as an execution oracle throughout both formalization and deduction. First, Solver-Driven Autoformalization unifies supervised formal-language adaptation and solvability-guided reinforcement learning into a single module built on QwenVL3-2B, making executability the central training signal. Second, Verified Theorem Proposing introduces an impasse-aware agent that proposes local auxiliary lemmas from current proof states, ensuring soundness by filtering all proposals through symbolic verification. Empirical evaluations on Geometry3K and PGPS9K demonstrate that SD-GPS consistently outperforms existing MLLM, neural, and neuro-symbolic methods across standard completion, multiple-choice, and cross-modal reference regimes, proving that closing the loop between multimodal perception and symbolic execution significantly improves geometric reasoning, offering profound insights into how neural agents can be grounded by formal systems to achieve verifiable problem-solving capabilities.

## 一、核心问题与整体含义（研究动机与背景）

几何问题求解（GPS）逐渐采用神经符号范式，即利用神经网络的直觉感知与符号引擎的逻辑推理相结合。但现有框架在两个核心阶段存在严重瓶颈：

1. **自动形式化（Autoformalization）**：当前系统将多模态（文本+图表）到形式语言的翻译视为静态任务，与下游符号求解器的执行需求脱节。即使语义准确，产生的谓词可能无法被求解器执行，导致“解耦+后修”范式的脆弱性。
2. **定理预测（Theorem Prediction）**：符号求解器依赖固定的规则库，当需要罕见定理实例或中间推演（如共圆、相似、比例关系）时，容易陷入演绎僵局（deductive impasse）。

为克服上述问题，论文提出 **SD-GPS**（Solver-Driven Geometry Problem Solving），核心思想是**将符号求解器作为执行预言机（execution oracle），同时驱动形式化学习与定理提议**，形成闭环验证。这从根本上使感知模块的学习目标与最终执行任务对齐，确保形式化输出是可执行的，并通过可验证的辅助引理扩展求解器的推理覆盖。

## 二、方法论：核心思想与关键技术细节

### 2.1 整体框架
SD-GPS 包含两个基于求解器的闭环：
- **第一环（Solver-Driven Autoformalization）**：统一多模态形式化模块 \(F_\theta\)，直接接收原始图表 \(I\) 和问题文本 \(T\)，输出求解器可执行的形式谓词序列 \(\hat{\Lambda}\)。
- **第二环（Verified Theorem Proposing）**：当求解器无法在时限内完成推导时，调用困境感知的定理提议智能体，从当前证明状态提出候选局部引理，经符号验证后（依次检查良类型、可应用性、可证明性、目标缩减性）方可被采用。

### 2.2 形式化数据构建
- **真实数据来源**：Geometry3K-Train、PGPS9K 训练集、PGDP 训练集，统一注释规范并过滤不可执行样本。
- **合成数据**：基于几何模板生成，控制点布局、标注、代数取值等参数，用于补充真实数据中缺少的场景（如省略标签、密集角度标记、视觉相似点）。最终训练数据为元组 \((I, T, \Lambda^*, a^*, m)\)。

### 2.3 Solver-Driven Autoformalization
- **骨干网络**：初始化为 QwenVL3-2B（2B 参数）。
- **第一阶段：监督形式语言适应（SFT）**  
  使用目标形式语言注释进行自回归训练，目标函数为负对数似然：  
  \[
  L_{\text{SFT}}(\theta) = -\frac{1}{N} \sum_{i=1}^{N} \sum_{t=1}^{L_i} \log p_\theta(y_{i,t} | I_i, T_i, y_{i,<t})
  \]
- **第二阶段：可解性引导策略优化（SG-RL）**  
  对每组采样 \(K\) 个候选 \(\{\hat{\Lambda}_{i,j}\}\)，经解析器和求解器执行后，分配综合奖励：
  \[
  R = \lambda_{\text{fmt}} R_{\text{fmt}} + \lambda_{\text{exec}} R_{\text{exec}} + \lambda_{\text{ans}} R_{\text{ans}}
  \]
  其中 \(R_{\text{fmt}}\) 表示格式有效，\(R_{\text{exec}}\) 表示可构造一致证明状态，\(R_{\text{ans}}\) 表示正确得到答案。采用 GSPO（Group Sequence Policy Optimization）更新策略，使模型优化方向与求解器执行兼容性一致。
- **推理时修复**：若形式化失败，允许最多两次修复尝试，最终答案必须来自可执行形式化。

### 2.4 Solver-Driven Theorem Proposing
算法流程（对应论文 Algorithm 1）：
1. 求解器初始化证明状态 \(s_0, h_0\)。
2. 若无法立即解决，则启动循环（最多 \(T_{\max}\) 轮）。
3. 智能体基于当前状态、目标、诊断信息输出候选引理集 \(\mathcal{T}_t\)（约束为受限模式：类型、前提、结论、实体）。
4. 求解器逐一检查：良类型 → 可应用于当前状态 → 可从合法前提验证 → 能缩减目标。
5. 通过者加入局部引理，求解器继续搜索。
6. 若成功则返回答案，否则直至轮次耗尽。
- 所有提议均被验证后才影响推导，保持正确性。

## 七、优点

- **创新性方法**：首次将符号求解器的可执行性作为形式化学习的核心训练信号（SG-RL），使模型与下游任务对齐。

- **可验证定理提议**：通过符号验证保证新增引理的正确性，而非依赖神经网络自由生成，保持了推理的声纳性。
