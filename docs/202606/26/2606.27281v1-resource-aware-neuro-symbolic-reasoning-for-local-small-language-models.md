## 摘要
小语言模型可在消费级硬件上本地运行，但结构化推理常迫使使用者反复采样或转向更大模型。本文研究了一种用于本地推理的有界神经符号替代方案：模型将问题转化为类型化有限域规则与约束，符号层检查可溯性与一致性，确定性求解器执行推理步骤。由此产生的可验证形式化与修复流水线（VFR-LLM）测试了符号验证在何种情况下能以不降低准确率的方式替代重复采样。我们通过Apple Silicon上的LM Studio进行评估，以Qwen3-4B-2507为主要模型，以Phi-4-mini-reasoning和Gemma-3n-E4B进行鲁棒性检验。在120个纯优先关系问题上，Qwen VFR-LLM的准确率达0.983，而使用单次模型调用而非五次调用的串行自一致性方法仅为0.700。在120个实例的BBH派生扩展逻辑演绎子集上，其准确率为0.933，对比方法为0.283。该优势在与更强且成本感知的自适应自一致性基线对比时依然存在——该基线降低了采样成本，但未能弥合单次调用的准确率差距。Gemma复现了相同的模型依赖边界，而Phi在类型化约束上表现负面。其贡献是有界的：对于某些结构化任务，有限域逻辑可替代重复本地采样，节省模型调用次数与串行延迟，并实现依赖层级的令牌节省。

## Abstract
Small language models can run locally on consumer hardware, but structured reasoning often pushes users toward repeated sampling or larger models. This article studies a bounded neuro-symbolic alternative for local inference: a model translates a problem into typed finite-domain rules and constraints, a symbolic layer checks traceability and consistency, and a deterministic solver performs the reasoning step. The resulting Verifiable Formalization and Repair pipeline (VFR-LLM) tests when symbolic verification can replace repeated sampling without weakening accuracy. We evaluate it through LM Studio on Apple Silicon, using Qwen3-4B-2507 as the primary model, with Phi-4-mini-reasoning and Gemma-3n-E4B as robustness checks. On 120 generated pure-precedence problems, Qwen VFR-LLM achieves 0.983 accuracy, versus 0.700 for serial self-consistency using one model call instead of five. On a 120-instance BBH-derived extended logical-deduction subset, it reaches 0.933 versus 0.283. The advantage persists against a stronger cost-aware adaptive self-consistency baseline, which lowers sampling cost but not the single-call accuracy gap. Gemma reproduces the same model-dependent boundaries and Phi is negative on typed constraints. The contribution is bounded: finite-domain logic can replace repeated local sampling for some structured tasks, saving model calls and serial latency, with stratum-dependent token savings.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：小语言模型（SLM）可以在消费级硬件上本地运行，保护隐私、支持离线使用、降低操作成本，但面对结构化推理任务时，单次生成的答案往往不可靠，用户通常被迫采用重复采样（如自一致性）或换用更大的模型。然而，重复采样增加了模型调用次数、生成令牌数和串行延迟，给本地资源有限的设备带来沉重负担。本文旨在探索一种**有界的神经符号替代方案**：能否用一次模型调用加上符号验证和确定性求解，替代多次神经生成，同时保持或提升准确率，并节省本地计算资源？

- **整体含义**：论文并不是声称符号求解器能改进所有LLM推理任务。其定位是：对于**约束显式、搜索空间非平凡的结构化任务**（如排序、逻辑演绎），有限域逻辑可以替代重复本地采样，从而降低推理成本。这项研究为本地小模型的资源高效推理提供了新思路，并划定了该方法适用的边界条件。

## 2. 方法论

### 2.1 核心思想

- 将本地SLM视为一个**概率翻译器**，负责将自然语言问题转换为**类型化有限域规则与约束**的中间表示。
- 符号组件作为**确定性执行器**，在该表示上进行推理。
- 在这两者之间设置**验证层**：在允许求解器输出成为最终答案之前，检查中间表示是否在原始问题中可追溯（grounded in the source text），是否结构完整。
- 如果验证失败，则执行**确定性修复**（仅基于源文本和求解器诊断，不额外调用模型）。
- 这种设计剥离了角色：SLM不负责逻辑推理，只负责翻译；符号层负责可靠执行；验证层确保翻译忠实。

### 2.2 关键技术细节

- **形式语言**：定义为一个元组 \(\mathcal{P} = \langle E, T, F, R, K, q \rangle\)，其中：
  - \(E\)：有限实体常量集合
  - \(T\)：类型映射
  - \(F\)：基原子事实
  - \(R\)：安全Horn风格规则（变量由有限类型或实体谓词限定范围）
  - \(K\)：有限域约束（包括before/after、type_before、position等）
  - \(q\)：查询问题
  - 没有函数符号，没有无界量化，所有规则在求解前可被基化（range-restricted）。
- **推理流程**（VFR-LLM流水线五阶段）：
  1. **形式化**：LLM将问题翻译为结构化中间表示（含实体、事实、规则、约束、源文本片段）。
  2. **覆盖率检查**：验证每个形式约束是否在原始文本中有根据，标记缺失或无法支持的约束。
  3. **求解执行**：确定性求解器（当前为枚举式有限域求解器，搜索所有双射位置分配）执行推理，返回答案或失败诊断。
  4. **修复**：如果求解器失败或诊断指出形式化不完整，确定性修复模块应用局部编辑（规范化比较语法、修正颠倒的参数、删除不支持的导入规则等）。修复不调用模型。
  5. **答案生成**：从求解结果生成最终答案，并链接回证明它的约束。

- **资源模型**：
  - 直接回答成本 \(C_{dir}\)，自一致性成本 \(C_{sc}(k) \approx \sum C_{answer,i} + C_{vote}\)
  - VFR成本 \(C_{vfr} = C_{formalize} + C_{verify} + C_{solve} + C_{repair}\)
  - 在目标任务类上，期望 \(C_{solve}\) 和确定性修复远小于额外的神经生成，而形式化 \(C_{formalize}\) 不可忽略。因此只有在形式化+确定性检验比重复生成更便宜时，方法才能节省资源。

## 6. 主要结论与发现

1. **纯优先任务（生成）**：
   - Qwen VFR-LLM准确率0.983，自一致性（k=5）0.700，Direct 0.675；令牌减少34.4%。
   - Gemma类似：0.683 vs. 0.367，令牌减少39.1%。
   - **最强支持**：方法能以一次调用替代五次采样，且准确率大幅提升。

2. **BBH派生扩展子集（120实例，含绝对位置）**：
   - Qwen VFR-LLM准确率0.933，Direct 0.317，自一致性0.283；减少调用和延迟（11.32s vs 16.54s），但令牌数增加（702.9 vs 618.6）。
   - **优势在于准确率和调用节省，而非令牌减少**。
   - 自适应自一致性基线（~4次调用）仍无法弥合准确率差距（0.933 vs 0.283，McNemar p=1.4e-21）。

3. **类型化优先任务**：
   - Qwen：Direct准确率0.850最高，VFR 0.817，被直接回答主导，不构成节省。
   - Gemma：VFR 0.608 vs Direct 0.408，提升但延迟更高（23.36s vs 3.57s），混合支持。
   - Phi：VFR准确率仅0.042，Direct 0.183，形式化严重失败 → **负面结果**。

4. **模型依赖性**：
   - Qwen在扩展BBH上表现优异，Gemma仅微弱提升（0.375 vs 0.350，不显著），Phi几乎无效。
   - 自动可追踪性检查显示：Qwen完全可追踪率达0.942，Gemma仅0.292 → 解释性能差异。

5. **确定性消融证明形式化必要性**：类型化有限域求解器在BBH扩展上准确率1.000，而纯优先求解器仅0.208 → 固定位置约束是必要的。

6. **负控制**：两个求解器变体都拒绝所有故意无效实例（返回unsat或invalid），证明符号层能识别不可能状态。

## 7. 优点

1. **清晰的理论框架**：明确分离概率翻译器、验证层和确定性执行器，资源模型与错误模型定义清楚。
2. **有界的资源声明**：不夸大方效，明确在直接回答已足够好的情况下不适用，仅在结构化约束任务中可能有优势。
3. **广泛的实验验证**：涵盖三个模型家族、多个基准、多种基线（包括自适应自一致性），并进行了自动可追踪性检查和流水线消融，验证了每部分贡献。
4. **可审计性设计**：源文本片段与形式约束相关联，使得答案生成路径可追溯，便于审查和诊断。
5. **确定性修复透明**：修复操作在实验前指定、记录并依据源文本，避免了隐藏的推理通道。
6. **对模型错误的细致分类**：失败模式分为模式/语法错误、未知实体、不支持规则、不可满足等，有助于定位瓶颈。

## 8. 不足与局限

1. **任务范围有限**：仅测试了排序和有限约束满足，未验证规划、非排序约束分配、开放域推理等。作者承认需要扩展到非排序有限域任务。
2. **公开基准筛选性强**：BBH派生子集仅保留能用有限域排序语言表示的实例，不覆盖完整BBH逻辑演绎任务，外部有效性受限。
3. **模型依赖性显著**：Qwen效果最好，Gemma中等，Phi失败 → 方法不是模型无关的。当前形式化目标对某些小型模型可能过于困难或昂贵。
4. **资源度量不完整**：未测量能耗、热节流、内存压力，仅用令牌、调用、延迟作为代理，且未实现并行自一致性对比（串行假设）。
5. **非逐位可复现**：LM Studio后端不公开随机种子，虽通过重复探测验证稳定性，但限制了精确复现。
6. **修复层风险**：确定性修复虽透明，但若前提条件不可检查，仍可能隐含推理。源文本映射的语义忠实性依赖自动检查，未进行独立人工标注。
7. **可能遗漏形式化失败**：自动可追踪性检查不能捕捉所有自然语言释义或语用蕴含错误，仍存在未检测的翻译失真风险。
8. **自适应基线未完全探索**：虽然测试了文献中的自适应自一致性（Beta停止准则），但未尝试更激进的难度自适应预算方法（如Difficulty-Adaptive Self-Consistency），可能进一步缩小差距。
