## 摘要
尽管多模态大语言模型（MLLMs）在复杂的视觉-语言任务上展现出卓越的能力，但它们从复杂且嘈杂的环境中提取与查询相关的视觉特征的机制仍然不透明。在本文中，我们进行了一项深入的可解释性研究，揭示了 MLLMs 内部一个深刻的结构特性：跨模态检索中的功能稀疏性。利用一种称为检索注意力质量（RAM）的词元级指标，我们识别并描述了一组高度专业化的注意力头，称为上下文感知检索（CoRe）头。在不同的视觉领域和模型规模上，我们观察到一个清晰的功能划分：CoRe 头充当专用的信息提取器，而大多数其他头则将注意力分布到更广泛的上下文区域。因果干预进一步证明了这些专业化头的必要性。仅消融前5%的 CoRe 头就会导致多模态推理性能显著下降，而消融排名靠后的头则影响甚微。此外，加速实验验证了 CoRe 头的实用性，表明利用这种局部稀疏性可以显著加速推理，同时保持稳健的任务性能。我们的研究结果揭示了 MLLMs 内部功能稀疏性的结构原理，完善了当前对机制可解释性的理解，并为未来架构设计和模型优化奠定了理论基础。

## Abstract
While Multimodal Large Language Models (MLLMs) demonstrate remarkable proficiency on complex vision-language tasks, the mechanisms by which they extract query-relevant visual features from complex, noisy contexts remain opaque. In this paper, we present an in-depth interpretability study that uncovers a profound structural property within MLLMs: functional sparsity in cross-modal retrieval. Leveraging a token-level metric termed Retrieval Attention Mass (RAM), we identify and characterize a highly specialized subset of attention heads, referred to as Context-aware Retrieval (CoRe) heads. Across diverse visual domains and model scales, we observe a clear functional division: CoRe heads act as dedicated information extractors, while most other heads distribute attention over broader contextual regions. Causal interventions further demonstrate the necessity of these specialized heads. Ablating only the top 5% of CoRe heads causes significant degradation in multimodal reasoning performance, whereas ablating lower-ranked heads has minimal effect. Moreover, acceleration experiments validate the utility of CoRe heads, showing that leveraging this localized sparsity significantly accelerates inference while maintaining robust task performance. Our findings reveal a structural principle of functional sparsity within MLLMs, refining the current understanding of mechanistic interpretability and laying a theoretical foundation that can inspire future architecture design and model optimization.

## 2. 论文提出的方法论

### 2.1 核心思想
- 提出**检索注意力质量（Retrieval Attention Mass，RAM）** 指标，定量衡量每个注意力头从查询词元到关键视觉目标词元的注意力分配强度。高 RAM 值表示该头部实现了精准的跨模态检索。
- 基于 RAM 排序，识别出**上下文感知检索头部（CoRe Heads）**——即 RAM 得分最高的稀疏子集，这些头部是信息提取的核心。

### 2.2 关键技术细节
1. **RAM 公式**：
   $$M_{RAM}^{(h)}(q \to V^*) = \mathbb{E}_{x \in q} \left[ \sum_{y \in \Omega(V^*)} A_{x \to y}^{(h)} \right]$$
   其中 \(q\) 为指令查询词元集合，\(\Omega(V^*)\) 为关键视觉实体对应的离散词元索引，\(A_{x \to y}^{(h)}\) 为头 \(h\) 中从词元 \(x\) 到 \(y\) 的注意力权重。该指标通过平均所有查询词元，反映头部的预期检索强度，并且由于限制求和到目标区域，能够区分真正的检索头与注意力汇（attention sinks）。

2. **探测流程**（图 3）：

   - 应用公式（1）聚合得到每个头的标量 RAM 得分，形成全局分布，得分最高的头部被定义为 CoRe heads。

### 2.3 因果验证与加速方法
- **因果干预**：在推理时通过注意力头掩码消融指定头部，对比 Top‑k CoRe heads、Bottom‑k heads 和随机掩码对性能的影响。
- **加速实验**：提出 **CoRe 引导的混合注意力机制**——预填充阶段，对 Top‑k CoRe heads 保留标准全注意力，其余头部采用局部滑动窗口的流稀疏注意力（Stream Sparse Attention），解码阶段恢复标准注意力。通过预填充速度提升衡量加速效果。

## 6. 论文的主要结论与发现

1. **功能稀疏性普遍存在**：在多种 MLLM 中，RAM 得分呈高度倾斜分布，仅前 5%–10% 的注意力头（CoRe heads）支配了跨模态信息检索，其余头部表现为全局、弥散的注意力模式。
2. **因果必要性**：仅消融前 5%（约 5–30 个）CoRe heads 即导致多模态推理准确率骤降（Qwen‑VL‑4B 从 45.3% 降至 27.0%，LLaVA 从 16.4% 降至 10.6%），而消融低排名头部几乎无影响。
3. **规模演变规律**：随模型容量从 4B 增至 32B，CoRe heads 从分散分布演化为在深层（第 44–56 层）形成高度集中的“瓶颈”区域。更大模型展现出更高的注意力冗余，允许更激进的无损剪枝。
4. **跨任务稳定性**：不同数据集（静态图像、视频、文档、长上下文）之间 Spearman 相关系数高达 0.79–0.92，约 30 个头部在所有任务中稳定高激活，呈现“全局一致、局部变异”的分布范式。
5. **加速有效性**：通过仅保留 Top‑k CoRe heads 的全注意力（占比 1.2%–25.5%），其余头部改用流稀疏注意力，可实现 1.8×–2.3× 预填充加速，同时性能损失极小（常小于 1%），甚至在细粒度推理任务上略有提升。长序列下加速优势更明显（图 7）。
6. **视觉编码器与预对齐的影响**：InternVL3.5 因其强大的视觉编码器和深层预对齐导致 CoRe heads 分布更密集；而 Qwen3‑VL 和 LLaVA‑OneVision 因视觉‑语言桥接方式不同而呈现不同的稀疏拓扑。

## 7. 优点

- **指标创新**：RAM 从文本到视觉词元的细粒度注意力量化，优于以往粗粒度熵或聚合方法，能精确捕捉查询条件的目标检索能力。

- **因果性验证**：通过注意力头部掩码进行严格的因果干预，而非仅相关性分析，证明了 CoRe heads 的不可或缺性。
- **加速落地**：将机制洞察转化为实际系统加速方案（混合注意力），在不依赖额外训练或微调的情况下实现显著加速，且性能保持良好。该方案简单、可部署。

## 8. 不足与局限

- **依赖标注信息**：RAM 计算需要已知关键视觉词元的真值（如边界框、时间管、证据页面），无法直接推广到无标注的抽象推理或开放式生成任务。
- **架构覆盖有限**：仅研究了后融合 Transformer 架构（Qwen、LLaVA、InternVL），未在早期融合、混合编码器或非 Transformer 模型（如 Mamba、RWKV）上验证。
- **静态配置**：加速方案使用预定义的确定性头部掩码（基于一个静态 RAM 排序），未考虑输入样本的自适应性。更理想的方案应是动态、输入依赖的头部路由。
- **计算资源未明确**：未报告 GPU 型号、显存消耗、训练时间等细节，不利于独立复现能耗分析。

- **性能评估维度**：加速实验仅测量预填充延时和任务准确率，未讨论端到端吞吐、显存峰值或能耗改进。
- **理论分析深度**：虽然发现了功能稀疏性的现象学规律，但未深入解释 CoRe heads 在底层如何实现空间/时间对齐的神经网络机制（如是否涉及特定神经元模式）。
