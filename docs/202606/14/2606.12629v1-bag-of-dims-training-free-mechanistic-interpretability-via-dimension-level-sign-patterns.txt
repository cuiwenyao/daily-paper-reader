# ABSTRACT 

We show that the standard basis of transformer hidden states already provides a training-free, architecture-general feature basis. Individual dimensions encode semantic content via their signs ( ±1) and confidence via their magnitudes, func-tioning as independent binary registers. We validate this Bag of Dims framework across three model families (Qwen 3.5-4B, Gemma 3-4B, Mistral 7B) through four progressive experiments. Sign patterns alone carry predictive content: replacing all magnitudes with unity achieves 72–93% top-5 next-token accuracy through the LM head, and pure Ham-ming scoring without any decoder reaches 80–90% top-4096. These sign patterns organize into semantic features: using a single-token type cache (one forward pass per vocabulary token, no context), we discover 175 categories via per-dimension sign consistency (mean AUC 0.80) from 50 anchors with zero training. A trained probe adds only +0.018 AUC and converges to axis-aligned weights, confirming negligible cross-dimension structure. This structure extends to attention: all 175 categories remain discoverable in K and V projections. On the write side, static FFN weight inspection links 20% of features to individual writer neurons ( >0.70 agreement; random controls: 0%), with top-200 neuron coalitions achieving >0.70 agreement on 99.9% of prototypes via majority vote. Fully unsupervised discovery (random seeds, no labels) scales to 1500 features at 100% yield and 99% sparsity across all three models, with pairwise MI of 0.0014 bits confirming low inter-dimension coupling. These results establish that the standard basis already suffices for feature reading throughout the transformer compute pathway, requiring no training, no optimization, and no GPU-days beyond a single forward pass per vocabulary token. 

# 1 INTRODUCTION 

As transformer language models scale and are deployed in safety-critical applications, inspecting what they compute internally becomes increasingly valuable. Current approaches require training separate interpretability models, adding GPU-days and hyperparameters before any feature can be read. We report an empirical finding: individual dimensions in transformer hidden states encode semantic features via their signs. By visualizing the raw dimension values of the residual stream across layers and prompts, we observe a striking regularity: the population of all dimensions exhibits a characteristic expanding envelope that is independent of input content (Figure 1), emerges only through training (Figure 2), and is consistent across architectures. Individual dimensions follow independent trajectories (Figure 3), confirming that the population-level structure is a statistical property of many independent paths. with cross-dimension mutual information of 0.0014 bits at the type level (isolated tokens) and 0.0006 bits in natural text (200 prompts, 25,600 contextual tokens). Context reduces pairwise coupling rather than increasing it. This observation motivates a framework we call Bag of Dims : treating transformer hidden states as collections of independent binary registers, where each dimension encodes content via its sign ( +1 

or −1) and confidence via its magnitude. Features are subsets of dimensions with consistent sign patterns, readable directly without training or learned rotations. 1

2.1 THE BAG -OF -D IMS FRAMEWORK 

We treat the hidden state of a transformer as a collection of independent binary registers. Each of the 

D dimensions ( D = 2560 for a 4B model, D = 4096 for Mistral 7B) functions as an independent channel: • Sign (+1 or −1): the semantic content, what the dimension is encoding. • Magnitude (|value |): the confidence, how committed the dimension is. A feature is a subset of dimensions with a consistent sign pattern across tokens of a given semantic category. For example, if tokens representing animals consistently have dims {47 , 512 , 1893 } positive and dims {203 , 678 } negative, that sign pattern is the “animal” feature, readable directly from the standard basis without any learned rotation. This is analogous to bag-of-words: just as bag-of-words ignores word order and treats each word as an independent signal, Bag of Dims ignores inter-dimension geometry and treats each dimension as an independent binary voter. 2.2 SINGLE -T OKEN TYPE CACHE 

To discover what each dimension encodes, we construct a type-level cache by running every vocabu-lary token through the model individually (no context): 1. For each of the V tokens in the vocabulary ( ∼248K for Qwen, ∼262K for Gemma, ∼32K for Mistral): • Feed the token as a single-token input • Extract the hidden state at target layers • Store the D-dimensional state 2. Result: a matrix H ∈ RV ×D per layer. We focus on layer 24 (of 32/34) as the primary semantic readout layer. A per-layer AUC sweep confirms that category separability peaks at intermediate layers before the prediction transition at layer 28 onward. Dim assignments are layer-specific (cross-layer Jaccard = 0 .042 ); discovery must be performed per-layer. The cache requires one forward pass per vocabulary token ( ∼20 minutes on a single GPU) and is computed once per model. 2.3 FEATURE DISCOVERY VIA PER -D IMENSION AUC Given the type-level cache, we discover features through three steps: 

Step 1: Anchor tokens. For a category ( e.g. , “animal”), select 50 single-token exemplars. 

Step 2: Per-dimension AUC. For each dimension d, compute AUC: how well does this dimension’s sign separate anchors from the full vocabulary? The negative set is the entire vocabulary ( ∼248K tokens), not a curated subset. 

Step 3: Build sign prototype. Collect dimensions with AUC above threshold (0.75) and record their expected polarity. The result is a (dim indices, polarities) pair. 

Scoring. To classify a new token, count the fraction of prototype dimensions where the token’s sign matches expected polarity: score = 1 − (Hamming distance /n dims ). No learned weights, just counting sign matches. 

Note on metrics. We report two distinct AUC values throughout: (1) per-dimension AUC measures how well a single dimension separates a category from the full vocabulary: this is a discovery metric for selecting which dims belong to a feature. # 4 RELATED WORK 

Sparse Autoencoders. SAEs decompose hidden states into overcomplete dictionaries of interpretable features (Bricken et al., 2023; Templeton et al., 2024; Cunningham et al., 2023). These methods assume features correspond to directions recoverable only through learned rotations. Our work shows that for 175 semantic categories, comparable detection is achievable from the standard basis without training. Beyond the 175 curated categories, unsupervised discovery (random anchor seeds, Hamming-based clustering) scales to 1500 features at 100% yield and 99% sparsity ( <1% vocab fire rate) across all three models, matching SAE-scale coverage without optimization. Recent work raises concerns about SAE reliability: Makelov et al. (2025) demonstrate that SAEs produce interpretable features even on untrained transformers, questioning whether discovered features reflect learned computation. We test this directly: on randomly initialized models with identical architecture, per-dim category AUC drops to 0.60–0.68 (0/175 categories detectable on Qwen/Gemma, 0 monosemantic features on all three), confirming that the structure we find requires training and is not an artifact of architecture or the discovery method. 

Linear probes. Probes (Alain & Bengio, 2017; Belinkov, 2022) confirm that representations contain information but require training per property. Our probe comparison reveals that trained probes converge to axis-aligned weights (99.9% sign agreement). They were finding per-dim features all along, without recognizing it. 9Logit lens. The logit lens (nostalgebraist, 2020) and tuned lens (Belrose et al., 2023) demonstrate that raw intermediate states are directly readable. Our framework extends this by explaining why :individual dimensions carry independent features, making intermediate states interpretable without any transformation. 

Representation engineering. RepE (Zou et al., 2023) identifies concept “directions” for monitoring and control. Our work suggests these may correspond to subsets of dimensions with consistent sign patterns rather than geometric directions. 

Individual neuron interpretability. Early work showed neurons encode concepts (Bau et al., 2017); the field moved away when “neurons are polysemantic” became consensus (Elhage et al., 2022). Our findings suggest polysemanticity may be localized to MLP interiors, while residual stream dimensions exhibit high per-dim specificity (AUC 0.80). 

# 5 DISCUSSION 

Why do dimensions behave independently? We observe this as an emergent property of training, not an architectural guarantee. Circuit tracing provides a mechanistic sketch: FFN neurons write to specific dim subsets via down proj . If neuron activations are sparse (few fire per token), each neuron writes to largely non-overlapping dimensions, inducing per-dim specificity. This is consistent with our MI finding (0.0014 bits) and with the structure surviving through learned projections. We emphasize that this is functional independence, cross-dimension capacity adds no practical value for feature reading, rather than a claim of strict statistical independence. 

Per-layer coordinate systems. The dim-to-concept mapping is layer-specific: cross-layer Jaccard overlap is 0.042 (chance level). Dim 847 may encode “animal” at h24 but something entirely different at h8 or h32 . The register file metaphor applies within each layer’s output, not across the full stack. Each layer’s FFN rewrites the residual stream into its own coordinate convention, and features discovered at hL link specifically to layer L−1’s FFN neurons (not to neurons at other layers). This is why discovery must be performed per-layer and why prototypes are not transferable across layers. Full per-layer sweep data is provided in Appendix D. 

Combinatorial coding. We discover 1500+ features from 2560 dimensions, with features using 

∼897 dims each and sharing ∼35% by overlap. Features remain independently detectable (99% fire on <1% of vocabulary) because scoring uses sign agreement on a feature’s specific dim subset, not a global operation. The capacity is combinatorial rather than geometric: features need not compete for orthogonal directions. 

Contextual updating. Approximately 58% of dimensions maintain their type-level sign in natural text; 42% flip. The flipping dimensions are predominantly low-magnitude and below threshold. This is the mechanism by which attention encodes contextual role while preserving type identity on the high-magnitude, feature-registered dims. Contextual pairwise MI is lower than type-level (0.0006 vs. 0.0014 bits), consistent with context diversifying rather than entangling dimensions. 

Limitations. (1) Scale: tested on 3–7B models; whether the structure persists at 70B+ is open. (2) The 42% flipping dims are predominantly low-magnitude but may carry contextual information that our type-level framework does not yet characterize. (3) Steering (flipping dims to change behavior) produces inconsistent results; type-level prototypes may be too coarse for behavioral control. (4) Cross-architecture variation exists: per-dim AUC scales with model capacity (Mistral 0.844, Qwen 0.801, Gemma 0.763). (5) The 175 categories are a subset of the model’s full feature inventory. 

# 6 CONCLUSION 

We have presented evidence that transformer dimensions function as independent binary registers encoding semantic features via their signs. This structure is validated across three model families through four converging lines of evidence: sign-only prediction achieves 72–93% top-5 accuracy (80–90% top-4096 without any decoder); 175 semantic categories are discoverable with zero training at AUC 0.80; the same features remain discoverable in K/V attention projections (remaining axis-aligned despite dense learned transforms); and specific FFN writer neurons install these patterns axis-aligned (confirmed against random controls). Low pairwise coupling (MI = 0.0014 bits) and 10 the failure of cross-dim probes indicate that per-dim reading captures the available structure without need for rotation. These findings show that the standard basis already provides a surprisingly effective feature basis, requiring no optimization, no GPU-days, and no hyperparameter tuning. We do not claim it is the unique or optimal basis, only that it suffices for practical feature reading at a quality comparable to trained methods. The method scales trivially: the type cache is one forward pass per vocabulary token, and all subsequent analysis is numpy on sign matrices.
