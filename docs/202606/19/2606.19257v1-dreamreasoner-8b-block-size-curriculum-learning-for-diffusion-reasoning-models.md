## 摘要
块扩散语言模型通过并行的逐块去噪加速解码，但它们能否可靠地扩展到长思维链（CoT）推理仍未解决。为此，我们开发了 DreamReasoner-8B，一个开源的块扩散推理模型，并系统研究了训练和推理块大小如何影响长CoT推理。我们的分析揭示了显著的性能差异：使用大块大小训练导致推理能力极差，而小块大小则保留了有效的推理能力。为了弥合这种粒度差距，我们提出了块大小课程学习，逐步将训练从细粒度块大小过渡到粗粒度块大小，从而克服了这一限制，并实现了跨不同推理块大小的强泛化推理性能。在数学和代码推理基准上，DreamReasoner-8B 取得了与领先的开源自回归模型（如 Qwen3-8B）相竞争的结果。这项工作为高效且具备推理能力的扩散语言模型奠定了实践基础。我们已在 https://github.com/DreamLM/DreamReasoner 发布我们的模型。

## Abstract
Block diffusion language models accelerate decoding through parallel block-wise denoising, yet whether they can be reliably scaled for long chain-of-thought (CoT) reasoning remains unresolved. To this end, we develop DreamReasoner-8B, an open-source block diffusion reasoning model, and conduct a systematic study of how training and inference block sizes affect long-CoT reasoning. Our analysis reveals a stark performance disparity: training with large block sizes yields remarkably poor reasoning, whereas small block sizes preserve effective reasoning. To bridge this granularity gap, we propose block-size curriculum learning, which gradually transitions training from fine-grained to coarse-grained block sizes, thereby overcoming this limitation and enabling strong reasoning performance that generalizes across diverse inference block sizes. On mathematical and code reasoning benchmarks, DreamReasoner-8B achieves results competitive with leading open autoregressive models such as Qwen3-8B. This work establishes a practical foundation for efficient, reasoning-capable diffusion language models. We release our model at https://github.com/DreamLM/DreamReasoner.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：自回归语言模型在复杂推理中表现优异，但其左到右逐 token 生成方式限制了解码并行性，导致推理效率瓶颈。扩散语言模型，特别是**块扩散**模型，通过并行块去噪提供了替代方案，但在长链思维（CoT）推理中，其性能与块大小的关系尚不明确，尤其在大块训练时会出现严重退化。
- **整体目标**：探究块扩散模型能否通过恰当的训练和推理策略，在维持推理质量的同时实现大规模并行解码。为此，开发了开源 8B 参数块扩散推理模型 DreamReasoner-8B，并系统研究训练/推理块大小对长 CoT 推理的影响，提出解决方案以弥合粒度差距。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 块扩散模型基础
- 将序列分成交互的块（block），每个块包含 B 个 token。
- 块间采用自回归分解：\( p_\theta(x_0) = \prod_{k=1}^K p_\theta(b_0^k \mid b_0^{<k}) \)，其中 \( b_0^k \) 是第 k 块的干净状态。
- 块内使用双向扩散过程并行去噪，采用吸收式掩蔽（[MASK] token）。

### 2.2 训练目标
- 对每个块，目标为预测掩蔽位置的原 token，损失为加权交叉熵：  
  \( L(\theta) = -\mathbb{E}_{t,b_0,b_t} \left[ \sum_{k=1}^K w_t \log p_\theta(b_0^k \mid b_0^{<k}, b_t^k) \right] \)，  
  其中 \( w_t = \alpha'_t/(1-\alpha_t) \) 是基于噪声调度 αt 的权重。

### 2.3 块大小课程学习
- **核心思想**：先使用细粒度小块（如块大小 4）训练，让模型学习精确的局部因果依赖和推理模式，再逐步过渡到粗粒度大块（如块大小 32），从而避免大块直接训练带来的性能崩溃。
- **具体流程**：
  - 基座模型 DreamReasoner-8B-Base 使用块大小 32 进行连续预训练。
  - 监督微调阶段：首先训练 3 个 epoch 块大小 4，然后切换到混合粒度训练（块大小从 {4,8,16,32} 中随机采样）1 个 epoch。

### 2.4 RelaxedConfidence 解码策略（分析性探针）
- **问题**：标准 LowConfidence 解码（阈值为 0.95）过于保守，连续高质量 token 因独立置信度不高而无法被提前提交。
- **方法**：为每个 token 定义位置相关的阈值 \( \tau_i = \tau - (\tau - \tau_{\min}) S_i \)，其中 \( S_i \) 是局部支持分数，基于已解码邻居的信心值计算。
- **效果**：孤立 token 保持原阈值，被可靠邻居包围的 token 可被提前提交，从而加速解码而不牺牲准确率。

## 5. 主要结论与发现

### 5.1 块大小影响
- **大块直接训练导致推理性能显著下降**：块大小 32 训练在 AIME 2024 上仅 20.0%（小块推理时），而小块 4 训练可达 47.1%。
- **小块训练更具鲁棒性**：即使在大块推理下仍保持较高性能，说明局部结构可推广。

### 5.2 解码策略影响
- 粗粒度训练在 LowConfidence 解码下表现更差，而自回归解码可部分恢复，显示其过度依赖并行聚合，缺乏 token 级顺序推理。

### 5.3 课程学习有效性
- 课程学习（4→32）在所有推理块大小下表现稳健，弥合了粒度差距，达到与小块训练相当甚至更好的平均性能。

### 5.4 DreamReasoner-8B 竞争性
- 在数学和代码推理上与 Qwen3-8B-Thinking 等 8B 级别模型持平，显著超越之前所有开源扩散推理模型。
- 推理块大小变化时性能稳定，而 SDAR-30B-A3B-Sci 出现严重退化。

### 5.5 效率加速
- TPF 随推理块大小单调增加，准确率稳定。
- RelaxedConfidence 在思考阶段提升 TPF 12-33%，回答阶段提升 50-59%，且准确率几乎不变。

## 6. 优点
