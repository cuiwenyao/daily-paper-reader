## 摘要
现实世界中的决策很少遵循固定的脚本。相反，它表现为一个动态推理过程，其中适当的行动方案随着新背景和数据的出现而演变。传统的业务流程管理系统提供了严谨性、确定性和可审计性，但它们通常难以在运行时调整执行。相反，基于大型语言模型（LLM）的智能系统为决策带来了灵活性，但它们本质上是黑箱的，往往不可靠，并且在处理大型数据集时面临显著的可扩展性限制。为了结合这些互补范式，我们引入了VADAOrchestra，这是一个神经符号框架，将复杂工作流建模为演变的推理过程。该框架采用混合方法：给定用户查询和一组数据源，基于LLM的编排器逐步规划并调整工作流。这被编码为Datalog+/-片段中的逻辑程序，其中谓词对应工具调用，规则既表示预定义的领域依赖关系，也表示按需合成的用于操作中间结果的逻辑构造。然后，所有逻辑推理任务均由最先进的Datalog+/-符号引擎执行。这种方法提供了可验证的推理轨迹，支持整个过程的审计性和可重复性。此外，通过将高层编排与符号推理解耦，它解决了可扩展性问题，通过有针对性的数据查询实现了对大型数据集的复杂推理。我们在真实世界的金融用例上评估了VADAOrchestra，展示了其与标准智能架构相比的忠实性、可扩展性和可解释性。

## Abstract
Decision-making in real-world settings rarely follows a fixed script. Instead, it unfolds as a dynamic reasoning process in which the appropriate course of action evolves as new context and data become available. Traditional Business Process Management systems provide rigor, determinism, and auditability, yet they generally struggle to adapt their execution at runtime. Conversely, agentic systems based on Large Language Models (LLMs) bring flexibility to decision-making, but they are inherently opaque, often unreliable, and suffer from significant scalability constraints when operating over large datasets. To combine these complementary paradigms, we introduce VADAOrchestra, a neurosymbolic framework that models complex workflows as evolving reasoning processes. The framework adopts a hybrid approach: given a user query and a collection of data sources, an LLM-based orchestrator incrementally plans and adapts the workflow. This is encoded as a logic program in a fragment of Datalog+/- where predicates correspond to tool invocations and rules represent both predefined domain dependencies and logic constructs synthesized on demand to manipulate intermediate results. All logical inference tasks are then executed by a state-of-the-art Datalog+/- symbolic engine. This approach provides a verifiable reasoning trace, supporting the auditability and reproducibility of the entire process. Furthermore, by decoupling high-level orchestration from symbolic inference, it addresses scalability concerns, enabling complex reasoning over large datasets through targeted data querying. We evaluate VADAOrchestra on real-world financial use cases, demonstrating faithfulness, scalability, and explainability compared to standard agentic architectures.

- **整体意义**：提出一种全新的**神经符号编排框架**，将 LLM 的灵活规划能力与符号引擎的确定推理结合，为金融等高风险领域提供可验证、可重复、可扩展的决策工作流自动化方案。

## 2. 论文提出的方法论

### 核心思想
将整个工作流（包括结构化组件和动态适应组件）建模为一个**不断演化的逻辑程序**（Vadalog，Datalog+/- 的扩展）。  
- **LLM 编排器（Orchestrator）**：负责工具发现、依赖感知规划、参数化、数据驱动重规划，以及按需合成逻辑规则。编排器本身不直接处理原始数据。
- **符号推理引擎（Vadalog）**：执行所有数据推理任务（如聚合、连接、算术运算），提供确定性结果。

### 关键技术细节
1. **工具定义**：每个推理工具对应一个 Vadalog 程序，包含名称、参数、描述、输出谓词、依赖列表。
2. **依赖图构造**：对选定工具递归解析 `get_dependencies`，生成有向无环图（DAG），确保执行顺序正确。
3. **执行计划生成**：将工具调用划分为多个并行的阶段（stage），满足完整性、互斥性、依赖顺序、谓词安全性。
4. **智能数据检索**：执行阶段后，LLM 首先检查中间结果的**基数**，对超过阈值的谓词先获取统计摘要（min/max/分布），再制定针对性的 `get_top_k` 策略，避免将全部数据塞入上下文。
5. **按需数据操作（On-Demand Data Manipulation）**：LLM 根据当前理解**动态合成 Vadalog 规则**（如聚合、连接、算术运算），交由符号引擎执行并保存到逻辑轨迹。
6. **重规划机制**：每次执行后，LLM 评估是否需要新的工具调用，并基于依赖图扩展计划；限制最大迭代次数，禁止重复调用相同工具与参数。
7. **逻辑轨迹**：完整的执行过程被记录为一个有序的 Vadalog 程序（包括调用规则和操作规则），可独立重放得到相同结果，实现完全可审计。

### 算法流程（文字说明）
1. 工具发现和选择 → 2. 依赖感知规划 → 3. 生成执行计划 → 4. 迭代执行每个阶段（并行工具调用 → 智能数据检索 → 可选数据操作 → 重规划决策） → 5. 所有阶段完成后生成最终答案。

## 3. 实验设计

### 数据集
- **Bank 数据集**：基于欧洲某央行知识图谱（约 10k 三元组，9 类关系），包含 278 道模板化问题（通用查询、计数、多跳问题）。
- **Bank+ 数据集**：Bank 的增强版，用于可扩展性压力测试，计数查询所需实体数从 1 到 1000 不等。

### 基准方法
- **LLM-only**：仅用 LLM 参数知识回答。
- **ReFactX**：约束解码方法，在知识图谱三元组上构建前缀树限制输出。
- **LLM+RAG**：检索增强生成，检索相关段落注入上下文（实验中配置了 top-10 / top-100 / top-1000 三种深度）。
- **LLM+MCP**：赋予 LLM 与 VADAOrchestra 相同的推理工具（通过 MCP），但无依赖感知规划和动态规则合成能力。

### 评估指标
- **Exact Match (EM)**：字符串完全匹配。
- **LLM-as-a-Judge**：用独立 LLM（Llama-3.3-70B）判断答案是否正确且完整。

### LLM 骨架
- 开源模型：Llama-3.3-70B-Instruct
- 闭源模型：GPT-4o（API）
