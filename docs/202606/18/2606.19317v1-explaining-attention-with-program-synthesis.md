## 摘要
可解释深度学习研究的一个长期目标是，用具有人类意义的符号描述取代不透明的神经计算。本文提出了一种方法，用可执行程序近似深度网络组件的行为。我们聚焦于Transformer语言模型中的注意力头。对于给定的注意力头，我们首先在一组随机选取的训练样本上计算其关联的注意力矩阵。接着，我们向预训练语言模型提供这些矩阵的摘要，并指示其生成一组Python程序，这些程序仅根据输入句子的文本就能重现关联的注意力模式。最后，我们根据程序在保留输入上预测行为的效果进行重新排序。我们证明，少于1000个这样的生成程序就能重现GPT-2、TinyLlama-1.1B和Llama-3B模型中注意力头的注意力模式，在TinyStories数据集上平均交并比相似度超过75%。此外，最优匹配程序可以替代神经注意力头而不显著影响模型行为：在三个模型中用程序替代25%的注意力头仅导致平均困惑度增加16%，同时在各种下游问答基准上保持性能。这项工作为使用人类可读、可执行代码逆向工程Transformer模型中的注意力头提供了一个可扩展的流水线，推动了神经模型符号透明性的进程。

## Abstract
A longstanding goal of research on interpretable deep learning is to replace opaque neural computations with human-meaningful symbolic descriptions. In this paper, we propose an approach for approximating the behavior of components of deep networks with executable programs. We focus on attention heads in transformer language models. For a given head, we first compute its associated attention matrices on a collection of randomly selected training examples. Next, we prompt a pre-trained language model with a summary of these matrices, and instruct it to generate a set of Python programs that can reproduce the associated attention patterns given only text from the input sentence. Finally, we re-rank programs according to how well our final set of programs predict behavior on held-out inputs. We demonstrate that a set of fewer than 1,000 such generated programs can reproduce the attention patterns of heads in GPT-2, TinyLlama-1.1B, and Llama-3B, achieving an average Intersection-over-Union similarity above 75% on TinyStories. Moreover, the best-fit programs can replace neural attention heads without substantially affecting model behavior: replacing 25% of attention heads with programmatic surrogates across the three models incurs only a 16% average perplexity increase, while maintaining performance on a variety of downstream question answering benchmarks. This work contributes a scalable pipeline for reverse-engineering attention heads in transformer models using human-readable, executable code, advancing a path toward symbolic transparency in neural models.

# 通过程序合成解释注意力机制：论文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：深度学习模型（尤其是Transformer语言模型）的内部计算是黑箱，现有解释方法（如神经探测、自然语言描述）要么缺乏形式化保证，要么难以验证。论文旨在用**可执行程序**作为中间表示，近似注意力头的计算，实现人类可读、可验证、可直接替换的解释。
- **整体意义**：提供一种可扩展的符号化逆向工程方法，将神经注意力头的行为转化为人类可阅读和修改的代码，推动神经模型向符号透明性迈进。

## 2. 论文提出的方法论

- **核心思想**：利用另一个语言模型（explainer LM）基于提取的注意力模式生成候选Python程序，并通过相似度评估和一轮反馈改进选择最佳程序。
- **关键技术细节**：
  - **注意力提取**：在目标模型处理输入序列时，记录每个注意力头的注意力矩阵 \(A\)（softmax后的权重）。
  - **提示构造**：提取每个输入中权重最高的2.5%的注意力边，格式化为token-pair权重摘要，嵌入结构化的提示（约4000 tokens）。
  - **程序合成**：使用explainer LM（Claude Sonnet 4）生成候选Python函数，函数输入为文本tokens，输出为预测的注意力矩阵\(\hat{A}\)。LM可调用NumPy、spaCy、NLTK等库。
  - **评估与选择**：使用Jensen-Shannon距离（JSD）衡量真实与预测注意力分布的差异：
    \[
    \text{JSD}(A, \hat{A}) = \frac{1}{2} \text{KL}(A \parallel \frac{A+\hat{A}}{2}) + \frac{1}{2} \text{KL}(\hat{A} \parallel \frac{A+\hat{A}}{2})
    \]
    并进一步使用交并比（IoU）作为对齐指标。
  - **改进**：对最佳候选程序进行一轮反馈（提供最好和最差样本的对比），重新生成改进版本。最终在验证集上选择性能最优的程序。
- **算法流程**：提取注意力 → LM生成候选程序 → 执行评估 → 反馈改进 → 在验证集上选优。

## 6. 论文的主要结论与发现

- **程序拟合准确性高**：少于1000个程序即可为三个因果模型实现平均IoU > 75%（GPT-2: 69%, TinyLlama: 74%, Llama-3B: 79%）。BERT双向模型拟合较差（仅稀疏高IoU头）。
- **因果替换可行**：替换25%的头仅导致平均16%的困惑度增加；替换30–40%时下游任务性能无明显下降。
- **IoU是良好代理指标**：IoU与替换后困惑度增加呈强负相关（r > 0.9）。
- **模型规模与拟合质量正相关**：更大的模型（Llama-3B）头更容易被程序拟合，猜测因为功能特化更明显。
- **头类型分布存在层次结构**：早期层以“首token”程序为主，中层“句法”程序增加，深层“共指”程序增多。

## 7. 优点

- **方法创新**：首次将基于LM驱动的程序合成用于解释和替换现代大语言模型的注意力头。
- **可验证性**：程序是可执行、可直接插入模型的，允许因果验证（干预实验）。
- **可扩展性**：仅使用少量API成本即可生成覆盖上千头的程序库。
- **结果透明**：提供了程序文档字符串分类，有助于理解不同头的行为。
- **公平基线**：对比了随机和均匀基线，突显了程序方法的有效性。

## 8. 不足与局限

- **覆盖不完全**：许多头的IoU低于40%（尤其是BERT），当前程序库尚不能充分表征所有头。
- **程序多样性有限**：很多高得分程序是简单模式（如主要关注首token），复杂行为难以捕获。
- **单一反馈轮次**：仅进行一轮改进，可能错失更优解。
- **因果替换仅限因果模型**：BERT双向注意力头的替换效果未评估，且替换顺序贪心，未探索联合优化。
- **潜在修剪效应混淆**：在低替换水平下性能甚至提升，与注意力剪枝类似，需区分“解释真的抓住了功能”和“该头本身多余”。
- **语言模型偏差**：使用Claude Sonnet 4作为合成器，可能引入其自身的偏差或模式，影响程序的泛化性。
